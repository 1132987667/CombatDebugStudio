## 批次 4：创建 `_mixins.scss` + 模式收敛

### 4a. 创建 `src/presentation/styles/_mixins.scss`

定义 8 个 mixin（零 CSS 产物，纯抽象）：

1. `flex-layout($justify, $align)` — flex 容器
2. `btn-base` — 按钮基座
3. `field` — 输入框/选择器
4. `panel-header` — 面板头部
5. `panel` — 面板容器
6. `badge($bg, $fg)` — 徽章
7. `empty-state` — 空状态
8. `overlay($z)` — 遮罩

### 4b. 应用到 SCSS partials

#### `_buttons.scss`（~200 行→~80 行）
- `btn-base` 收敛 12+ 按钮变体的基座样式
- 差异行（padding、font-size、特定颜色）保留在类中

#### `_cards.scss`（~540 行→~400 行）
- `.panel` → `@include panel`
- `.badge-*` → `@include badge(...)`
- `.empty-*` → `@include empty-state`

#### `_battle-log.scss`
- `@include empty-state` for `.no-logs`
- `@include scroll-area` for `.log-content`
- `@include flex-layout` for `.log-header`, `.log-tabs`, `.log-tools`

#### `_layout.scss`
- `@include flex-layout` for layout sections
- `@include panel` for panel sections
- `@include scroll-area` for scroll containers

#### `_dashboard.scss`
- `@include panel-header` for dashboard headers
- `@include empty-state` for `.no-skills`

#### `_keybind.scss`
- `@include panel`
- `@include badge`
- `@include field`

#### `_dialog.scss`
- `@include overlay` for dialog overlay

### 4c. 注意：scoped .vue 组件中不用 `@use _mixins`

所有 `_mixins` 的消费方是 SCSS partials（被 main.scss @forward），组件中不额外 `@use`。如果未来组件需要在 scoped 中用 mixin，则写 `@use '@/presentation/styles/mixins' as *;`——因 `_mixins.scss` 是零产物的纯 mixin 文件，这样用安全。

### 4d. 排除 `main.scss` 直接引入 `_mixins`

`_mixins.scss` 不加入 `main.scss` 的 `@forward` 链，仅在具体 partial 中 `@use`。这样既不会产生全局 CSS 输出，语义也清晰。

**验证**：`npm run build` + 逐面板点检
