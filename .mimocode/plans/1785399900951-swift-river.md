### R1：updatePerTurn 传 currentTurn（1 行修改）

**文件**：`src/domain/buff/BuffSystem.ts` 第 999 行

**改前**：
```typescript
instance.script.onUpdate(instance.context, 0)
```

**改后**：
```typescript
instance.script.onUpdate(instance.context, currentTurn)
```

**理由**：`updatePerTurn` 已经接收 `currentTurn` 参数，effectPlan 的 `onTick` 已正确传递它。
唯独脚本的 `onUpdate` 被硬编码了 `0`，导致 ShieldBuff._onUpdate 等基于回合的逻辑看不到当前回合数。

### R2：effectLines 适配 Path A（约 3 行）

**文件**：`src/domain/buff/BuffSystem.ts` 第 654-673 行

**改前**：
```typescript
if (buffResolved?.effectPlan && buffResolved.effectPlan.length > 0) {
  // effectPlan onApply ...
  // effectLines 从 effectPlan 生成并追加到脚本 effectLines 之后
  if (effectLines.length > 0) {
    buffInstance.effectLines = [...buffInstance.effectLines, ...effectLines]
  }
}
```

**改后**：
```typescript
if (buffResolved?.effectPlan && buffResolved.effectPlan.length > 0) {
  // effectPlan onApply ...
  // Path A：effectLines 只从 effectPlan 生成，覆盖脚本的 effectLines
  if (effectLines.length > 0) {
    buffInstance.effectLines = effectLines
  } else {
    buffInstance.effectLines = []
  }
}
```

**理由**：Path A（纯 effectPlan）的 buff 不应展示脚本生成的 effectLines（脚本可能无 effectLines 或返回过时内容）。
