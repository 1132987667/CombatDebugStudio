# 恢复"通用减免"展示 — 改用 `damageReduction` 字段

## 背景

之前删除了 `DamageBreakdown` 中的 `generalDamageReduction`（与 `damageReduction` 属性重复），但模板里的"通用减免"区块也顺带删了。用户确认需要展示 `damageReduction`（免伤率）。

`DamageCalculator.ts:490-504` 已应用 `ATTRIBUTE_CODE.damageReduction` 做计算，但未将其存入 `DamageBreakdown` 用于展示。

## 改动

### 1. `src/domain/battle/combat-record.ts` — 新增字段

在 `DamageBreakdown` 接口中添加：

```ts
/** 通用减免（免伤率，百分比点） */
damageReduction?: number
```

放在 `damageTakenIncrease` 附近（第 100 行），语义相关。

### 2. `src/domain/skill/DamageCalculator.ts` — 赋值

在 `damageReduction` 计算步骤（第 492 行）处，将 `dmgReduction` 值写入 `breakdown.damageReduction`：

```ts
const dmgReduction = getAttrVal(target, ATTRIBUTE_CODE.damageReduction)
breakdown.damageReduction = dmgReduction  // 新增
```

### 3. `src/presentation/views/components/BattleRecordingDialog.vue` — 恢复展示

在第 78 行后（`skillDmgReduction` 块之后）重新添加"通用减免"行：

```vue
<div v-if="record.damageBreakdown.damageReduction" class="stat-row">
  <span class="stat-label">通用减免</span>
  <span class="stat-value">{{ record.damageBreakdown.damageReduction }}%</span>
</div>
```

## 涉及文件

| 文件 | 操作 |
|------|------|
| `src/domain/battle/combat-record.ts` | +1 行（接口字段） |
| `src/domain/skill/DamageCalculator.ts` | +1 行（赋值） |
