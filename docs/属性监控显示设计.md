# 属性监控显示设计

## 四层架构

所有属性的修饰符来源按以下四层组织：

| 层级 | 系统类型 | 说明 |
|------|---------|------|
| **基础数值** | `base` + `ADDITIVE` | 基础值 + 固定数值加成，不含百分比 |
| **属性加成** | `PERCENTAGE` | 百分比加成，叠乘计算中的第二乘区 |
| **独立乘区** | `MULTIPLICATIVE` | 独立乘法，叠乘计算中的第三乘区 |
| **最终乘区** | `FINAL` | 最终乘法，叠乘计算中的第四乘区 |

## 攻击力（区间属性）

攻击力是范围值，拆分为 **最小攻击力（minAttack）** 和 **最大攻击力（maxAttack）** 两个独立属性各自计算，各层的取值均为区间。

### 显示格式

```
基础数值            min-max
基础                minBase-maxBase
装备                +value
装备(最小攻击力)    +value
装备(最大攻击力)    +value

属性加成            min%-max%
天赋                +value%
特性(最小攻击力)    +value%
特性(最大攻击力)    +value%

独立乘区            min%-max%
...

最终乘区            min%-max%
...
```

### 修饰符标注规则

- 同时作用于 **最小+最大** 且值相同的修饰符 → 直接显示 `+value`
- 仅作用于 **最小攻击力** → 标注 `(最小攻击力)`
- 仅作用于 **最大攻击力** → 标注 `(最大攻击力)`
- 同时作用于两者但值不同 → 拆为两行分别标注

### 计算过程

```
[最小] base × (1 + 增幅合计%) × (1 + 独立合计%) × (1 + 最终合计%) = result
[最大] base × (1 + 增幅合计%) × (1 + 独立合计%) × (1 + 最终合计%) = result
→ finalMin-finalMax
```

## 通用属性（单值属性）

非攻击力的普通属性按现有逻辑计算，显示格式：

```
基础数值            value
基础                +baseValue
装备                +value
特性                +value

属性加成            total%
天赋                +value%
...
```

## 数据层约定

- `minAttack` 和 `maxAttack` 各自维护独立的 `AttributeValue`（含各自的 `modifiers` 列表）
- 增幅/独立/最终乘区的修饰符按 `ModifierType`（`PERCENTAGE` / `MULTIPLICATIVE` / `FINAL`）归类
- 基础数值层包含 `base` 修饰符和所有 `ADDITIVE` 类型的修饰符
