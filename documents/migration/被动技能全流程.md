# 分析
对 首领威严 进行分析
```
{
  "id": "skill_enemy_008_passive",
  "name": "首领威严",
  "description": "被动效果：为所有友方单位施加光环，提升15%攻击力和10%防御力",
  "cooldown": 0,
  "selector": {
    "faction": "self",
    "strategy": "first"
  },
  "steps": [
    {
      "type": "apply_buff",
      "buffId": "aura_leader_awe"
    }
  ],
  "energyCost": 0,
  "skillType": "passive",
  "triggerTimes": [
    "battle_start"
  ]
},
```


---

### 1. 分层设计
- **第 1 层：被动技能的作用目标（`skill_passive.json` 中的 `selector`）**
  ```json
  "selector": { "faction": "self" }
  ```
  它的语义是：**这个被动技能只作用于施法者自己**。  
  即：金护法发动被动，把“首领威严”这个 **Buff 施加到自己身上**。

- **第 2 层：Buff 的扩散范围（`buffs.json` 中的 `aura.targetSelector`）**
  ```json
  "aura": { "targetSelector": "allies" }
  ```
  它的语义是：**这个 Buff 是一个光环**，当它挂载在某人身上时，会自动把修饰符**扩散给所有友方单位**。

所以流程是：`金护法（自己）` → `获得“首领威严”光环` → `光环自动扩散给所有友方`。

**结论**：`faction: "self"` 是用来“给施法者挂载光环”的，而 `targetSelector: "allies"` 才是真正实现“全友方生效”的字段。

---

### 2. 光环的 `cooldown` 应该怎么配置？

需要区分**被动技能的冷却**和**光环本身的刷新机制**：

#### (1) 被动技能的 `cooldown`（配置在 `skill_passive.json`）
当前配置：`"cooldown": 0`

- **触发时机**：`"triggerTimes": ["battle_start"]`
- **系统默认**：`battle_start` 触发的被动，**最大触发次数默认为 1**（整场战斗只触发一次）。
- **结论**：因为只触发一次，`cooldown` 字段在此场景下**不会被使用**。保持 `0` 即可，无论设成多少都不会影响功能（因为不会第二次触发）。

#### (2) 光环（Buff）自身的持续/刷新（配置在 `buffs.json`）
光环本身**没有 `cooldown` 字段**，它只有 `duration`（持续时间）：

```json
"duration": -1   // -1 表示永久持续，整场战斗不会消失
```

因此，这个光环的**最佳配置就是 `duration: -1`**（永久），配合 `battle_start` 触发一次，覆盖整场战斗。不需要任何“冷却”或“刷新”机制。

---

### 总结

| 层级 | 配置位置 | 当前值 | 正确性 | 说明 |
|------|---------|--------|--------|------|
| 被动技能目标 | `skill_passive.json` → `selector` | `self` | ✅ 正确 | 给自己挂载光环 Buff |
| 光环扩散范围 | `buffs.json` → `aura.targetSelector` | `allies` | ✅ 正确 | 让光环影响所有友方 |
| 被动冷却 | `skill_passive.json` → `cooldown` | `0` | ✅ 无影响 | `battle_start` 只触发一次，冷却字段不生效 |
| 光环持续 | `buffs.json` → `duration` | `-1` | ✅ 最佳实践 | 永久光环，无需刷新 |

您唯一可以做的“规范化”调整是：删除 `selector` 中多余的 `"strategy": "first"`（因为 `faction: "self"` 时该字段被忽略）。其他配置（包括 `cooldown`）在功能上都是正确的。
