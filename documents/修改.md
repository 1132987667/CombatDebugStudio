根据代码分析，我来详细解释技能系统中 `selector` 和 `target` 的设计原理、优先级和判断逻辑：

## 📊 两个字段的定义和区别

### **1. `selector` 字段**
- **作用**：定义技能的**初始目标选择范围**（即技能整体的目标范围）
- **位置**：在技能配置的根级别
- **值类型**：字符串
- **常见值**：
  - `"single_enemy"` - 选择单个敌人
  - `"all_enemies"` - 选择所有敌人
  - `"self"` - 选择自身
  - `"all_allies"` - 选择所有友方
  - `"lowest_ally"` - 选择生命值最低的友方
  - `"all"` - 选择所有单位

### **2. `target` 字段**
- **作用**：定义**单个步骤的具体目标**
- **位置**：在 `steps` 数组中的每个步骤对象中
- **值类型**：字符串
- **常见值**：
  - `"enemy"` - 敌人
  - `"self"` - 自己
  - `"allies"` - 所有友方
  - `"lowest_ally"` - 生命值最低的友方
  - `"all"` - 所有单位

## ⚖️ 优先级和判断逻辑

### **优先级规则**
```
步骤中的 target > 技能中的 selector
```

### **详细判断逻辑流程**

```typescript
// 伪代码：动作执行器处理技能的逻辑
async executeSkill(skillConfig, caster) {
    // 1. 使用 selector 确定技能的整体目标范围
    let skillTargets = this.selectTargetsBySelector(caster, skillConfig.selector);
    
    // 2. 遍历技能的每个步骤
    for (const step of skillConfig.steps) {
        // 3. 确定当前步骤的目标
        let stepTarget;
        
        if (step.target) {
            // 如果步骤有 target 字段，使用步骤的 target
            stepTarget = this.selectTargetsByStepTarget(caster, step.target, skillTargets);
        } else {
            // 如果步骤没有 target 字段，使用技能的 selector 结果
            stepTarget = skillTargets;
        }
        
        // 4. 执行步骤
        await this.executeStep(step, caster, stepTarget);
    }
}
```

```typescript
function selectTargetsBySelector(caster, selector) {
    switch (selector) {
        case "single_enemy":
            // 从敌人列表中选择一个目标（自动战斗AI选择或随机选择）
            return [selectRandomEnemy()];
        case "all_enemies":
            // 返回所有敌人
            return getAllEnemies();
        case "self":
            // 返回施法者自己
            return [caster];
        case "all_allies":
            // 返回所有友方单位
            return getAllAllies();
        case "lowest_ally":
            // 返回生命值最低的友方
            return [getLowestHealthAlly()];
        default:
            // 默认返回空或错误
            return [];
    }
}
```

### **2. `target` 的选择逻辑**
```typescript
// 伪代码：根据步骤的 target 选择目标
function selectTargetsByStepTarget(caster, target, skillTargets) {
    switch (target) {

            // 使用所有单位
            return getAllUnits();
        default:
            // 默认使用技能选择的目标
            return skillTargets;
    }
}
```

```typescript
// ActionExecutor.ts
async executeSkill(skillConfig, caster) {
    // 防御性检查：确保 selector 存在
    if (!skillConfig.selector) {
        console.error(`技能 ${skillConfig.id} 缺少 selector 字段`);
        // 使用默认值
        skillConfig.selector = "single_enemy";
    }
    
    // 选择目标
    let targets = this.selectTargets(skillConfig.selector, caster);
    
    if (!targets || targets.length === 0) {
        console.error(`无法为技能 ${skillConfig.id} 选择目标`);
        return;
    }
    
    // 执行步骤
    for (const step of skillConfig.steps) {
        // 确定步骤目标
        let stepTarget = step.target ? 
            this.selectTargets(step.target, caster) : 
            targets;
        
        await this.executeStep(step, caster, stepTarget);
    }
}
```

## 📋 总结：设计建议

1. **必须为所有技能配置 `selector` 字段**，这是技能系统的基础
2. **步骤中的 `target` 是可选的**，用于覆盖技能的默认目标选择
3. **优先级：步骤 target > 技能 selector**
4. **被动技能**通常使用 `"selector": "self"`
5. **攻击技能**通常使用 `"selector": "single_enemy"` 或 `"all_enemies"`
6. **辅助技能**可能使用 `"selector": "all_allies"` 或 `"lowest_ally"`

**针对您的自动战斗卡住问题**，最可能的原因是：
1. 第一个角色的技能缺少 `selector` 字段
2. 或者 `selector` 值无效，导致无法选择目标
3. 动作执行器在解析技能时出错，但没有正确处理异常

**建议立即检查 `configs/skills/skills.json` 中所有技能的 `selector` 字段是否完整有效**，特别是第一个出场角色的技能。
