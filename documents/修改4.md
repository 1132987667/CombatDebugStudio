# 遗留问题清单 — 第四轮修改（消灭启发式猜测）未修复事项

> 记录日期：2026-07-31；复核日期：2026-08-05 / 2026-08-11。本文档源自《修改4.md》，已修复项均已归档，此处仅保留**未修复**事项。

## 一、未修复事项

### 1.1 participantMapper 的 perStack 语义

`participantMapper.buildBuffRawItems` 合并多个 MODIFIER 效果的 attributes 后统一 `× stacks`，
`perStack: false` 时语义丢失（2026-08-11 复核：`configs/buffs/buffs.json` 已有 10 处 modifier 效果声明 `perStack: false`，该语义丢失已具实际影响）。
**建议**：提取 attributes 时保留 perStack 标志。

### 1.2 动态 Buff 的 triggers phase 未归一化

`BuffConfigResolver` 仅对 JSON 配置的 `triggers[].phase` 归一化；运行时动态创建的 Buff
（调用方传入 `config.triggers`）若使用旧风格名（`ON_TURN_START`）会注册到错误事件名，
触发器静默失效。当前无动态 Buff 携带 triggers，无实际影响。**建议**：在 `BuffSystem.registerTriggersForInstance`
入口统一归一化（复用 `OLD_PHASE_NAME_MAP`）。

### 1.3 isPercentage × PERCENTAGE 组合（原复核注记"另发现"）

全库约 20 处 isPercentage 属性（critRate/dodge/damageReduction 等）× PERCENTAGE 组合，
基值 0 时按乘法缩放完全无效，与"属性+X%"描述不符，需策划确认意图后逐条修正。
**建议**：单独立项，确认意图后逐条修正。
