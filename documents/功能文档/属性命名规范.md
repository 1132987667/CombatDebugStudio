# 属性命名规范（命中 / 闪避族）

> 2026-09-23 拍板。起因：`hit` 一个 key 曾同时承载三套语义（命中率%修正、SAP 六维固定值、宠物生成权重），对账极易串线；敌人 stats 又用 hit/dodge 作命中值/闪避值的别名。本文为当前唯一的命名权威口径。

## 属性 code 单源

- 权威单源：`configs/attributes/attributes.json`。
- `ATTRIBUTE_CODE` / `AttributeMetaMap` 由 `scripts/generate-attributes.cjs` 自动生成（`npm run generate:attributes`），**勿手改** `src/domain/attribute/attribute-codes.generated.ts`。
- 改属性列表/改 code 名 = 只改 attributes.json，然后重新生成，typecheck 会揪出全部漏改引用点。

## 命中 / 闪避四键

| code | 名称 | 语义 | 量纲 |
|------|------|------|------|
| `hitValue` | 命中值 | 攻方基础值，与守方闪避值对抗：基础命中率 = hitValue / (hitValue + dodgeValue) | 固定值 |
| `dodgeValue` | 闪避值 | 守方基础值 | 固定值 |
| `hitRate` | 命中率 | 命中公式修正加项 | 百分点 |
| `dodgeRate` | 闪避率 | 命中公式修正减项 | 百分点 |

命中公式（PRD §12，实现见 `DamageCalculator.ts`，受 `enableDodge` 门控，默认关闭）：
实际命中率 = clamp(基础命中率 + hitRate − dodgeRate, 10%, 95%)

## 同形不同义键（非属性 code，勿与上表混淆）

| 键 | 位置 | 语义 |
|----|------|------|
| `hit` / `dodge`（值 1-5） | `configs/pets/pets.json` weights、`configs/mounts/mounts.json` weights、`equipment-overview.ts` 个体键 | 宠物/坐骑属性投放**生成权重** |
| `hit` / `dodge`（加点键） | `player.json` statBonuses 外层键、`debugActions.ts` STAT_ALLOC_KEYS | 演劫台自由加点面板键，映射到 hitValue/dodgeValue |
| `HIT` / `DODGE` | `unified-attrs.ts`、`BattleTriggerPhase` | 回放属性简写 / 触发时机枚举 |
| 敌人 `stats` 键 | `configs/enemies/enemies.json` | 已统一为 `hitValue`/`dodgeValue`（2026-09-23），无别名，键名即属性 code |

## 后缀约定

- `Rate`：百分比/几率属性（hitRate / dodgeRate / critRate / comboRate / debuffImmunityRate…）
- `Value`：固定值对抗属性（hitValue / dodgeValue）
- `Ratio` 后缀不使用，避免与 Rate 双轨。

## 格挡

本项目**无格挡概念**（2026-09-23 移除）：无格挡属性 code、无格挡触发器；历史设计文档中的格挡词条已清理，`documents/过期/` 与 `configs/expired/` 归档保留原貌不动。
