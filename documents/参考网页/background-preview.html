战斗背景质感参考

全部为纯 CSS 实现，不依赖图片资源。质感三要素：1) 多层渐变定调（径向 + 线性叠出空间感）、2) 噪点颗粒覆层（SVG feTurbulence 压膜，去"塑料感"）、3) 光晕与暗角（聚焦视线 + 增加纵深）。点击任意卡片全屏预览。

01 夜穹星光

radial-gradient 1~2.5px 点阵×5 层平铺星群；顶部蓝紫光晕 + 底部深色渐变收底

适合：战斗结算 / 秘境入口 / 剧情过场

02 熔岩地脉

repeating-linear-gradient 斜向裂纹 + blur + screen 混合；底部炽红径向渐变 + 脉动动画

适合：副本入口 / BOSS 战前

03 幽蓝深海

浅蓝顶部天光 + 深色底部；repeating-linear-gradient 斜波纹 + blur 缓慢起伏

适合：水战地图 / 水底洞窟

04 机械网格

双层 1px 细网格（大格 + 小格）叠色光晕；扫描亮线上下循环

适合：科技城 / 测试场 / 数据分析台

05 极光冰原

多层大 blur 色带 + screen 混合 + 缓慢漂移；绿/紫/青三色光幕

适合：北境 / 天空地图 / 圣洁氛围

06 羊皮纸卷

米黄色渐变 + 不规则浅斑（radial hard-stop）+ 噪点压膜 + inset 暗角

适合：技能图鉴 / 古籍 / 商贩面板

07 像素复古

linear-gradient 阶梯硬边造像素云山；1.5~2px 点阵模拟 dither 颗粒

适合：复古模式 / 怀旧副本 / 彩蛋关卡

08 森林迷雾

多层大 blur 白色雾气 + screen 混合缓慢横移；树干暗影用斜向条纹 + blur

适合：野外 / 密林 / 副本第一层

09 黄昏沙漠

紫→橙天空渐变 + radial 椭圆太阳；底部多弧 hard-stop 沙丘叠层

适合：沙漠地图 / 边境 / 落日余晖

10 魔法符文

细网格符文底纹 + conic-gradient 旋转法阵光 + 漂浮光点微光

适合：法师场景 / 召唤阵 / 高塔顶端

11 深渊虚空

中心黑洞 + conic-gradient 光带 blur 后缓慢自旋，模拟时空漩涡

适合：BOSS 位面 / 传送门 / 最终决战

12 冰封雪山

亮色天空渐变 + 雪花点阵 + 侧扫天光（唯一偏白的场景，供对比）

适合：山顶 / 雪地关卡 / 圣洁之地

13 霓虹雨夜

粉/青双色霓虹光晕 + 细斜雨丝按纹路周期平移动画，雨感循环无缝

适合：雨夜城 / 暗巷 / 氛围紧张时刻

14 晨曦金殿

金色圣光 + repeating-linear-gradient 竖条纹模拟廊柱 + 缓慢光扫

适合：神殿 / 王城 / 圣殿战斗

15 水墨山水

米白纸底 + 大 blur 灰墨晕染成远山近峦，加墨点营造笔触

适合：武侠 / 仙侠 / 诗画意境关卡

16 血色危城

深红渐变 + 微斜暗色条纹 + 顶部应急红光，脉动式警戒感

适合：战争 / 危机 / 血腥副本

17 云海之巅

亮蓝天 + 底部大 blur 白云成海 + 上层浮云缓慢漂移

适合：天空城 / 登顶时刻 / 自由开阔场景

18 水晶洞窟

青绿 + 蓝色双辉光棱柱（斜向亮线 blur）+ 微光点

适合：矿洞 / 晶石秘境 / 精灵居所

19 星轨长曝

conic-gradient 低透明度圆弧缓慢旋转，模拟相机长曝星轨

适合：观星台 / 时间流逝 / 旅途终章
