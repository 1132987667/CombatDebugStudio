# 角色监控显示设计

## 四层架构

所有属性的修饰符来源按以下四层组织：

| 层级         | 系统类型            | 说明                              |
| ------------ | ------------------- | --------------------------------- |
| **基础数值** | `base` + `ADDITIVE` | 基础值 + 固定数值加成，不含百分比 |
| **属性加成** | `PERCENTAGE`        | 百分比加成，叠乘计算中的第二乘区  |
| **独立乘区** | `MULTIPLICATIVE`    | 独立乘法，叠乘计算中的第三乘区    |
| **最终乘区** | `FINAL`             | 最终乘法，叠乘计算中的第四乘区    |

## 攻击力

攻击力为单一数值属性，统一使用 `attack`。

### 显示格式

```
基础数值            value
基础                baseValue
装备                +value

属性加成            total%
天赋                +value%
...

最终乘区            final%
```

### 修饰符标注规则

- 所有修饰符直接作用于 `attack`，无需按最小/最大拆分标注。

### 计算过程

```
base × (1 + 增幅合计%) × (1 + 独立合计%) × (1 + 最终合计%) = result
```

## 通用属性（单值属性）

非攻击力的普通属性按现有逻辑计算，显示格式：

```
基础数值            value
基础                +baseValue
装备                +value
特性                +value

属性加成            total%
天赋                +value%
...
```

## 数据层约定

- `attack` 维护单一的 `AttributeValue`（含完整的 `modifiers` 列表）
- 增幅/独立/最终乘区的修饰符按 `ModifierType`（`PERCENTAGE` / `MULTIPLICATIVE` / `FINAL`）归类
- 基础数值层包含 `base` 修饰符和所有 `ADDITIVE` 类型的修饰符
