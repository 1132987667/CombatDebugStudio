技能威力

最终攻击力

最终攻击力 × 技能倍率 × (1 + 伤害加成%)
在计算目标防御、免伤之前，攻击方打出的“全额伤害”

全额伤害/原始伤害

对敌人真正造成的伤害 实际伤害 / 最终伤害

技能基础伤害 = 倍率 × 攻击力 + Σ(属性 × ratio)

原始伤害 = 技能基础伤害 × 暴击倍率

最终伤害 = 原始伤害 - 暴击承伤减免 - 防御
× (1 - 攻击类型减免%)
× (1 - 伤害大类抗性%)
× (1 - 通用减免%)
× (1 + 易伤%)
× (1 + 伤害提升%)
× (1 + 条件加成%)
× Π(targetModifiers)
→ clamp(min, max)

你的模型（2 层）：
基础伤害 × (1 + 伤害加成%) ──→ 原始伤害 ──→ 扣血 ──→ 最终伤害

实际链路（14 步）：
① 基础威力（倍率×攻击力 + extraValues）
② 暴击倍率
③ 暴击承伤减免 ← 目标方
④ 防御（减法） ← 目标方
⑤ 攻击类型减免 ← 目标方
⑥ 伤害大类抗性 ← 目标方
⑦ 通用减免 ← 目标方
⑧ 易伤 ← 目标方
⑨ damageBoost ← 来源方
⑩ 火系/物理技能加成 ← 来源方
⑪ 低血量加成 ← 来源方
⑫ targetModifiers
⑬ 阈值钳制
⑭ 最终伤害

┌─ 来源方产出（原始伤害）─────────────────────────┐
│ 基础威力 + extraValues │
│ × 暴击倍率 │
│ × (1 + damageBoost%) │ 伤害提升
│ × (1 + fireSkillDmgBonus%) ← 来源方 │ 火系技能伤害加成  
│ × (1 + physicalSkillDmgBonus%) ← 来源方 │ 物理技能伤害加成  
│ × (1 + damageToLowHp%) ← 来源方 │ 对低生命值目标的伤害
│ = 原始伤害 (rawDamage) │
├─ 目标方减免（原始 → 最终）─────────────────────┤
│ - 暴击承伤减免 │
│ - 防御（减法） │
│ - 攻击类型减免 │
│ - 伤害大类抗性 │
│ - 通用减免（真实伤害跳过） │
│ × (1 + 易伤%) │
│ × targetModifiers │
│ → clamp │
│ = 最终伤害 (finalDamage) │
└────────────────────────────────────────────────┘


基础威力 → extraValues加成 → 暴击倍率 → 来源方加成(damageBoost/火系/物理/低血量)
→ rawDamage捕获 → 暴击承伤减免 → 防御减法 → 攻击类型减免 → 元素抗性
→ 通用免伤 → 易伤增伤 → targetModifiers → 阈值钳制 → finalDamage
