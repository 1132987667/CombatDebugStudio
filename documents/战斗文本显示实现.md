# 战斗文本显示实现

战斗过程中，攻击文本、伤害数字、治疗数字、技能名称飞字等效果的实现分布在以下文件中。

---

## 1. BattleVisualEffects.vue — 主浮层系统（全局飘字）

**路径：** `src/presentation/components/BattleVisualEffects.vue`

最核心的战斗文本展示组件，负责渲染：

| 方法 | 效果 |
|------|------|
| `showDamageNum()` | 红/橙色 `-数值` 飘字，分普通/暴击 |
| `showHealNum()` | 绿色 `+数值` 飘字 |
| `showShieldNum()` | 蓝色 `+数值` 飘字 |
| `showSkillName()` | 技能名称从攻击者飞向目标 |
| `showProjectile()` / `showImpact()` | 弹道/命中特效（非文字，但配合动画管线） |

编排方法 `playAttackSequence()` / `playHealSequence()` / `playShieldSequence()` 组合文字+弹道+命中动画。

---

## 2. ParticipantCard.vue — 每个角色独立飘字

**路径：** `src/presentation/components/ParticipantCard.vue`

每个参战者卡片维护自己的 `damageNumbers` 响应式数组，通过 CSS `@keyframes float-up` 动画驱动。`addDamageNumber()` 支持 `damage` / `heal` / `critical` / `miss` 类型。

---

## 3. DamageNumber.vue — 带伤害类型分类的飘字

**路径：** `src/presentation/components/DamageNumber.vue`

使用 Vue `<transition-group>` + CSS keyframe 动画，伤害类型分为：

- `physical_damage` — 伤害
- `elemental_damage` — 元素伤害
- `true_damage` — 真实伤害
- 子类：`combo` / `shield`

不同伤害类型有不同的颜色和图标。

---

## 4. BattleAnimationService.ts — GSAP 飘字底层服务

**路径：** `src/infrastructure/animation/BattleAnimationService.ts`

使用 GSAP 创建 DOM 元素 + 补间动画。定义的 CSS 类：

- `floating-skill-name`
- `floating-damage-text`
- `floating-miss-text`
- `floating-passive-text`

---

## 6. GsapAnimationEngine.ts — 通用 GSAP 飘字策略

**路径：** `src/infrastructure/animation/GsapAnimationEngine.ts`

`FloatingTextStrategy` 类创建 `div.floating-text`，可配置：

- `fontSize` — 字号
- `color` — 颜色
- `duration` — 动画时长
- `fadeDuration` — 淡出时长

---

## 7. AnimationElementManager.ts — DOM 对象池

**路径：** `src/infrastructure/animation/AnimationElementManager.ts`

管理 `'floating-text'` 对象池（初始 10 个，最大 50 个），避免频繁创建/销毁 DOM 导致的 GC 压力。

---

## 7. BattleField.vue — 事件分发层

**路径：** `src/presentation/views/BattleField.vue`

监听战斗事件（如 `DAMAGE_ANIMATION`），调用上述组件的 `showDamageNum()` / `addDamageNumber()` 等方法来展示战斗文本。

---
## 总结

| 文件 | 职责 |
|------|------|
| `BattleVisualEffects.vue` | 全局飘字：伤害/治疗/护盾数字 + 技能名飞字 + 弹道特效 |
| `ParticipantCard.vue` | 每个角色卡片独立的飘字 |
| `DamageNumber.vue` | 按伤害类型分类的飘字组件 |
| `BattleAnimationService.ts` | GSAP 飘字底层创建 |
| `GsapAnimationEngine.ts` | 通用 GSAP 飘字策略 |
| `AnimationElementManager.ts` | 飘字 DOM 对象池 |
| `BattleField.vue` | 事件调度入口 |
