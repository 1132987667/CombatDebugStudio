# 战斗文本显示实现

战斗过程中的攻击文本、伤害数字、治疗数字、技能名称飞字、闪避文字等效果，统一由 `BattleVisualEffects.vue` 全局浮层承担（纯 DOM + CSS 动画，无 GSAP 依赖）。GSAP 仅用于卡片的突进/震屏/辉光等非文本动画。

---

## 1. BattleVisualEffects.vue — 主浮层系统（全局飘字）

**路径：** `src/presentation/components/BattleVisualEffects.vue`

覆盖在战场上方，渲染所有战斗文本与特效。动画结束后自动清理（Vue 响应式数组 + CSS keyframe，无对象池）。

| 方法 | 效果 |
|------|------|
| `registerCard()` / `unregisterCard()` | 卡片 DOM 注册/注销，供特效层 `cardCenter()` 定位 |
| `showSkillName()` | 技能名称从攻击者飞向目标（时长 = 0→50%T） |
| `showProjectile()` / `spawnTrail()` | 光弹飞行（rAF 驱动）+ 尾迹（非文字） |
| `showImpact()` | 命中爆炸，按 `debugStore.impactStyle` 切换 explosion / slash / iceshatter / shockwave / shadow 变体 |
| `showHealAura()` / `showShieldHex()` | 治疗光环 / 护盾六边形 |
| `showDamageNum()` | 红色/橙色 `-数值` 飘字，分普通/暴击 |
| `showHealNum()` | 绿色 `+数值` 飘字 |
| `showShieldNum()` | 蓝色 `+数值` 飘字 |
| `showMissText()` | 闪避文字（固定偏移到目标右上角） |
| `showScreenShake()` | 暴击时屏幕震动 |
| `playFlightSequence()` | 编排：技能名飞字 + 光弹飞行（不包含命中） |

- 各特效时长从 `BATTLE_ANIMATION_TIMING` 相位派生，随倍速缩放
- 生命周期安全调度器（`later()` / `nextFrame()` / `setRemove()`）统一管理定时器与 rAF，卸载时全部清理

---

## 2. ParticipantCard.vue — 卡片视觉状态（不再独立飘字）

**路径：** `src/presentation/components/ParticipantCard.vue`

旧版的 `damageNumbers` 数组与 `addDamageNumber()` 已删除。现在每张卡片只负责自身的视觉状态反馈，飘字统一走全局浮层：

- `triggerVisualState()` — 施放（`casting`）/ 受击（`hurt`）/ 治疗（`healed`）/ 护盾（`shielded`）CSS 状态类
- `flashHpBar()` — 气血条闪光
- `cardRef` — 暴露给特效层用于定位

---

## 3. 伤害类型分类 — visual-effect-mapper.ts

**路径：** `src/shared/utils/visual-effect-mapper.ts`

原 `DamageNumber.vue` 已删除，其伤害类型分类逻辑集中到此映射器：

- `ImpactClass` — `fire` / `frost` / `heal` / `shield`
- `getVisualEffect(category, isHeal)` — 伤害大类（physical / elemental / true）与治疗标记 → `{ color, impactClass, projectileClass }`
- 消除 BattleField.vue 等 UI 文件中的硬编码 if-else

---

## 4. BattleAnimationService.ts — GSAP 底层服务

**路径：** `src/infrastructure/animation/BattleAnimationService.ts`

GSAP 负责的非文本动画（卡片突进、震屏、辉光），支持倍速控制与 `prefers-reduced-motion` 无障碍降级：

- `playAttackAnimation()` — 攻击方突进（windup 相位 20%T）
- `playHitAnimation()` — 受击震屏 + 血条/卡片闪光（闪避文本由 `showMissText()` 统一接管，本层不再创建）
- `playBuffAnimation()` — Buff 辉光
- `stopAllAnimations()` — 清理活动时间线与 `floating-*` 残留元素

注意：`playSkillNameAnimation` / `playDamageTextAnimation` / `playPassiveTextAnimation` 仍会创建 `floating-*` 元素，但当前 BattleField 的调用路径不触发（突进不传 skillName、受击仅在 MISS 分支不传 damage/passiveName），战斗文本一律由 BattleVisualEffects 创建；`stopAllAnimations()` 对 `floating-*` 元素的清理仅为兜底。

**封装层：** `src/presentation/composables/useBattleAnimation.ts` — Vue composable，将 `BattleAnimationService` 包装为 `playAttackAnimation()` / `playHitAnimation()` / `playBuffAnimation()` / `registerElement()` / `setBattleSpeed()` / `stopAllAnimations()`，供 BattleField.vue 使用。

---

## 5. BattleField.vue — 事件分发层

**路径：** `src/presentation/views/BattleField.vue`

固定预算模型：深监听 `store.animationState`，由领域层配速驱动，UI 按事件即时调用上述特效方法（技能 → `playAttackAnimation` + `playFlightSequence`；伤害 → `showDamageNum` + `showImpact`；治疗 → `showHealAura` + `showHealNum`；闪避 → `showMissText`；Buff → `playBuffAnimation`）。

---

## 总结

| 文件 | 职责 |
|------|------|
| `BattleVisualEffects.vue` | 全局飘字/特效：技能名、光弹、命中、伤害/治疗/护盾/闪避文字、屏幕震动 |
| `visual-effect-mapper.ts` | 伤害大类 → 视觉配置映射 |
| `ParticipantCard.vue` | 卡片视觉状态（施放/受击/治疗/护盾）与血条闪光，不再独立飘字 |
| `BattleAnimationService.ts` | GSAP 底层：突进/震屏/辉光，经 `useBattleAnimation` 封装 |
| `useBattleAnimation.ts` | Vue composable 封装层 |
| `BattleField.vue` | 事件分发与动画编排入口 |

## 已删除的旧实现

- `DamageNumber.vue` — 分类逻辑并入 `visual-effect-mapper.ts`
- `GsapAnimationEngine.ts`（`FloatingTextStrategy`）— 删除
- `AnimationElementManager.ts`（`'floating-text'` DOM 对象池）— 删除，改由 Vue 数组 + CSS 动画自动清理
- `ParticipantCard.vue` 的 `damageNumbers` / `addDamageNumber` — 删除
- `BattleAnimationService` 的 `playDeathAnimation` / `playMissTextAnimation` / `getAnimationDuration` / `getTotalAttackSequenceDuration` — 无调用方，删除
