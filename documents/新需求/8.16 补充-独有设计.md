### 十三、存档数据结构

#### 13.1 装备实例存储格式

**裁定：代码层已有定义，非缺口。**

`types.ts` 中 `GearInstance` 接口：

```typescript
interface GearInstance {
  instanceId: string
  itemId: string
  enhance: number        // 强化等级
  quality: number        // 品质（1-5）
  qualityFactor: number  // 品质系数（roll 后锁存）
  star: number           // 星级（0-3）
  affixes: GearAffix[]   // 词条数组
}
```

- 词条存储**完整词条对象**（ID + 数值），不仅存 ID。
- 强化等级存储在装备实例上。
- 装备实例不跨存档位共享（每个存档独立）。

#### 14.2 配置引用完整性

**裁定：已有检查脚本，非缺口。**

`scripts/check-craft-loop.cjs` 和 `scripts/check-items.cjs` 已实现引用完整性检查：

- 装备 `recipeId` → `cave.json` 的 `forgeRecipes.id`
- 敌人 `drops.itemId` → `items.json` 的 `id`
- 技能 `buffId` → `buffs.json` 的 `id`
- 断裂引用时报错并列出具体位置
