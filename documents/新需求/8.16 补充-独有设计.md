> **文档性质**：8.16 权威文档（《全物品文档-8.16》《新需求调整-8.16》）**未覆盖**的独有设计收录。这些内容源自此前归档删除的旧文档（《设计稿补充-物品》《设计稿补充-装备》《回答》），经评审确认不违反 8.16 裁定、且存在真实设计缺口，故单独收录保留。
> **与 8.16 的关系**：本文档仅作**补充**，不替代 8.16；凡 8.16 已有定义的需求一律以 8.16 为准。本文档列出的均为 8.16 物品清单/机制中缺失或存在空白的部分。

## 一、图纸残页 3 合 1 机制（bp_page）

**出处**：`设计稿补充-物品.md` §12.3、§12.2；`设计稿补充-装备.md`；`回答.md`

**机制**：
```text
ID：bp_page（图纸·合成素材）
获取：普通敌人低概率掉落（1%-5%）
合成：3 张残页 → 1 张完整图纸（随机该阶位）
```

**与 8.16 的关系**：8.16 第六章图纸体系只列了主线六槽图纸 / 传说 / 仙品 / 特殊图纸，**无残页物品、无 3 合 1 合成**；且 8.16 主线六槽图纸获取以「首杀必掉 + 守护者完整图纸包 + 降妖令兑换指定图纸」为主。

**定位（补充建议）**：图纸残页仅作为**普通小怪掉落的可选补充碎片**路径，用于填补主线六槽图纸的小怪掉落空白，**不作为完整图纸的核心获取方式**（核心获取以 8.16 图纸包体系为准，避免冲突）。

## 二、分解磁铁（decomp_magnet）

**出处**：`设计稿补充-物品.md` §11.4；`设计稿补充-装备.md`；`设计稿补充-装备V2.md`；`回答.md`

**机制**：
```text
ID：decomp_magnet（分解辅助道具）
效果：分解装备时额外获得 1 个材料
来源：商店、任务
```

**与 8.16 的关系**：8.16 功能道具仅定义「分解锤 decomp_hammer」（返还 50% 制造材料），**无「额外 +1 材料」的分解磁铁**。属独立增强道具，无等价物，不冲突。

## 三、幸运值掉落保底

**出处**：`设计稿补充-物品.md` §7.3「保底与幸运值」

**机制**：
```text
每次未获得关键图纸/晶球 → 幸运值 +1
幸运值满 5 时 → 下次必掉对应物品
幸运值按关卡/敌人类型独立计算
```

**与 8.16 的关系**：8.16 的防 RNG 兜底集中在两处——制造侧品质保底（§8.4.3，超品 5/绝品 10/神品 20 次）与降妖令兑换（§11.2）。但**降妖令只来自 BOSS 重复挑战**（主线 BOSS 重复不产出），**普通小怪 / 守护者的关键晶球与图纸掉落没有任何计数保底**——幸运值机制恰好覆盖这一空白，不可被降妖令完全替代。

## 四、附魔精华 / 附魔失败保底（ench_essence）

**出处**：`回答.md` §4.1、§4.2

**机制**：
```text
ID：ench_essence（附魔辅助道具）
效果：附魔失败时保底材料，累积 3 次必成
来源：分解附魔装备
```

**与 8.16 的关系**：8.16 §5 附魔系统定义附魔成功率 70%、附魔锁定石降为 50%，但**无「累积必成」的失败保底**；8.16 附魔材料仅有附魔粉（毒液/寒霜/烈焰）与附魔封存符，无 ench_essence。属 8.16 附魔系统的真实缺口。
> 注：`附魔锁定石（ench_lock）` 8.16 §5 已有对应定义（锁定时成功率降至 50%），不在本文档收录范围。

## 五、特殊材料用途补全（铁焰矿 / 金阳矿 / 神泉水）

**出处**：`设计稿补充-物品.md` §10.4「特殊材料用途补全」

**机制**：
```text
铁焰矿（mat_tieyan）  → 火属性武器强化石 / 定向洗练媒介（碎石岭）
金阳矿（mat_jinyang） → 阳属性靴子（速度）/ 戒指（暴击）材料（金风岭）
神泉水（mat_shenquan）→ 神泉金丹 / 高级恢复丹（隐藏 BOSS）
```

**与 8.16 的关系**：`铁焰矿 / 金阳矿 / 神泉水` 在 8.16 两份文档中**均无物品 ID 注册、无用途定义**（神泉水完全未出现；铁焰矿/金阳矿仅在词条权重说明中作为名词提及）。
> 注：`寒潭水 / 珍珠 / 毒液` 的用途 8.16 已覆盖（定向洗练 / 二阶护符 / 碧瘴灵液），不在本文档收录范围。
