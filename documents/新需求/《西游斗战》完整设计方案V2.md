## 第一章 · 背景故事与叙事

### 1.1 世界观设定

```text
一千年前，孙悟空以金箍棒镇压六耳猕猴于五行山下。
六耳猕猴肉身消亡，但残魂碎片散落在西行路上。
碎片渗透山川河流，感染万物——妖怪接触到碎片后，被"感染"，获得异常力量。
感染越深，词缀越强。
一千年后，西行路上妖气再起。
```

### 1.2 主角设定

```text
主角是五行山脚下村庄的一个小猴子。
不是天选之子，不是转世灵童。
只是一个"跑得快"的小猴子，被村中老猴看中，传授了第一招。
主角与六耳猕猴是镜像关系：
  · 六耳猕猴是"听"的极致——听万物之声。
  · 主角是"跑"的极致——跑万物之路。
  · 六耳猕猴听遍了世间，却听不见自己的心。
  · 主角跑遍了世间，最终要跑回自己的心。
```

### 1.3 镜像关系与结局对话

```text
最终 BOSS（六耳猕猴）战前对话：
  "你跑了一千里，可曾听见自己的脚步声？"
  "我听了千年，只听见一片寂静。"

最终 BOSS 战后对话（击败后）：
  "原来……脚步声里，藏着心跳。"
  "谢谢你，让我终于听见了。"

设计意图：
  · 六耳猕猴代表"知"的极端——知道一切，却感受不到。
  · 主角代表"行"的极端——跑过一切，却未必理解。
  · 结局是"知行合一"——跑与听，最终是同一件事。
```

### 2.2 词缀的叙事绑定

```text
词缀 = 妖气烙印。
六耳猕猴的残魂碎片散落在西行路上。
妖怪接触到碎片后，被"感染"，获得异常力量。
感染越深，词缀越强。

UI 表现：
  · 带词缀的敌人名字旁有一个墨点（轻度感染）
  · 三档/四档词缀怪的墨点变为朱红印章（深度感染）
  · 击败后战斗心经记录："妖气消散，[敌人名] 恢复清明。"
```

```text
五行克制矩阵是「天赋」——阵营克制系数。
五行抗性是「修行」——词缀修正的抗性层。
两者并存：火克木是天理（克制矩阵），但木阵营敌人可以堆 fireRes 反制（五行抗性词缀）。
「克制是天赋，抗性是修行。」
```

## 第三章 · 回合结算轴与能量节奏

### 3.1 回合结算轴（Phase）

每回合结算按以下固定顺序执行，不可跳步：

```text
Phase 1 · 回合开始
  ├── 回合开始触发（ON_TURN_START 被动）
  ├── 能量回复（每回合 +25，受击 +15）
  ├── Buff 回合递减（duration -1，到期移除）
  └── 控制状态判定（眩晕/冰冻 → 跳过行动）

Phase 2 · 行动选择
  ├── AI 决策 / 玩家手动选择
  ├── 技能可用性判定（能量/冷却/控制/沉默）
  └── 目标选择（单体/群体/自身）

Phase 3 · 技能执行
  ├── 技能步骤编排（deal_damage / heal / apply_buff / dispel）
  ├── 多段攻击逐段结算
  └── 连击判定（comboRate 触发追加段）

Phase 4 · 伤害结算
  ├── 14 步伤害链路（详见《设计稿补充-战斗.md》）
  ├── 暴击判定
  ├── 格挡判定
  ├── 闪避判定
  └── 最终伤害写入 HP

Phase 5 · 结算后触发
  ├── 反击判定（counterRate）
  ├── 吸血结算（lifestealRate）
  ├── 反弹伤害（reflectDamagePercent）
  ├── 斩杀判定（目标 HP ≤ 斩杀线 → 触发斩杀返还）
  ├── ON_DAMAGE_TAKEN / ON_ATTACK_LANDED 被动
  └── 能量获取（受击 +15）

Phase 6 · 回合结束
  ├── 回合结束触发（ON_TURN_END 被动）
  ├── 死亡判定与移除
  ├── 召唤物行动（若有）
  └── 胜负判定
```

### 3.2 斩杀返还机制

```text
斩杀条件：
  · 目标当前 HP ≤ 斩杀线（默认 15% 最大 HP）
  · 攻击方拥有「斩杀」词条或技能效果

斩杀效果：
  · 目标立即死亡（无视护盾/免死）
  · 攻击方返还 30% 本次技能能量消耗
  · 攻击方获得 1 层「杀意」（攻击力 +5%，最多 3 层，持续 2 回合）

设计意图：
  · 鼓励玩家集火残血目标
  · 为连击/多段攻击提供正反馈
  · 斩杀返还让大招后仍有能量释放小技能
```

### 3.3 流派能量节奏差异化

| 流派 | 能量获取特点 | 大招节奏 | 设计意图 |
|------|-------------|----------|----------|
| **灵猴道** | 连击触发额外能量（每次连击 +5）；攻速快，普攻频率高 | 大招频率中等（每 4-5 回合） | 高频小技能循环，大招作为爆发窗口 |
| **金行道** | 暴击触发额外能量（暴击 +10）；普攻能量标准 | 大招频率低（每 6-7 回合） | 攒暴击一击必杀，大招是核心输出 |
| **磐石道** | 受击触发额外能量（受击 +15 → +20）；格挡触发额外能量（格挡 +10） | 大招频率高（每 3-4 回合） | 挨打攒能量，大招是防御反击 |

### 3.4 能量数值定稿

```text
能量上限：150（固定，不随等级成长）
初始能量：25
每回合恢复：+25
受击恢复：+15
连击额外恢复（灵猴道）：+5/次
暴击额外恢复（金行道）：+10/次
格挡额外恢复（磐石道）：+10/次

小技能消耗：50 能量
小技能冷却：2-3 回合
大招消耗：150 能量
大招冷却：5 回合
普攻消耗：0 能量（回复 +10）
```

## 第四章 · 核心循环与系统架构

### 4.1 核心循环图

```text
战斗（刷取材料/图纸/降妖令）
  ↓
制造（洞府打造装备）
  ↓
穿戴（6 槽 + 法宝/神器）
  ↓
强化/洗练/升星（深度养成）
  ↓
挑战更强敌人（解锁新关卡/新难度）
  ↓
回到战斗（循环）
```

### 4.2 设计红线

```text
1. 不引入装备等级需求（无 Lv.X 才能穿戴）。
2. 数值控制在 10000 以内，避免后期膨胀。
3. 所有操作必须与现有材料、晶球、灵气、特殊掉落形成关联。
4. 制造仍是核心获取方式，BOSS 掉落作为补充和追求。
5. 法宝/神器不占装备槽位，为独立类型。
6. 五行攻击已删除（设计决策 D1b），统一为五行抗性。
```

### 4.3 装备槽位体系（v2.0 定稿）

```text
六类槽位：武器 / 衣服 / 头盔 / 靴子 / 护符 / 戒指
两大独立类型：法宝 / 神器

槽位迁移：
  项链 → 头盔（防御百分比）
  冠冕 → 头盔（全属性百分比）
  腰带 → 靴子（速度百分比）
  手镯 → 戒指（暴击率）
```

### 5.1 装备品级四维度

| 维度 | 作用 | 主要来源 |
|------|------|----------|

## 第七章 · 资源闭环与经济回收

### 7.1 资源闭环总图

```text
┌─────────────────────────────────────────────────────────┐
│                    资源产出端                            │
│  普通小怪 → 基础材料（桃木/粗石/铜精...）              │
│  守护者 → 晶球/图纸/稀有材料                           │
│  BOSS → 灵气/降妖令/专属材料                           │
│  隐藏BOSS → 天罡灵气/异化材料                          │
└───────────────────────┬─────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│                    资源消耗端（黑洞）                    │
│                                                         │
│  强化黑洞：晶球 + 金钱（持续消耗，永不饱和）           │
│  洗练黑洞：寒潭水 + 天罡灵气（超品装备优化）           │
│  重铸黑洞：混元灵气（终局完美词条追求）                │
```

### 7.2 强化黑洞设计

```text
设计意图：强化是最稳定的长线消耗，保证晶球和金钱永远有去处。

消耗结构：
  · 一阶装备：20 × 强化等级 金钱 + 一阶晶球
  · 二阶装备：50 × 强化等级 金钱 + 二阶晶球
  · 三阶装备：100 × 强化等级 金钱 + 三阶晶球
  · 天品装备：150 × 强化等级 金钱 + 三阶晶球
  · 仙品装备：200 × 强化等级 金钱 + 混元灵气

总消耗估算（单件装备从 +0 到满强化）：
  · 凡品（+5）：约 300 金钱 + 5 个一阶晶球
  · 玄品（+10）：约 2,750 金钱 + 10 个二阶晶球
  · 地品（+15）：约 12,000 金钱 + 15 个三阶晶球
  · 天品（+15）：约 18,000 金钱 + 15 个三阶晶球
  · 仙品（+20）：约 42,000 金钱 + 20 个混元灵气

6 件装备全部满强化（地品）：约 72,000 金钱 + 90 个三阶晶球
→ 这是中期（关卡 5-8）的核心消耗目标。
```

### 7.3 洗练黑洞设计

```text
设计意图：洗练是超品装备的优化手段，消耗稀有材料，形成"刷-洗-再刷"循环。

消耗结构：
  · 普通洗练：寒潭水 ×1（高频消耗）
  · 定向洗练：寒潭水 ×2 + 特殊材料 ×1（中频）
  · 锁词条洗练：天罡灵气碎片 ×3 + 寒潭水 ×3（低频）
  · 绝品洗练：天命洗炼符 ×1（三大 BOSS 掉落，极低频）
  · 神品洗练：天命洗炼符 ×1（最终 BOSS 掉落，极低频）

寒潭水消耗估算：
  · 一件装备从 3 词条洗到满意：约 10-20 次洗练
  · 6 件装备全部洗练：约 60-120 个寒潭水
  → 这是后期（关卡 7-10）的核心刷取目标。
```

## 第十五章 · 一句话总结

> 《西游斗战》是一款以「制造-穿戴-刷取-成长」为核心循环的西游题材回合制 RPG。六耳猕猴的残魂碎片感染了西行路上的万物，词缀是「妖气烙印」，装备词条是「器魂」，两者独立运作。主角是一个"跑得快"的小猴子，与六耳猕猴互为镜像——一个听遍世间却听不见心跳，一个跑遍世间最终要跑回自己的心。6 槽装备体系承载 Build 多样性，法宝/神器作为独立成长线提供终局追求。强化是黑洞，洗练是黑洞，丹药有上限，降妖令兜底消除 RNG 挫败。斩杀返还让大招后仍有能量释放小技能，三流派能量节奏差异化让每个流派都有独特手感。所有数值控制在 10000 以内，不引入装备等级需求，制造始终是核心获取方式。
