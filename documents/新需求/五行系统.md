## 1. 系统定位

五行是战前 BUILD 的一环（流派、站位、五行、AI规则）。

核心关键词：五行克制。

## 2. 核心机制：双轨附加制

```text
总伤害 = 物理伤害部分 + 五行附加伤害部分
```

### 五行附加公式

```text
五行附加伤害 = 技能基础伤害 × 五行攻击% × (1 - 五行抗性%) × (1 + 五行易伤%)
```

### 规则

| 规则 | 说明 |
|---|---|
| 五行附加伤害默认不暴击 | 防止乘区失控 |
| 五行附加伤害不触发连击 | 防止行动次数失控 |
| 五行附加伤害可触发五行异常 | 火、水、金、木、土对应异常 |
| 五行抗性独立生效 | 不受物理减免影响 |

## 3. 五行分支

每个流派可选择一种五行分支。

| 五行 | 作用 |
|---|---|
| 火 | 附加灼烧 |
| 水 | 附加减速 |
| 金 | 附加破甲 |
| 木 | 附加禁疗/缠绕 |
| 土 | 附加护盾/重压 |

## 4. 五行属性

属性类别 E - 五行属性（共2个）：

| 层级 | 属性 |
| :--: | :-- |
| L1 | 五行攻击%、五行抗性% |

## 5. 相关系统设计

### 5.1 站位

- 后排仇恨低，受伤降低，适合输出/五行/干扰
- 后排：仇恨-30，受到伤害-10%，远程/五行伤害+5%

### 5.2 宠物

定位：输出、异常、五行；含五行补充。

属性类别：E 五行属性 - 是，五行攻击、五行抗性。

五行系宠物独立被动示例：

| 宠物 | 独立被动 |
|---|---|
| 火系输出宠 | 攻击灼烧目标时，伤害独立+8% |
| 金系破甲宠 | 攻击防御高于自身目标时，伤害独立+10% |
| 水系控制宠 | 对速度高于自身目标，控制成功率+6% |
| 木系辅助宠 | 回合结束时若自身气血低于50%，回复最大气血6% |
| 土系守护宠 | 护盾存在时，免伤独立+6% |

### 5.3 坐骑

属性类别：E 五行属性 - 少量，可作为抗性来源。

五行系坐骑示例：

| 坐骑 | 独立被动 |
|---|---|
| 火麒麟 | 攻击时若目标有灼烧，伤害独立+6% |

### 5.4 天赋

天赋树分支建议含五行方向：

| 天赋分支 | 核心属性 | 适合流派 |
|---|---|---|
| 五行 | E、B | 五行输出、异常 |
