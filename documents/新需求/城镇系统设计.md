# 城镇系统设计（一域一城 · NPC 与操作详设）

> 立项锚点：《完整项目说明.md》「一域一城（2026-09-18 立项）」L2011-2023、§32 洞府/功能枢纽、附录A 十/十一（药园/坊市经济）。
> 本文回答三个问题：城镇怎么进入、里面有哪些 NPC、每个 NPC 能做什么操作。
> 上游裁定沿用：迷踪秘境与最终决战地不设城；货币仅金钱+灵韵两种；草药首株由掉落获得、无种子体系；坊市两层货架 + 每日轮换。

---

## 1. 设计定位

城镇是每域的**休整与功能枢纽**，在"变强 → 验证 → 碾压 → 再变强"主循环中扮演两个角色：

1. **变强的补给站**——打完前两关抵达城镇，补给（坊市）、打造强化（匠铺）、种药炼丹（药圃），
   把战斗产出转化为下一轮战力；
2. **叙事的落脚点**——五城各有主题与居民，承担区域剧情钩子、委托发布、情报传闻，
   让"刷关卡"之间有呼吸感，不做模拟经营（好感度/城建/居民满意度均不做）。

### 1.1 三条设计总原则

| 原则 | 含义 | 反例（不做） |
| ---- | ---- | ---- |
| 功能叙事化 | 宝阁已有的系统（坊市/洞府/历练）不重造，城镇 NPC 是它们的**叙事入口**，点 NPC 即跳转对应面板 | 为城镇另写一套商店/打造逻辑 |
| 五城差异化 | 每城通用 NPC 之外，必有 1~2 个**独占 NPC/独占货单**，与城市主题（desc）强绑定 | 五城长一个样，只换名字 |
| 数值不加体系 | 城镇只消费现有货币（金钱/灵韵）与现有材料/道具 id，新引入内容仅限"委托条目、货单条目、对话文本"这类数据 | 新货币、新属性、好感度数值 |

### 1.2 与现有系统的边界

| 功能 | 已实现位置 | 城镇做什么 |
| ---- | ---- | ---- |
| 坊市买卖 | PackPanel 坊市页签（packStore：常售+轮换8件，买入×2.0 卖出×0.56） | 坊市管事 NPC 入口；分城货单池 |
| 打造/强化/升星/洗练/符箓 | CavePanel forge/enhance/star/wash/talisman | 匠人 NPC 入口 |
| 药园/炼丹 | CavePanel garden/alchemy（灵韵催熟，6 灵田） | 药圃主 NPC 入口；首株灵草引导 |
| 任务/活动 | QuestPanel（quest.json：主线/日常/周常） | 告示板 NPC；新增城镇委托子类 |
| 降妖塔/收集/修行/装备 | TowerPanel/CollectPanel/CultivatePanel/EquipPanel | **不进城镇**（保持宝阁直达），仅在情报传闻中给线索 |
| 城镇弹窗壳 | TownDialog.vue（坊市/打造/药园三设施"未开放"占位） | 本文的落地主体：升级为 NPC 名录街景 |

## 2. 城镇进入与解锁

### 2.1 入口（已实现）

降妖路引两处城镇节点，点击进入：

- 侧栏路引时间线：城镇节点渲染在**每域第二个小场景之后**（出阵历练两场后抵达城镇休整）；
- 大地图弹窗：城镇通栏横贯列表第二行之后，金色描边。

### 2.2 解锁规则（新增裁定）

| 规则 | 内容 |
| ---- | ---- |
| 城镇开放条件 | 该域**首个场景解锁**即开放城镇（syncSceneUnlocks 逻辑已有"无前置 sceneId 默认解锁"，桃源镇开局可用） |
| 城镇节点视觉 | 未开放时降灰 + 锁形标记（与未解锁关卡同语义）；开放后金色 |
| 无城区域 | 迷踪秘境、最终决战地不渲染城镇节点（数据本就无 city 字段，代码已按 `region.city` 判空） |
| 存档 | 城镇开放状态由场景解锁状态派生，不单独存档 |

### 2.3 界面结构：从"设施清单"到"街景名录"

TownDialog 升级为两段式：

```
┌─────────────────────────────────────┐
│ 城镇  桃源镇            [×]          │
│ 落桃原 · 桃林初劫                    │
│ 「桃林边缘的小镇，主角的村庄就在镇外…」│
├─────────────────────────────────────┤
│ 街上的人                            │
│ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐    │
│ │周里正│ │钱货郎│ │鲁小锤│ │陶药娘│ …  │
│ │告示板│ │坊市  │ │匠铺  │ │药圃  │    │
│ └─────┘ └─────┘ └─────┘ └─────┘    │
├─────────────────────────────────────┤
│（点选 NPC 后）对话气泡 + [前往功能]   │
└─────────────────────────────────────┘
```

- NPC 卡片：名字 + 称号（功能角色）+ 一句 greeting；未解锁的 NPC 显示剪影与解锁条件。
- 点 NPC 展开对话气泡（greeting + 功能说明），气泡内按钮跳转：
  - 打开对应宝阁面板（坊市→PackPanel shop 页签、匠人→CavePanel 对应页签、告示板→QuestPanel），
    城镇弹窗保持开启，宝阁以功能态全屏呈现（沿用 activeCabinet 机制），返回即回到城镇；
  - 独占玩法（委托交付/情报购买等）在气泡内直接完成，不跳转。

## 4. 核心操作详设

### 4.1 坊市买卖（通用，全城差异在货单池）

复用 packStore 全部规则：常售层（疗伤丹/元气丹/强化石/洗练石）+ 每日轮换层（随机 8 件，跨天刷新，
限量商品库存重置 1-5）+ 进度解锁商品挂常售层；买入价 = 价值×2.0、卖出价 = 价值×0.56
（系数可经封神榜 economy_ratios 调参）。

**分城货单**（本文新增的数据裁定）：轮换层抽取时按"城市所在域"加权：

- 抽取池 = 全局池；本域 `resourceTheme` 特产材料与低阶图纸权重 ×3，他域特产权重 ×0.5；
- 江都城商会总管（独占）：轮换层扩容至 12 件，且稀有池（bp_t2 及以上图纸、灵尘、wash_/enh_ 石）
  权重 ×2——体现"古渡商旅枢纽"定位；
- 净域城知客僧（独占）：固定货架追加终局消耗品（高阶丹药、break_ 突破丹补给）；
- 听风城夜市货郎（独占）：第二货架，见 §4.5。

### 4.2 匠人五项操作（通用，全走洞府面板）

打造（bp_ 图纸解锁配方 → 材料+金钱 → 品质随机+保底）、强化（enh_ 强化石+金钱）、
升星（star_ 残魂）、洗练（wash_ 材料）、炼符（talismanRecipes）。城镇层不加成数值，
只在台词与门面上做城差（镇岳城炉火不熄、桃源镇学徒铺寒酸）。

### 4.3 药圃（通用）

种植/灵韵催熟/收获/炼丹全走 CavePanel garden/alchemy（6 灵田，田块扩容按附录A 药田升级表）。
城镇层新增一件事：**每城药圃主一次性赠予本域首株灵草**（该草未拥有过时才触发），
补"草药首株由掉落获得（4%→1%）"的容错——纯非酋玩家也有稳定起点。

### 4.4 告示板·城镇委托（新增 quest 子类，走历练面板）

quest.json 新增 `kind: "town"` 委托条目，每域 6 条（随城镇开放逐条出现），三类形态：

| 形态 | 目标 | 奖励 | 示例 |
| ---- | ---- | ---- | ---- |
| 讨伐 | 通关指定关卡 N 次（复用通关计数） | 金钱 + 本域特产材料 | 「桃林野猪患：讨伐落英坡 2 次」 |
| 采收 | 拥有过指定材料 ×N（不清耗） | 金钱 | 「急购桃木 ×10」 |
| 器成 | 拥有过指定品质装备/丹药 | 金钱 + bp_/enh_ 石 | 「替学徒打一件凡品武器」 |

裁定：委托**不占用日常/周常槽**、不互相排斥；奖励与既有日常任务同量级（金钱 30~150/条）。
镇岳城矿监委托是讨伐类的主题变体（目标锁定矿道关，额外给矿材加倍 flag，战斗内生效一次）。

### 4.5 情报与夜市（听风城独占）

- **耳翁情报屋**：花钱买线索（80~300 金/条），内容为文案提示 + 目标解锁指引：
  妖王挑战巢穴位置、降妖塔隐藏层传闻、迷踪秘境入口。线索购买后计入收集·成就
  （"听风辨位"系列），不直接开锁——开锁条件仍是既有玩法条件，情报只负责"告诉你去哪"。
- **夜市货郎**：完成听风城全部 6 条委托后解锁。第二货架卖高阶词条材料与 wash_ 石，
  价格 ×1.2（稀缺溢价），每日轮换 4 件。"入夜熄灯"叙事转化为夜市限定感，不做时辰系统。

### 4.6 净域城独占：藏经阁参悟

六技艺（cave.json crafts）任一达到 5 级后，可花 2000 金购买"参悟 buff"：
该技艺经验获取 ×2，持续至技艺满级（一次性消耗品语义，每种技艺仅可买一次）。
终局收敛手段，把 10 级技艺的长肝度削掉一截，符合"轻肝度"定位。

### 4.7 驿站（江都城老船家 → 全局）

- 江都城"疏浚航路"一次性工程：捐 1500 金 + 沉船河掉落材料×若干 → 解锁驿站网；
- 驿站网开启后，大地图各域页签的城镇节点旁出现"直达"标记（已开放的城可点击直接跳转当前场景
  所在域的城镇，无需该域场景解锁链）；
- 裁定：驿站只省"回到城镇的路"，不跨过场景解锁链——战斗进度仍由关卡链驱动。

### 4.8 客栈（通用）

歇脚：无数值效果（主循环结算期已自动回血），台词化提示"行囊已收拾妥当（进度已自动记录）"；
附带功能：出售回城卷轴 scroll_town（30 金，附录B 已有道具）。听风城客栈掌柜台词兼任
"入夜闭门"的世界观演出。

## 6. 数据结构建议（configs 层）

### 6.1 regions.json 的 city 扩展（向后兼容，字段全可选）

```json
"city": {
  "id": "city_taoyuan",
  "name": "桃源镇",
  "desc": "桃林边缘的小镇……",
  "npcs": [
    {
      "id": "npc_taoyuan_lizheng",
      "name": "周里正",
      "title": "告示板",
      "role": "quest",
      "greeting": "西行的？路引给我瞧瞧……好，前头两关打完再来，镇上给你备了行装。",
      "unlock": { "type": "none" }
    },
    {
      "id": "npc_taoyuan_hunter",
      "name": "老猎户",
      "title": "妖情窥探",
      "role": "special:scout",
      "greeting": "桃林里的东西，我闭着眼都数得清。",
      "unlock": { "type": "scene_cleared", "sceneId": "scene_1_2" }
    }
  ]
}
```

- `role` 枚举：`shop` / `forge` / `garden` / `quest` / `inn` / `special:scout|night_market|...`；
  `role` 决定点开后跳哪个面板（宝阁页签映射写死在表现层映射表）。
- `unlock.type`：`none` / `player_level` / `scene_cleared`；未解锁显示剪影+条件文案。

### 6.2 货单分城（最小做法）

`configs/xiyou/pack.json` 的 `shopGoods` 条目增加可选字段 `cityWeight`：
`{ "city": "city_jiangdu", "weight": 2 }` 数组；缺省 = 全城基础权重。不改 packStore 抽取结构，
只改权重读取。夜市/佛国补给等独占货架独立成 `stalls` 数组（`{ id, cityId, unlock, goods[] }`）。

### 6.3 委托条目（quest.json）

```json
{ "id": "townq_zhenyue_01", "kind": "town", "cityId": "city_zhenyue",
  "type": "hunt", "target": { "sceneId": "scene_3_2", "count": 2 },
  "reward": { "money": 120, "items": [{ "itemId": "mat_tongjing", "count": 3 }] },
  "title": "矿道清障", "desc": "矿道里又闹妖了……" }
```

## 8. 风险与校验清单

1. **经济回收口放大**：分城货单+委托奖励会提高金钱产出，落地后重跑附录A §11 收支平衡表
   （历史：产出139 < 消耗161，健康状态不可倒挂）。
2. **入口双轨一致性**：城镇 NPC 与宝阁直达操作的是同一 store 状态，不存在"城镇价"与"宝阁价"两套数值；
   买入/卖出系数仍走 packStore 单源。
3. **节点语义**：城镇节点可点击后，与"关卡节点"的视觉区分必须保持（金色/方框 vs 圆点），
   避免玩家误以为进城会消耗路引次数。
4. **编码**：本文档与后续相关文档均须 UTF-8 带 BOM（见 AGENTS.md）。
