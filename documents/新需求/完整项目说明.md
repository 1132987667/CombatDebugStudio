# 《斗战西游》项目说明PRD（简洁版）

## 1. 项目概述

平台：PC 商业化：免费单机  
《斗战西游》是一款单机自动战斗回合制RPG。  
玩家通过战前阵容、流派、站位、AI规则构建BUILD，战斗自动进行。

核心体验：

```text
变强 → 验证 → 碾压 → 再变强
```

核心关键词：

- 速度排序
- 自动战斗
- 4v4
- 流派BUILD
- 轻策略
- 爽感成长

---

## 2. 设计目标

| 目标       | 说明                            |
| ---------- | ------------------------------- |
| 战斗爽感   | 玩家成长后能明显感受到碾压      |
| 轻策略     | 策略主要体现在战前BUILD与AI设置 |
| 轻肝度     | 可刷装备/材料，但不强制重复日常 |
| 无运营压力 | 不做日活、留存、KPI、付费设计   |
| 数值可控   | 后期避免无限膨胀                |

---

## 3. 非目标

| 非目标     | 说明                    |
| ---------- | ----------------------- |
| 强PVP      | 不做实时PVP             |
| 重操作战斗 | 不做手动指令微操        |
| 重度日常   | 不做每日任务/活跃度系统 |
| 抽卡付费   | 不做商业抽卡            |
| 复杂战棋   | 不做走格战棋            |

---

## 4. 核心游戏循环

```text
战前配置
→ 自动战斗
→ 获得经验/金钱/材料/装备
→ 强化/突破/加点/调整流派
→ 挑战更高层级
→ 碾压旧内容
```

---

## 5. 战斗基础规则

| 规则     | 设定                     |
| -------- | ------------------------ |
| 战斗形式 | 4v4                      |
| 行动方式 | 自动战斗                 |
| 行动顺序 | 速度高者先行动           |
| 回合规则 | 每轮全体行动一次         |
| 胜负条件 | 一方全部单位死亡         |
| 站位结构 | 2x2，前排2人，后排2人    |
| 策略入口 | 流派、站位、AI目标优先级 |

## 6. 站位系统

采用 **2x2站位**。

```text
[前排左] [前排右]
[后排左] [后排右]
```

### 基础规则

| 规则     | 说明                                         |
| -------- | -------------------------------------------- |
| 前排     | 仇恨高，优先被攻击，适合承伤/反伤/近战       |
| 后排     | 仇恨低，受伤降低，适合输出/干扰              |
| 同列保护 | 前排存活时，保护同列后排不被普通近战直接攻击 |
| 暴露     | 某列前排死亡后，该列后排可被攻击且受伤提高   |
| 列攻击   | 可同时攻击一列前后排                         |
| 切后     | 特殊技能可无视前排保护攻击后排               |

### 站位修正建议

| 位置       | 效果                                 |
| ---------- | ------------------------------------ |
| 前排       | 仇恨+50，受到伤害+10%，护盾/反伤+10% |
| 后排       | 仇恨-30，受到伤害-10%，远程伤害+5%   |
| 后排被切后 | 受到伤害+15%                         |
| 暴露后排   | 受到伤害+15%，仇恨+30                |

## 7. 流派系统

首发四大主战流派：

| 流派            | 定位          | 核心机制               |
| --------------- | ------------- | ---------------------- |
| 斗战·连击流     | 高频输出/削甲 | 连击、风势、裂甲       |
| 破军·暴伤流     | 爆发/斩杀     | 暴击、破绽、斩杀、破盾 |
| 不动·护盾反伤流 | 承伤/反伤     | 护盾、嘲讽、反伤、怒目 |
| 幻影·闪避流     | 闪避/反击     | 残影、影袭、致盲、反击 |

### 队伍职责

先手削弱
主要输出
承伤反制
干扰收割
弱点打击

如:
先手挂异常
先手破甲
先手斩杀
后手反制
回合节奏控制

### 流派克制关系

```text
暴伤流 克 护盾反伤流
护盾反伤流 克 连击流
连击流 克 闪避流
闪避流 克 暴伤流
```

## 11. 伤害公式

### 技能基础伤害

```text
技能基础伤害 = 技能倍率 × 攻击力
```

普攻倍率：

```text
普攻倍率 = 1
```

### 原始伤害

```text
原始伤害 = 技能基础伤害 × 暴击倍率
```

暴击倍率：

```text
暴击时 = 攻击方暴击伤害% - 防御方暴伤减免%（最低100%）
未暴击 = 100%
```

### 最终伤害

```text
最终伤害 =
max(1, 原始伤害 - 防御)
× (1 - 攻击类型减免%)
× (1 - 伤害大类抗性%)
× (1 - 通用减免%)
× (1 + 易伤%)
× (1 + 伤害提升%)
× (1 + 条件加成%)
× 目标修正
```

最终伤害最低为1。

## 12. 命中与闪避

### 基础命中率

```text
计算命中率 = 命中值 / (命中值 + 闪避值)
```

### 实际命中率

```text
实际命中率 = clamp(计算命中率 + 命中率 - 闪避率, 10%, 95%)
```

规则：

| 规则       | 数值 |
| ---------- | ---: |
| 最低命中率 |  10% |
| 最高命中率 |  95% |

## 13. 暴击规则

```text
实际暴击率 = clamp(暴击率 - 暴击抵抗%, 0%, 100%)
```

暴击率可超过100%。

### 暴击溢出规则

```text
溢出暴击率 = max(0, 暴击率 - 100%)
每1%溢出暴击率 = 0.6%暴击伤害
溢出转化上限 = +50%暴击伤害
```

## 14. 连击规则

连击发生在同一次行动内，不额外占用回合。

### 连击判定

| 当前连击率   | 规则                                   |
| ------------ | -------------------------------------- |
| 大于100%     | 必定连击，连击后减少50点固定连击率     |
| 小于等于100% | 按当前概率判定，若连击成功，连击率减半 |
| 未触发连击   | 连击结束                               |

## 15. 反击、吸血、反伤

### 反击

```text
反击率判定通过后触发反击
```

规则：

| 规则               | 说明         |
| ------------------ | ------------ |
| 反击不占用行动回合 | 属于受击响应 |
| 反击可暴击         | 是           |
| 反击不可连击       | 是           |
| 每回合反击次数上限 | 2~3次        |

### 吸血

```text
吸血量 = 造成伤害 × 吸血率%
```

### 反伤

```text
反伤伤害 = 护盾吸收前受到伤害 × 伤害反弹% + 防御 × 0.6
```

规则：

| 规则                   | 说明 |
| ---------------------- | ---- |
| 反伤基于护盾吸收前伤害 | 是   |
| 反伤不能暴击           | 是   |
| 反伤不能连击           | 是   |
| 反伤不能吸血           | 是   |
| 伤害反弹上限           | 60%  |

护盾值 = 最大气血 × 25% + 防御 × 300%

## 21. 装备系统

不能出现：
武器可以洗免伤
护甲可以洗暴击
脚部可以洗暴伤
护符可以洗防御

装备属性由 属性组A + 属性组B 组成。

属性组A = 1 主要属性 + 2特定属性
属性组B = 词条数量由装备品质决定

### 装备属性数值公式

核心属性中的基础属性 与 附加属性中的基础属性，**权重为 2:1**。
全部装备属性权重之和 = 3 × 6 = 18（每部位：核心 2 + 附加 1；共 6 个基础部位）。

单位基数 = 等级默认总属性点 900 ÷ 6 部位 ÷ 3 权重和 ÷ 满级 50 = **1**。

```
装备属性值 = 单位基数 × 装备等级 × 属性权重 × 品阶权重 × 属性转化系数
           = 1 × 等级 × (核心 2 / 附加 1) × 品阶权重 × 转化系数
浮动范围 = 50% ~ 110%
```

示例：**10 级仙品剑**
- 核心属性为攻击：`1 × 10 × 2(核心权重) × 1.0(品阶权重) × 2(攻击转化) = 40`，浮动 **[20, 44]**
- 附加属性 1 为命中：`1 × 10 × 1(附加权重) × 1.0(品阶权重) × 2(命中转化) = 20`，浮动 **[10, 22]**

> 品阶权重取 §21 装备品阶表区间：仙品 0.9~1.0（示例取 1.0）；转化系数 = 属性点转化（1 属性点 = 12 气血 = 2 攻击 = 2 防御 = 2 命中 = 2 闪避 = 2 速度）。
