# 《斗战西游》项目说明PRD（简洁版）

## 1. 项目概述
平台：PC   商业化：免费单机  
《斗战西游》是一款单机自动战斗回合制RPG。  
玩家通过战前阵容、流派、站位、五行、AI规则构建BUILD，战斗自动进行。

核心体验：

```text
变强 → 验证 → 碾压 → 再变强
```

核心关键词：

- 速度排序
- 自动战斗
- 4v4
- 流派BUILD
- 五行克制
- 轻策略
- 爽感成长

---

## 2. 设计目标

| 目标 | 说明 |
|---|---|
| 战斗爽感 | 玩家成长后能明显感受到碾压 |
| 轻策略 | 策略主要体现在战前BUILD与AI设置 |
| 轻肝度 | 可刷装备/材料，但不强制重复日常 |
| 无运营压力 | 不做日活、留存、KPI、付费设计 |
| 数值可控 | 后期避免无限膨胀 |

---

## 3. 非目标

| 非目标 | 说明 |
|---|---|
| 强PVP | 不做实时PVP |
| 重操作战斗 | 不做手动指令微操 |
| 重度日常 | 不做每日任务/活跃度系统 |
| 抽卡付费 | 不做商业抽卡 |
| 复杂战棋 | 不做走格战棋 |

## 6. 站位系统

采用 **2x2站位**。

```text
[前排左] [前排右]
[后排左] [后排右]
```

### 基础规则

| 规则 | 说明 |
|---|---|
| 前排 | 仇恨高，优先被攻击，适合承伤/反伤/近战 |
| 后排 | 仇恨低，受伤降低，适合输出/五行/干扰 |
| 同列保护 | 前排存活时，保护同列后排不被普通近战直接攻击 |
| 暴露 | 某列前排死亡后，该列后排可被攻击且受伤提高 |
| 列攻击 | 可同时攻击一列前后排 |
| 切后 | 特殊技能可无视前排保护攻击后排 |

### 站位修正建议

| 位置 | 效果 |
|---|---|
| 前排 | 仇恨+50，受到伤害+10%，护盾/反伤+10% |
| 后排 | 仇恨-30，受到伤害-10%，远程/五行伤害+5% |
| 后排被切后 | 受到伤害+15% |
| 暴露后排 | 受到伤害+15%，仇恨+30 |

## 7. 流派系统

首发四大主战流派：

| 流派 | 定位 | 核心机制 |
|---|---|---|
| 斗战·连击流 | 高频输出/削甲 | 连击、风势、裂甲 | 
| 破军·暴伤流 | 爆发/斩杀 | 暴击、破绽、斩杀、破盾 |
| 不动·护盾反伤流 | 承伤/反伤 | 护盾、嘲讽、反伤、怒目 |
| 幻影·闪避流 | 闪避/反击 | 残影、影袭、致盲、反击 |

### 队伍职责
先手削弱
主要输出
承伤反制
干扰收割
弱点打击

如: 
先手挂异常
先手破甲
先手斩杀
后手反制
回合节奏控制

### 流派克制关系

```text
暴伤流 克 护盾反伤流
护盾反伤流 克 连击流
连击流 克 闪避流
闪避流 克 暴伤流
```

### 五行分支

每个流派可选择一种五行分支。

| 五行 | 作用 |
|---|---|
| 火 | 附加灼烧 |
| 水 | 附加减速 |
| 金 | 附加破甲 |
| 木 | 附加禁疗/缠绕 |
| 土 | 附加护盾/重压 |

## 8. 五行系统

采用 **双轨附加制**。

```text
总伤害 = 物理伤害部分 + 五行附加伤害部分
```

### 五行附加公式

```text
五行附加伤害 = 技能基础伤害 × 五行攻击% × (1 - 五行抗性%) × (1 + 五行易伤%)
```

规则：

| 规则 | 说明 |
|---|---|
| 五行附加伤害默认不暴击 | 防止乘区失控 |
| 五行附加伤害不触发连击 | 防止行动次数失控 |
| 五行附加伤害可触发五行异常 | 火、水、金、木、土对应异常 |
| 五行抗性独立生效 | 不受物理减免影响 |

## 9. 属性系统

### 属性四层乘区

| 层级 | 类型 | 说明 |
|---|---|---|
| 第一层 | 基础数值 | base + ADDITIVE |
| 第二层 | 百分比加成 | PERCENTAGE |
| 第三层 | 独立乘区 | MULTIPLICATIVE |
| 第四层 | 最终乘区 | FINAL |

### 最终乘区限制

只有以下属性拥有最终乘区：

- 气血
- 攻击
- 防御
- 伤害
- 伤害减免

最终乘区必须稀缺投放。

## 11. 伤害公式

### 技能基础伤害

```text
技能基础伤害 = 技能倍率 × 攻击力
```

普攻倍率：

```text
普攻倍率 = 1
```

### 原始伤害

```text
原始伤害 = 技能基础伤害 × 暴击倍率
```

### 最终伤害

```text
最终伤害 =
max(1, 原始伤害 - 暴伤减免 - 防御)
× (1 - 攻击类型减免%)
× (1 - 伤害大类抗性%)
× (1 - 通用减免%)
× (1 + 易伤%)
× (1 + 伤害提升%)
× (1 + 条件加成%)
× 目标修正
```

最终伤害最低为1。

## 12. 命中与闪避

### 基础命中率

```text
计算命中率 = 命中值 / (命中值 + 闪避值)
```

### 实际命中率

```text
实际命中率 = clamp(计算命中率 + 命中率 - 闪避率, 10%, 95%)
```

规则：

| 规则 | 数值 |
|---|---:|
| 最低命中率 | 10% |
| 最高命中率 | 95% |

---

## 13. 暴击规则

```text
实际暴击率 = clamp(暴击率 - 暴击抵抗%, 0%, 100%)
```

暴击率可超过100%。

### 暴击溢出规则

```text
溢出暴击率 = max(0, 暴击率 - 100%)
每1%溢出暴击率 = 0.6%暴击伤害
溢出转化上限 = +50%暴击伤害
```

---

## 14. 连击规则

连击发生在同一次行动内，不额外占用回合。

### 连击判定

| 当前连击率 | 规则 |
|---|---|
| 大于100% | 必定连击，连击后减少50点固定连击率 |
| 小于等于100% | 按当前概率判定，若连击成功，连击率减半 |
| 未触发连击 | 连击结束 |

### 连击限制

| 规则 | 数值 |
|---|---:|
| 连击率软上限 | 230% |
| 普通战斗最大连击段数 | 5段 |
| Boss战最大连击段数 | 6段 |
| 连击伤害衰减 | 100% / 85% / 70% / 60% / 50% |

---

## 15. 反击、吸血、反伤

### 反击

```text
反击率判定通过后触发反击
```

规则：

| 规则 | 说明 |
|---|---|
| 反击不占用行动回合 | 属于受击响应 |
| 反击可暴击 | 是 |
| 反击不可连击 | 是 |
| 每回合反击次数上限 | 2~3次 |

### 吸血

```text
吸血量 = 造成伤害 × 吸血率%
```

### 反伤

```text
反伤伤害 = 护盾吸收前受到伤害 × 伤害反弹% + 防御 × 0.6
```

规则：

| 规则 | 说明 |
|---|---|
| 反伤基于护盾吸收前伤害 | 是 |
| 反伤不能暴击 | 是 |
| 反伤不能连击 | 是 |
| 反伤不能吸血 | 是 |
| 伤害反弹上限 | 60% |

---

## 16. 护盾规则

```text
护盾值 = 最大气血 × 25% + 防御 × 300%
护盾上限 = 最大气血 × 80%
```

规则：

| 规则 | 说明 |
|---|---|
| 多个护盾不叠加 | 取最高值 |
| 护盾存在时提高反伤 | 反伤+20% |
| 护盾存在时提高嘲讽 | 承伤优先级提高 |
| 护盾破碎后 | 获得“怒目”，短期提高反伤 |

---

## 17. 控制规则

```text
控制成功率 = 控制成功率% - 控制豁免率%
```

规则：

| 规则 | 数值 |
|---|---:|
| 普通控制持续时间 | 1回合 |
| 同类控制免疫 | 被控后1回合免疫同类控制 |
| 精英控制抗性 | 30%~50% |
| Boss控制抗性 | 60%~90% |

## 19. 等级系统

50级

每级固定成长。
每级2自由属性点，按标准模板加点。
每10级突破奖励。


### 等级经验公式

```text
EXP(L) = round(50 × L^1.35 + 60 × L)
```

### 每级固定成长

| 属性 | 每级成长 |
|---|---:|
| 气血 | +12 |
| 攻击 | +3 |
| 防御 | +2 |
| 命中 | +2 |
| 闪避 | +2 |
| 速度 | +2 |

### 每级自由属性点

```text
每级2点自由属性点
```

默认可加：

- 气血
- 攻击
- 防御
- 命中
- 闪避
- 速度

### 属性点转化

```text
1属性点 = 12气血 = 2攻击 = 2防御 = 2命中 = 2闪避 = 2速度
```

## 24. 怪物设计原则

| 怪物类型 | 设计目标 |
|---|---|
| 普通小怪 | 2~3回合击杀 |
| 精英怪 | 4~6回合击杀 |
| 小Boss | 6~8回合击杀 |
| 大Boss | 8~12回合击杀 |
| 隐藏Boss | 12回合以上 |

### 怪物属性基准

```text
怪物属性 = 玩家同等级标准属性 × 怪物类型系数
```

| 类型 | 生命系数 | 攻击系数 |
|---|---:|---:|
| 普通怪 | 70%~120% | 80%~105% |
| 精英怪 | 200%~400% | 110%~160% |
| Boss | 600%~1800% | 120%~170% |

|---|---|
| 普通小怪战 | 标准阵容2~3回合结束 |
| 精英战 | 标准阵容4~6回合结束 |

| 同装等流派差异 | 各流派效率差异不超过±15% |

| 被克制场景 | 被克制方效率下降15%~30% |
| 后期数值 | 不出现无限连击、无限控制、反伤秒杀Boss |
| 自动战斗 | 战斗结果可被AI/站位/流派解释 |

## 29. 风险与控制

| 风险 | 控制方式 |
|---|---|
| 速度成为唯一属性 | 速度成长克制，站位不大幅加速度 |
| 连击动画过长 | 最大连击段数限制 |
| 反伤秒杀Boss | 反伤上限与Boss反伤抗性 |
| 闪避流无交互 | 命中下限、Boss必中技、连击克制 |
| 暴伤秒杀Boss | Boss韧性、斩杀抗性、护盾机制 |
| 五行伤害失控 | 五行附加不暴击、受五行抗性限制 |
| 最终乘区膨胀 | 最终乘区稀缺投放 |
