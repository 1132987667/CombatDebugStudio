## 1. 物品分类总览

物品按用途分为以下大类：

| 大类 | 包含类型 | 说明 |
|------|----------|------|
| 装备 | 武器、衣服、头盔、靴子、护符、戒指 | 六槽装备，可穿戴 |
| 独立装备 | 法宝、神器 | 不占槽位，独立栏位 |
| 材料 | 木材、矿石、金属、玉石、水产、皮革、织物、陶瓷、古董、液体、毒物、特殊材料、BOSS材料 | 制造 / 强化 / 洗练消耗 |
| 强化资源 | 晶球、灵气、强化、升星、附魔、洗炼、重铸、传承、分解、突破 | 装备养成消耗 |
| 消耗品 | 丹药、永久丹药、符箓 | 战斗 / 养成使用 |
| 图纸 | 武器图纸、衣服图纸、头盔图纸、靴子图纸、护符图纸、戒指图纸、特殊图纸、传说图纸、仙品图纸 | 解锁制造配方 |
| 经济 | 货币、钥匙、门票 | 交易 / 通行 |
| 其他 | 杂物、任务、器灵、套装烙印、技能书、经验 | 杂项 |

## 5. 词条生成规则

### 5.1 生成流程

```text
第一步：确定装备阶位（凡/玄/地/天/仙）。
第二步：根据品质确定词条数量（凡1/精2/超3/绝4/神5）。
第三步：根据装备部位选择对应词条池。
第四步：按权重随机抽取词条。
第五步：检查是否与装备类型冲突（如轻型武器不出格挡词条）。
第六步：根据阶位确定数值区间，随机生成数值。
```

### 5.2 不可重复规则

```text
同一件装备不允许出现两条同名词条。
例如不能同时出现两个「暴击率 +3%」。
```

### 5.3 数值分档

| 阶位 | 数值区间系数 |
|------|-------------|
| 凡品 | 60%-80% |
| 玄品 | 70%-90% |
| 地品 | 80%-100% |
| 天品 | 90%-100% |
| 仙品 | 100% |
