# 新增武器："刺"（闪避流专属）

## 一、目的

闪避流拥有专属武器，四流派各配一把主武器，互不侵占。

## 二、武器定义

| 项目 | 内容 |
| :--- | :--- |
| 名称 | 刺（变体：双刺 / 峨眉刺 / 影刃） |
| 定位 | 闪避流专属 |
| 固定主属性 | 攻击 |
| 策略池（抽2条） | 闪避率、反击率、速度、真伤率、反击伤害系数 |
| 必含规则 | 2条策略属性中至少含闪避率或反击率 |
| 严禁属性 | 连击率、连击伤害系数、破甲、易伤 |

## 三、攻击系数

| 品质档位 | 攻击系数 |
| :--- | :--- |
| 凡品 | 85% |
| 精良/玄品 | 95% |
| 稀有/地品 | 105% |
| 史诗/天品 | 115% |

> 随品质成长，低品质保守，高品质追平重武器。满级攻击力 = 162 × 系数。

## 四、四种武器对比

| 武器 | 攻击系数 | 策略池（抽2条） | 服务流派 |
| :--- | :--- | :--- | :--- |
| 剑 | 85% | 速度、连击率、连击伤害系数、暴击率 | 连击流 |
| 刺 | 85% | 闪避率、反击率、速度、真伤率、反击伤害系数 | 闪避流 |
| 棍 | 100% | 反击率、反击伤害系数、普攻加成、暴击率 | 反击流 |
| 刀 | 100% | 暴击率、暴击伤害、技能加成、伤害系数 | 破甲流 |
