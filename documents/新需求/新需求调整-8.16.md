# 《西游斗战》需求调整说明 · 全物品体系与子系统联动（V5.0）

> **文档性质**：需求整合规格——基于「新需求调整-8.16」为主轴、「装备系统优化设计对话」为补充，对齐现有设计文档（装备 v2.1、物品 v2.0、词缀 v3.1、关卡 v2.0）。
> **核心变更**：药园重构为"灵韵灌溉制"（杀敌催熟）；装备总量扩充至 100+；材料体系扩充至 60+ 种；全物品联动网络闭合；**品质生成机制完整联动（技艺/辅助材料/保底）**；**丹药取消品质**；**药引天材地宝化**；**灵韵数值与材料阶级隔离重构**。

---

## 一、游戏定位与设计哲学

### 1.1 核心定位

```text
一款爽快的单机修仙 Looter RPG。
核心体验：斩妖除魔 → 收集材料 → 炼丹铸器 → 不断变强。
核心循环：杀敌 → 掉落 → 制造/强化/洗练 → 属性提升 → 挑战更强敌人。
```

### 1.2 三大设计法则

| 法则 | 含义 | 落地约束 |
|------|------|----------|
| **杀敌即成长** | 一切资源获取均来自战斗，无现实时间等待 | 药园杀敌催熟、掉落即时结算、无离线挂机 |
| **物品即选择** | 每件物品都有明确去向，每个节点都有分支 | BOSS 掉落随机、材料多用途、词条可定制 |
| **场景即主题** | 每个场景绑定专属资源生态 | 5 大场景 × 专属材料 × 专属装备 × 专属丹药 |

### 1.3 爽感节奏目标

```text
玩家从 1 级打到 50 级，每推进一个场景，
都能明确看到"材料升级 → 装备升级 → 丹药升级"的陡峭成长曲线。

普通战斗：3-8 回合
BOSS 战斗：10-20 回合
一阶装备获取：10-20 分钟
二阶装备获取：40-70 分钟
Demo 通关：90-150 分钟
```

### 1.4 关键设计决策（本次调整确认）

| 决策项 | 旧方案 | 新方案 | 理由 |
|--------|--------|--------|------|
| 药园催熟 | 现实时间等待 | **杀敌催熟（灵韵灌溉制）** | 解决"卡心流"和"离线无意义" |
| 装备槽位 | 3 槽（武器/衣服/饰品） | **6 槽 + 法宝/神器独立** | 横向宽度 + 纵向深度 |
| 装备总量 | 39 件 | **≥ 100 件** | 支撑 25 关 + 多 BOSS 刷取深度 |
| 装备等级 | 无等级需求 | **itemLevel 标识 + requiredLevel 宽松门槛** | 清晰标识阶段归属 |
| 材料种类 | 每类 1-2 种 | **每场景 4-5 种专属 + 通用辅助** | 形成刷取网络 |
| BOSS 奖励 | 固定 1 件 | **随机掉落（不做玩家选择）** | 保留随机惊喜 |

## 二、全物品体系设计

### 2.1 物品分类总览（7 大类 + 独立类型）

| 大类 | 子类 | 预估数量 | 核心用途 |
|------|------|----------|----------|
| **装备** | 武器/衣服/头盔/靴子/护符/戒指 | ≥ 100 件 | 穿戴 → 属性提升 |
| **独立装备** | 法宝 / 神器 | 5+ / 预留 | 独立栏位，不占 6 槽 |
| **材料** | 木材/矿石/金属/玉石/皮革/织物/液体/毒物/BOSS 材料等 | ≥ 60 种 | 制造/强化/洗练/炼丹 |
| **强化资源** | 晶球/灵气/升星石/附魔材料/洗练材料/重铸材料/传承材料 | ≥ 25 种 | 装备养成消耗 |
| **消耗品** | 丹药/永久丹药/符箓 | ≥ 20 种 | 战斗/养成使用 |
| **图纸** | 各槽位 × 各阶位 + 传说 + 仙品 | ≥ 30 种 | 解锁制造配方 |
| **功能道具** | 词条萃取液/定向洗练石/锁词条符/强化传承石等 | ≥ 10 种 | 终局定制 |

#### 2.2.2 装备数量矩阵

```text
基础装备计算：
  武器：5 场景 × 3 子类型 = 15 件
  衣服：5 场景 × 3 子类型 = 15 件
  头盔：5 场景 × 3 子类型 = 15 件
  靴子：5 场景 × 3 子类型 = 15 件
  护符：5 场景 × 2~3 子类型 = 10~15 件
  戒指：5 场景 × 2~3 子类型 = 10~15 件
  基础小计：80~90 件

BOSS 装备：
  场景 BOSS（5 个）× 1~2 件 = 5~10 件
  三大 BOSS × 1 件 = 3 件
  最终 BOSS × 1 件 = 1 件
  妖尊 × 1 件 = 若干
  BOSS 小计：10~15 件

天品/仙品：
  天品：3~4 件
  仙品：4~5 件
  小计：7~9 件

总计目标：≥ 100 件
```

```text

范围：1 ~ 50
作用：
  1. 标识装备强度层级（玩家一眼看出"这是哪个阶段的装备"）
  2. 作为穿戴门槛（玩家等级 ≥ 装备等级 - 5 方可穿戴）
  3. 作为数值锚点（装备基础属性与等级挂钩，便于数值校验）
```

| 场景 | 装备等级范围 | 穿戴门槛 | 对应阶位 |
|------|-------------|----------|----------|
| 落桃原 | 1-10 | 1-5 | 凡品 |
| 断柳渡 | 11-20 | 6-15 | 玄品 |
| 碎石岭 | 21-30 | 16-25 | 地品 |
| 迷雾谷 | 31-40 | 26-35 | 地品/天品 |
| 灵霄台 | 41-50 | 36-45 | 天品/仙品 |

#### 2.2.4 装备品级四维体系

```text
阶位：凡品 / 玄品 / 地品 / 天品 / 仙品
品质：凡 / 精 / 超 / 绝 / 神
星级：0 星 / 1 星 / 2 星 / 3 星
锻造状态：强化等级 / 附魔槽 / 洗练状态
```

| 维度 | 作用 | 主要来源 |
|------|------|----------|
| 阶位 | 决定装备基础属性区间和成长上限 | 场景材料、关卡进度 |
| 品质 | 决定基础属性系数和词条数量 | 制造、技艺、特殊材料 |
| 星级 | 提升基础属性，增强长期价值 | 同名装备消耗 |
| 锻造状态 | 玩家后续养成操作 | 强化、附魔、洗练、传承 |

### 2.4 消耗品体系

| 子类 | 示例 | 用途 | 来源 |
|------|------|------|------|
| 战斗丹药 | 疗伤丹、解毒散、聚气丹 | 战斗中恢复/解除异常/回能 | 炼丹、商店 |
| 永久丹药 | 铁骨丹、灵犀丹、破境丹 | 永久提升基础属性 | BOSS 掉落、高级炼丹 |
| 符箓 | 护体符、破甲符、疾行符 | 战斗中使用，消耗 1 回合 | 制造、商店 |
| 经验丹 | 小/中/大经验丹 | 直接获得经验 | 敌人掉落、任务 |

> **裁定：丹药不设品质。** 丹药是消耗品，服用后即消失，品质差异体验仅持续一场战斗，不值得投入系统复杂度；炼丹本身已有"配方解锁 + 材料收集"成长线，再加品质赌博属叠加挫败。品质系统**仅作用于装备制造**，不涉及丹药、符箓或其他消耗品。炼丹结果 = 成功（产出目标丹药）+ 暴击判定（双份出炉率 = 5% + 炼丹术×2% + 催化剂 5%），炼丹必定成功，仅暴击与否的区别。

## 三、物品关联网络

### 3.1 核心循环图

```text
杀敌 → 掉落材料/晶球/图纸
         ↓
    制造装备（材料 + 图纸 + 金钱）
         ↓
    穿戴装备 → 属性提升
         ↓
    强化装备（晶球/异矿/灵水 + 金钱）
         ↓
    附魔装备（场景辅材 + 金钱）
         ↓
    洗练词条（洗练材料 + 金钱）
         ↓
    升星装备（同名装备 / 升星石）
         ↓
    挑战更强敌人 → 更高阶材料 → 循环
```

### 3.2 材料 → 装备关联

```text
场景主材（桃木/铁精/毒藤等）
  → 制造对应场景阶位的装备

场景辅材（毒液/寒潭水/藤蔓丝等）
  → 炼丹（战斗消耗）
  → 附魔（附加固定词条）
  → 洗练（替换随机词条）

BOSS 专属材料
  → 合成改变游戏机制的传说装备
  → 明确的 Build 方向选择
```

### 3.3 装备养成链路

```text
获取 → 穿戴 → 强化 → 附魔 → 升星 → 洗练/重铸 → 传承/分解
                                  ↑                    ↓
                         晶球/灵气/材料          残魂/材料回收
```

### 3.4 药园 → 炼丹 → 战斗联动（灵韵灌溉制）

```text
杀敌获得"灵韵"
  ↓
灵韵灌溉药园 → 药材催熟（无现实时间等待）
  ↓
采收药材
  ↓
炼丹（药园 + 炼丹炉）
  ↓
丹药用于战斗 / 永久属性提升
```

| 药园要素 | 旧设计 | 新设计（灵韵灌溉制） |
|----------|--------|----------------------|
| 催熟方式 | 现实时间等待 | **杀敌获得灵韵，灵韵灌溉催熟** |
| 灵韵来源 | 无 | 每次战斗胜利获得，BOSS 战加倍 |
| 药材品质 | 固定 | 灵韵投入量影响品质 |
| 药田升级 | 时间解锁 | 累计灵韵消耗解锁更多药田 |

### 3.5 BOSS → 装备追求关联

| BOSS 类型 | 掉落机制 | Build 方向 |
|-----------|----------|------------|
| 场景 BOSS | 材料 + 图纸（随机掉落） | 对应场景流派 |
| 牛魔王 | 天品武器材料 | 控制流 / 重型 |
| 蝎子精（盘丝） | 天品戒指材料 | 毒伤流 / 连击 |
| 大鹏 | 天品头盔材料 | 速度流 / 闪避 |
| 最终 BOSS（六耳） | 仙品材料 | 终局全属性 |
| 妖尊 | 特殊装备 / 功能道具 | 特殊 Build |

> **BOSS 掉落规则（裁定）**：不做玩家选择，改为**随机掉落其一**（含天品/仙品装备、图纸解锁）。击败后按概率随机出一件，直接进背包。仅首杀触发高品质掉落；重复挑战随机掉降妖令 + 通用材料。

### 8.3 材料阶位与品质的关系（重新定义）

#### 8.3.1 核心规则：配方材料固定，不可替换

```text
每件装备的配方材料是固定的，玩家不可自行替换。
示例：
  竹剑   = 桃木×3 + 铜精×1（固定，不可用松木替代桃木）
  伏魔杖 = 金精×3 + 铁木×2（固定，不可用铜精替代金精）

因此不存在"用高阶材料替代低阶材料来提升品质"的机制。
```

#### 8.3.2 品质提升的正确途径：额外投入辅助材料

"使用特殊材料可提升品质下限"中的"特殊材料"指**配方之外的额外投入**（辅助材料）：

```text
制造界面：
┌────────────────────────────────────────┐
│ 制造：伏魔杖（三阶·中型武器）           │
│                                        │
│ 必需材料（固定配方）：                  │
│   金精 ×3  ✓（持有 5）                 │
│   铁木 ×2  ✓（持有 3）                 │
│                                        │
│ 辅助材料（可选投入，提升品质）：        │
│   [ ] 珍珠 ×1    → 精品概率 +10%       │
│   [ ] 玉佛像 ×1  → 超品概率 +8%        │
│   [ ] 品质丹·超  → 超品概率 +12%       │
│                                        │
│ [ 开始制造 ]                           │
└────────────────────────────────────────┘
```

#### 8.3.3 辅助材料品质加成表

| 辅助材料 | 效果 | 适用阶位 | 获取来源 |
|----------|------|----------|----------|
| 珍珠 ×1 | 精品概率 +10% | 一阶~二阶 | 场景2敌人掉落 |
| 翡翠玉镯 ×1 | 超品概率 +5% | 二阶~三阶 | 关卡 4-5 BOSS「迷雾妖主」掉落 |
| 玉佛像 ×1 | 超品概率 +8% | 三阶 | 场景5 BOSS掉落 |
| 品质丹·精 | 精品概率 +15%，凡品 -15% | 一阶~三阶 | 炼丹 |
| 品质丹·超 | 超品概率 +12%，凡品 -12% | 二阶~三阶 | 炼丹 |
| 品质丹·绝 | 绝品概率 +8%，凡品+精品各 -4% | 仅三阶 | 炼丹（稀有） |
| 天命品质符 | 本次制造**必定**超品以上 | 任意阶位 | BOSS首杀/成就 |

**使用限制**：
```text
每次制造最多投入 1 件辅助材料。
辅助材料在制造后消耗（无论结果如何）。
天命品质符为保底符，直接覆盖概率表，不与其他辅助材料叠加。
```

#### 8.3.4 材料阶位的真正作用

材料阶位**不影响品质概率**，而是影响**词条倾向**（知识库已有设计）：

```text
使用桃木/松木/铁木制造 → 灵猴道词条权重 +50%
使用铜精/铁精/金精制造 → 金行道词条权重 +50%
使用粗石/铁焰矿/金阳矿制造 → 磐石道词条权重 +50%
使用鹿皮/虎皮/仙云皮制造 → 灵猴道词条权重 +50%
使用圣水玉/玉佛像制造 → 佛门/生存词条权重 +50%
使用毒液/寒潭水制造 → 元素/异常词条权重 +50%
```

**总结**：
```text
材料阶位 → 决定能做什么装备（配方门槛）+ 词条倾向
辅助材料 → 决定品质概率修正
技艺等级 → 决定品质概率基础分布
三者各司其职，互不混淆。
```

#### 8.4.2 具体数值演算（完整示例）

**场景**：玩家制造三阶中型武器"伏魔杖"

```text
已知条件：
  - 装备：伏魔杖（三阶·中型武器）
  - 技艺：武器制作 Lv.6
  - 辅助材料：品质丹·超（超品概率+12%，凡品-12%）
  - 保底计数器：距上次超品已 4 次（未触发保底）

步骤2 → 查表（技艺6）：
  凡 30% | 精 28% | 超 24% | 绝 13% | 神 5%

步骤3 → 应用品质丹·超：
  凡 30%-12% = 18%
  精 28%（不变）
  超 24%+12% = 36%
  绝 13%（不变）
  神 5%（不变）
  验证总和：18+28+36+13+5 = 100% ✓

步骤4 → 保底检查：
  距超品 4 次 < 5 → 未触发
  距绝品 7 次 < 10 → 未触发
  距神品 15 次 < 20 → 未触发

步骤5 → 加权随机：
  假设随机数落在 36% 的超品区间
  结果：超品

步骤6 → 超品区间内 roll：
  106%-120% 内随机 → 得到 114%

步骤7 → 词条数量：
  超品 → 3 条词条
  中型武器词条池 + 金行道倾向（金精×3）
  → 生成 3 条词条

步骤8 → 更新：
  保底计数器重置（超品计数器归零）
  weaponCrafting.exp += 1
  检查是否升级
```

#### 8.4.3 保底机制的精确规则

| 保底类型 | 触发条件 | 适用范围 | 触发后行为 |
|----------|----------|----------|------------|
| 超品保底 | 连续 5 次制造未出超品及以上 | 一阶~三阶 | 第 6 次必出超品 |
| 绝品保底 | 连续 10 次制造未出绝品及以上 | 仅三阶 | 第 11 次必出绝品 |
| 神品保底 | 连续 20 次制造未出神品 | 仅三阶 | 第 21 次必出神品 |

```text
计数器规则：
  - 每次制造后，若结果 ≥ 超品，则超品计数器归零
  - 每次制造后，若结果 ≥ 绝品，则绝品计数器归零
  - 每次制造后，若结果 = 神品，则神品计数器归零
  - 计数器按装备阶位独立计算（一阶/二阶/三阶各有独立计数器）
  - 天品/仙品制造不参与计数器（固定品质）
```

## 十一、设计缺口审计裁定（逐项裁定）

> 本节收录《设计缺口审计报告》的逐项裁定结论。审计基准：以本文档（V5.0）为主轴，结合 `设计稿补充-装备V2.md`、`全物品文档-8.16.md`、`关卡系统 v2.0.md`、`统一战斗系统文档.md`、`开发规范.md` 及代码层 `quality.ts`、`types.ts`、`xiyouData.ts` 等文件。
> **核心约束**：本项目为**单机网页游戏**，无服务端、无联网、无玩家间交易。所有随机可用 `Math.random`，存档走 IndexedDB，经济无需防通胀但需防溢出。

### 总体裁定

审计报告列出 42 个缺口。经逐项比对知识库，**其中约 28 个在现有文档中已有明确答案**，审计报告存在大面积"漏读"。真正需要补充的缺口约 **14 个**，且多数为 P2 级。以下逐一裁定。

### 一、装备品质生成机制

#### 1.1 品质如何决定？

**裁定：知识库已有完整定义，非缺口。**

审计报告称"未定义品质的生成规则"，这与知识库不符。本文档 §8 已给出完整的**品质生成联动机制**，包含三层：

| 层级 | 机制 | 出处 |
|------|------|------|
| 基础概率 | 技艺等级查表（§8.2.3），如技艺 6 → 凡 30% / 精 28% / 超 24% / 绝 13% / 神 5% | §8.2.3 |
| 辅助材料修正 | 每次制造最多投入 1 件辅助材料（珍珠 +10% 精品、品质丹·超 +12% 超品等） | §8.3.3 |
| 保底兜底 | 超品保底 5 次、绝品保底 10 次（仅三阶）、神品保底 20 次（仅三阶） | §8.4.3 |

此外：
- **天品固定绝品、仙品固定神品**，不走随机（§8.4.1 步骤 1）。
- **配方材料固定不可替换**，不存在"用高阶材料替代低阶材料提升品质"（§8.3.1）。
- 材料阶位**不影响品质概率**，只影响**词条倾向**（§8.3.4）。

> 注：审计报告提到"用户否决了概率制与保底制，要求材料决定品质"——在知识库中找不到此裁定。经确认，现行规则即为上表（概率制 + 保底），本段作为审计疑问记录保留。

**关于"是否为确定性"**：现行规则为**概率制 + 保底**，同一配方制造两次品质**可以不同**。这对单机 Looter 游戏是合理的——品质随机是制造系统的核心驱动力。

#### 1.2 品质系数区间内的具体数值如何 roll？

**裁定：代码层已有实现，非缺口。**

`quality.ts` 中 `rollQualityFactor` 函数已实现：

```text
在品质区间内均匀随机，保留 3 位小数。
示例：超品 106%-120% → 随机取 [1.060, 1.200] 之间任意值。
```

- 分布方式：**均匀随机**（非正态）。
- 系数仅影响**基础属性**，不影响词条数值。词条数值由词条自身的区间独立 roll。
- 不存在"满系数"特殊概念，120% 与 119% 无机制差异。

**单机适配**：均匀随机在单机场景下体验可接受。若未来希望"大概率出中值"，可改为三角分布，但当前无必要。

### 二、词条生成规则

#### 2.1 词条生成算法

**裁定：知识库已有 6 步流程，非缺口。但分布细节可补充。**

`设计稿补充-装备V2.md` §5.5 已定义：

```text
步骤 1：确定装备阶位
步骤 2：根据品质确定词条数量（凡 1 / 精 2 / 超 3 / 绝 4 / 神 5）
步骤 3：根据装备部位选择对应词条池
步骤 4：按权重随机抽取词条
步骤 5：检查是否与装备类型冲突
步骤 6：生成数值
```

| 问题 | 答案 | 出处 |
|------|------|------|
| 超品 3 条词条如何抽取？ | 从部位词条池中按权重随机抽 3 条 | 装备 V2 §5.5 |
| 是否允许重复词条？ | **不允许**。"同一件装备不允许出现两条同名词条" | 装备 V2 §5.5 |
| 词条数值分布？ | 按阶位确定区间，区间内随机（**建议均匀**） | 装备 V2 §5.4 |
| 材料是否影响词条？ | **是**。桃木/松木/铁木 → 灵猴道 +50%，铜精/铁精/金精 → 金行道 +50%，以此类推 | 装备 V2 §5.7 |
| 流派是否影响词条？ | 知识库未定义玩家流派直接影响制造词条。材料倾向已间接覆盖此需求 | — |

**真实微缺口**：词条数值的分布方式（均匀 / 正态 / 三角）未明确。**裁定：均匀随机**，与品质系数一致，保持规则简洁。

#### 2.2 词条与词缀的边界

**裁定：知识库已有明确隔离，非缺口。**

`设计稿补充-词缀.md` v3.1 §0 明确：

```text
词缀只作为敌人难度标签。
词缀不与玩家装备词条混用。
装备词条是「器魂」，战斗词缀是「妖气烙印」，两者独立运作。
```

- 词条池和词缀池**不共用**，是两套独立配置。
- 属性类型有重叠（如暴击率），但数值区间、权重、配置表完全独立。
- 代码层 `types.ts` 中 `EquipmentAffixData` 与 `AffixData` 是两个独立接口。

#### 2.3 词条总和上限

**裁定：知识库已有上限定义，非缺口。**

`equipment-system.json` 中 `affix_cap` 已定义：

| 属性 | 上限 |
|------|------|
| 固定攻击总和 | 200 |
| 百分比攻击总和 | 80% |
| 暴击伤害总和 | 300% |
| 连击率总和 | 60% |
| 闪避率总和 | 40% |
| 格挡率总和 | 60% |

### 四、洗练系统规则

#### 4.1 洗练的具体行为

**裁定：知识库已有定义，非缺口。**

`设计稿补充-装备V2.md` §7：

| 洗练类型 | 行为 | 消耗 |
|----------|------|------|
| 普通洗练 | **全部词条重新随机** | 洗炼石 ×1 + 金钱 |
| 定向洗练 | **指定 1 条词条重新随机** | 精洗石 ×1 + 金钱 |
| 锁词条洗练 | **锁定 1 条不变，其余重新随机** | 锁词符 ×1 + 金钱 |
| 洗髓液洗练 | 可指定词条类型（如只要攻击类） | 洗髓液 ×1 |
| 天命洗炼符 | 保证出现最高档数值区间 | 天命洗炼符 ×1 |

- 洗练后词条数量**不变**（超品 3 条洗练后仍为 3 条）。
- 洗练只能从**当前部位词条池**中抽取，不可跨池。
- 洗练结果**可以比原来差**（这是洗练的风险成本）。

#### 4.2 定向洗练的"定向"机制

**裁定：知识库已有示例，非缺口。**

`设计稿补充-装备V2.md` §9.3：

```text
定向洗练连击率：寒潭水 ×2 + 仙云皮 ×1
定向洗练暴击伤害：寒潭水 ×2 + 金精 ×1
定向洗练格挡率：寒潭水 ×2 + 古铜镜 ×1
```

- "特殊材料"决定目标词条类型。
- 定向是**100% 出目标词条类型**，但数值仍随机。
- 如果目标词条已存在，**覆盖**该词条（重新 roll 数值）。

#### 4.3 锁词条洗练

**裁定：知识库已有定义，非缺口。**

- 锁住词条**种类和数值**均不变。
- 最多锁定 **1 条**。
- 锁住的词条保持不变，其余词条重新随机。
- 天品/仙品的**固定特效不可锁定**。
- 品质限制：超品及以上开放锁词条洗练（凡/精仅普通/定向）。

### 五、附魔系统

#### 5.1 附魔与词条的区别

**裁定：知识库已有区分，非缺口。**

| 维度 | 词条 | 附魔 |
|------|------|------|

| 独立性 | 与附魔互不影响 | 与词条互不影响 |

附魔槽数量（§8.4.4）：

|------|--------|
| 凡 | 0 |
| 精 | 1 |
| 超 | 2 |

| 神 | 3 |

`equipment-system.json` 中 `infusion` 字段：

```text
2. 若装备有空槽 → 直接附加

```

- 附魔材料：地脉灵气（+5%）、天罡灵气（+10%）、混元灵气（覆盖时保留原数值）

**微缺口（P2）**：附魔粉尘的获取途径未完整列出。**裁定：守护者掉落 + 分解精品以上装备**。

### 十二、战斗结算细节

#### 12.1 速度相同时的行动顺序

**裁定：真实微缺口（P1）。**

`统一战斗系统文档.md` 定义了速度决定行动顺序，但未定义速度相同时的规则。**裁定（P1）**：

```text
速度相同时：我方优先于敌方。
同为敌方时：按配置顺序（enemies 数组索引）。
同为我方时：按队伍编成顺序。
```

理由：单机游戏中"玩家优先"是正向体验。不需要引入随机（避免回放不确定性）。"先手概率"词条不参与速度相同判定，仅影响速度不同时的额外先手判定。

#### 12.2 控制效果的结算

**裁定：统一战斗系统文档已有框架，但细节需补充（P1）。**

| 控制状态 | 对行动的影响 |
|----------|-------------|
| 眩晕 | 完全跳过行动（不能普攻、不能技能、不能用丹药） |
| 沉默 | 不能释放技能，**可以普攻**，可以用丹药 |
| 冰冻 | 同眩晕，但受到火属性伤害时立即解除 |

- 控制效果可被净化丹药解除。
- 控制抗性减少**持续时间**（如 2 回合眩晕 × 50% 抗性 = 1 回合）。
- BOSS 被眩晕后获得控制抗性（已有）。

#### 12.3 DOT 结算时机

**裁定：知识库已有定义，非缺口。**

`设计稿补充-大体.md` §1.1 回合结算轴：

```text
Phase 1 回合开始：DOT 结算（中毒/燃烧/流血在此阶段扣血）。
```

- DOT 伤害**不受防御减免**（真实伤害）。
- DOT 伤害**不可暴击**。
- 多个 DOT **同时生效**（中毒 + 燃烧各扣各的）。
- DOT 导致死亡时，触发"阵亡"事件（影响被动技能）。

#### 12.4 护盾机制

**裁定：真实缺口（P1）。**

知识库提到护盾但未定义完整规则。**裁定（P1）**：

```text

护盾优先于气血扣除。

持续时间结束后，剩余护盾值消失。
护盾在 Phase 1 回合开始时不结算（非 DOT）。
```
