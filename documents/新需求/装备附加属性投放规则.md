# 装备附加属性（词条）投放规则

> **状态**：2026-08-31 策划定稿。配置文件 `configs/equipment/affix-rule.json`（与 equipment-affixes.json 同级，独立于封神榜 IDB 种子，仅作策划存档与后续接入依据）。

## 一、属性组定义

### 1.1 百分比加成（ADD）

| 组 | 标签 | 包含属性（attributes.json code = 中文名） |
| --- | --- | --- |
| **ATK-ADD** | 攻击系·百分比加成 | `attackBonus`=攻击加成、`hitBonus`=命中加成、`speedBonus`=速度加成、`damageBoost`=伤害提升、`normalAtkBonus`=普攻加成、`skillBonus`=技能加成 |
| **DEF-ADD** | 防御系·百分比加成 | `healthBonus`=气血加成、`defenseBonus`=防御加成、`dodgeBonus`=闪避加成、`shieldBonus`=护盾加成、`healBonus`=治疗强度加成、`reflectBonus`=伤害反弹加成 |

> 属性 code 均已核对存在（attributes.json）。「伤害提升」对应 `damageBoost`，非"伤害加成"字面，沿用现有 code。

## 二、部位与子类型

| 部位 | 子类型 |
| --- | --- |
| 武器 | 剑 / 棍 / 锤 |
| 衣甲 | 布甲 / 皮甲 / 盔甲 |
| 头部 | 面 / 冠 / 头盔 |
| 脚部 | 布鞋 / 皮鞋 / 战靴 |
| 护符 | 护符 |
| 护腕 | 护腕 |

**投放阵营（side）**：武器/护符/护腕 → **ATK**；衣甲/头部/脚部 → **DEF**。

## 五、禁止规则

- 武器禁止洗出免伤率
- 护甲禁止洗出暴击率
- 脚部禁止洗出暴击伤害
- 护符禁止洗出防御
