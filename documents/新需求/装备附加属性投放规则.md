> **状态**：2026-08-31 策划定稿。配置文件 `configs/equipment/affix-rule.json`（与 equipment-affixes.json 同级）。2026-09-02 起已接入封神榜 `params` 域（key=`affix_rule`），驱动「词条投放规则」页编辑与「装备总览」页反推，接入现状与缺口见 §七。

## 一、属性组定义

### 1.1 百分比加成（ADD）

| 组 | 标签 | 包含属性（attributes.json code = 中文名） |
| --- | --- | --- |
| **ATK-ADD** | 攻击系·百分比加成 | `attackBonus`=攻击加成、`hitBonus`=命中加成、`speedBonus`=速度加成、`damageBoost`=伤害提升、`normalAtkBonus`=普攻加成、`skillBonus`=技能加成 |
| **DEF-ADD** | 防御系·百分比加成 | `healthBonus`=气血加成、`defenseBonus`=防御加成、`dodgeBonus`=闪避加成、`shieldBonus`=护盾加成、`healBonus`=治疗强度加成、`reflectBonus`=伤害反弹加成 |

> 属性 code 均已核对存在（attributes.json）。「伤害提升」对应 `damageBoost`，非"伤害加成"字面，沿用现有 code。

## 二、部位与子类型

| 部位 | 子类型 |
| --- | --- |
| 武器 | 剑 / 刺 / 棍 / 刀 |
| 衣甲 | 布甲 / 皮甲 / 盔甲 |
| 头部 | 面 / 冠 / 头盔 |
| 脚部 | 布靴 / 皮靴 / 战靴 |
| 护符 | 护符 |
| 护腕 | 护腕 |

**投放阵营（side）**：武器/护符/护腕 → **ATK**；衣甲/头部/脚部 → **DEF**。

> 配置中词条池按 **side** 展开（`affix_rows[].pool.ATK` / `.DEF`），不按子类型细分——同部位各子类型的池完全相同。子类型之间的差异由禁止规则（§五）与核心属性词条系数（`core_affix_ratio`）承载。

## 五、禁止规则

`forbidden` 支持两种粒度：仅 `slot` = 整个部位生效；`slot + subType` = 只约束该子类型（配置里存 `sub_type_groups` 的中文名）。

| 范围 | 禁止洗出 |
| --- | --- |
| 武器（全子类型） | 免伤率 |
| 武器 · 刺 | 连击率、连击伤害系数、破甲、易伤 |
| 衣甲 | 暴击率 |
| 脚部 | 暴击伤害 |
| 护符 | 防御、防御加成、防御系数 |

> **NOTE**：消费侧（词条池生成、「装备总览」反推）必须按 `slot + subType` 双条件过滤。只按 slot 匹配会把子类型级禁令误加到同部位其他子类型上（如「刺禁连击率」会连带吃掉剑的连击率）。

## 七、接入现状与缺口

**已接入**：

- `configs/equipment/affix-rule.json` 经 `seed.ts` 的 `buildAffixRule()` 导入封神榜 IDB `params` 域（key=`affix_rule`）。**新增顶层字段必须同步加进 `buildAffixRule` 的字段白名单，否则静默丢失。**
- 封神榜 → 词条投放规则页可编辑该规则；其「装备总览」页按等级/部位/子类型/品阶/品质反推核心、主要、附加三区间的可获得范围。
- 主要属性池 `main_affix_pool`（子类型 → 第 1 条固定 + 第 2 条随机池；元素可为属性组码或单个属性码）：已配 剑 / 棍 / 刀 / 护符 / 护腕。

**缺口**：

- 其余 10 个子类型（刺、布甲、皮甲、盔甲、面、冠、头盔、布靴、皮靴、战靴）整体未配 `main_affix_pool`；已配的 5 类中棍/刀随机池为空、护腕第 1 条固定为空 —— 原稿仅存在于图片中，未逐条转写。「装备总览」对未配置项给出「配置缺口」告警而非补默认值。
- `vulnerability`（易伤）出现在 `SHD-L1` / `ATK-ALL` 池中，但 `affix_value_curve` 无对应行 —— 总览按「缺曲线」显示，不显示 0。
- `configs/equipment/equipment-affixes.json`（30 条）的 `applicableSlots` 仍是旧口径：`weapon:轻型/中型/重型`、`armor:木甲/皮甲/铠甲`，与规则侧 15 子类型既不同名也不齐（无「刺」，也无「刀」）—— 按装备名逐件 re-tag 尚未做。
