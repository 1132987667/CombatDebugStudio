## 1. 设计原则

```text
1. 装备不引入等级需求（无 Lv.X 才能穿戴）。
2. 装备成长主要通过阶位、品质、强化、附魔、升星、词条实现。
3. 所有操作必须与现有材料、晶球、灵气、特殊掉落形成关联。
4. 数值控制在 10000 以内，避免后期膨胀。
5. 制造仍然是核心获取方式，BOSS 掉落作为补充和追求。
6. 法宝/神器不占装备槽位，为独立类型。
7. 五行攻击已删除（设计决策 D1b），装备词条不出现五行攻击修正。
```

## 2. 装备品级体系总览

装备品级拆分为四个独立维度：

```text
阶位：凡品 / 玄品 / 地品 / 天品 / 仙品
品质：凡 / 精 / 超 / 绝 / 神
星级：0 星 / 1 星 / 2 星 / 3 星
锻造状态：强化等级 / 附魔槽 / 洗练状态
```

| 维度 | 作用 | 主要来源 |
|------|------|----------|
| 阶位 | 决定装备基础属性区间和成长上限 | 场景材料、关卡进度 |
| 品质 | 决定基础属性系数和词条数量 | 制造、技艺、特殊材料 |
| 星级 | 提升基础属性，增强长期价值 | 同名装备消耗 / 装备残魂 |
| 锻造状态 | 玩家后续养成操作 | 强化、附魔、洗练、传承 |

## 5. 品质差异设计

| 品质 | 基础属性系数 | 随机词条数量 | 获取方式 |
|------|-------------|-------------|----------|
| 凡 | 80%-90% | 1 条 | 制造（低技艺） |
| 精 | 91%-105% | 2 条 | 制造（中技艺） |
| 超 | 106%-120% | 3 条 | 制造（高技艺）/ 特殊材料 |
| 绝 | 121%-140% | 4 条 | BOSS 材料定向合成（天品） |
| 神 | 141%-150% | 5 条 | 最终 BOSS 材料定向合成（仙品） |

品质生成规则：

```text
制造时根据技艺等级、材料品质、运气因素综合判定。
技艺等级越高，高品质概率越大。
使用特殊材料可提升品质下限。
```

绝 / 神品与凡 / 精 / 超品的区别：

```text
凡 / 精 / 超品：制造体系内可重复获得，可升星、可传承、可分解。
绝 / 神品：由 BOSS 材料定向合成，拥有固定特效，不可升星、不可传承、不可分解，可随意重铸。
```

定位：输出向 / 爆发向核心部位

## 12. 法宝属性设计

法宝是独立于六槽之外的成长型装备，不占槽位，与角色绑定出战。

```text
定位：成长型战力
主属性：随等级成长的基础属性（攻击/防御/气血）+ 专属技能
成长规则：通过喂养材料升级，达到特定等级解锁专属技能
限制：不可交易、不可分解
```

示例：

| 法宝 | 来源 | 专属技能 |
|------|------|----------|
| 如意金箍棒 | 主线剧情 | 每次攻击后提升 3% 攻击，可叠 5 层 |
| 九齿钉耙 | 主线剧情 | 重击时 20% 概率眩晕目标 |
| 降妖宝杖 | 主线剧情 | 受击时 15% 概率获得护盾 |
| 芭蕉扇 | 隐藏 BOSS | 大招伤害 +25% |
| 紫金红葫芦 | 隐藏 BOSS | 击杀后恢复 10% 最大气血 |

## 14. 随机词条设计

### 14.1 词条生成总流程

```text
第一步：确定装备阶位。
第二步：根据品质确定词条数量。
第三步：根据装备部位选择对应词条池。
第四步：按权重随机抽取词条。
第五步：检查是否与装备类型冲突。
第六步：生成数值。
```

品质决定词条数：

```text
凡：1 条
精：2 条
超：3 条
绝：4 条
神：5 条
```

词条不可重复：

```text
同一件装备不允许出现两条同名词条。
```

### 14.8 材料倾向加成

使用特定材料制造时，对应词条权重 ×2：

| 材料 | 对应装备类型 | 加成词条方向 |
|------|-------------|-------------|
| 桃木 / 松木 / 铁木 | 轻型武器 | 连击率、攻速、能量获取 |
| 铜精 / 铁精 / 金精 | 中型武器 | 暴击率、暴击伤害、命中 |
| 粗石 / 铁焰矿 / 金阳矿 | 重型武器 | 格挡率、受击能量获取、伤害减免 |
| 鹿皮 / 虎皮 / 仙云皮 | 皮甲 | 闪避率、速度 |
| 圣水玉 / 玉佛像 | 护符 / 头盔 | 气血、治疗效果、护盾效果 |
| 毒液 / 寒潭水 | 戒指 | 对异常目标伤害、元素伤害 |
| 古铜镜 / 翡翠玉镯 | 靴子 / 戒指 | 速度、暴击率 |

### 14.9 冲突检测规则

```text
轻型武器：格挡率禁止。
重型武器：连击率权重减半（不禁止）。
皮甲：格挡率禁止。
铠甲：闪避率禁止。
护符：暴击率、暴击伤害禁止。
靴子：暴击伤害禁止。
```

## 15. 装备最终属性公式

```text
装备基础属性 = 原始基础属性 × 品质系数 × (1 + 技艺等级 × 5%) × (1 + 强化等级 × 强化系数) × (1 + 星级 × 10%)

最终角色属性 = 角色基础属性 + 装备基础属性总和 + 装备词条固定值总和

然后：
最终角色属性 × (1 + 装备百分比词条总和) × (1 + 附魔百分比效果总和) × (1 + 套装效果总和)
```

### 16.7 强化传承

强化传承仅适用于凡品、玄品、地品装备。

```text
天品装备不可传承。
仙品装备不可传承。
```

传承条件：

```text
1. 同部位。
2. 同阶位。
3. 目标装备未强化，或强化等级低于来源装备。
```

传承内容：

```text
仅转移强化等级。
```

不转移内容：

```text
品质、星级、随机词条、固定特效、附魔。
```

传承结果：

```text
目标装备获得来源装备的强化等级。
来源装备强化等级清零。
```

成本：金钱 + 地脉灵气。

## 19. 洗练与重铸设计

### 19.1 洗练权限

| 品质 | 可执行操作 |
|------|-----------|
| 凡 | 普通洗练 |
| 精 | 普通洗练、定向洗练 |
| 超 | 普通洗练、定向洗练、锁词条洗练 |
| 绝 | 仅限绝品洗练，不可改变固定特效 |
| 神 | 仅限神品洗练，不可改变固定特效 |

### 19.2 普通洗练

```text
效果：随机重置装备上的 1 条词条。
消耗：寒潭水 ×1 + 金钱（当前阶位基础费用）。
结果：玩家可选择保留旧词条，或替换为新词条。
```

### 19.3 定向洗练

```text
效果：将 1 条词条替换为指定类型词条。
消耗：寒潭水 ×2 + 对应特殊材料 ×1 + 金钱（较高费用）。
示例：
  定向洗练连击率：寒潭水 ×2 + 仙云皮 ×1
  定向洗练暴击伤害：寒潭水 ×2 + 金精 ×1
  定向洗练格挡率：寒潭水 ×2 + 古铜镜 ×1
限制：不保证数值满值，只保证词条类型。
```

### 19.4 锁词条洗练

```text
效果：洗练时锁定 1 条词条，不被重置。
消耗：天罡灵气碎片 ×3 + 寒潭水 ×3 + 金钱（高费用）。
限制：最多锁定 1 条词条。天品/仙品装备不可锁定固定特效。
```

### 19.5 重铸

```text
重铸与洗练不同：
  洗练：改变词条。
  重铸：重新生成整件装备的词条。

建议仅超品及以上品质装备开放重铸；天品/仙品装备可随意重铸。

消耗：混元灵气碎片 ×5（或混元灵气 ×1）+ 对应阶位晶球 ×1 + 大量金钱。

结果：
  装备品质不变。
  强化等级保留。
  附魔保留。
  星级保留。
  所有随机词条重新生成。

重铸是终局装备追求完美词条的手段，不应频繁使用。
```

## 25. 开发优先级

### P0：必须实现

```text
装备阶位
装备品质
基础属性
随机词条
制造装备
强化装备
装备穿戴
```

这是装备系统最小闭环。

### P1：Demo 后期实现

```text
附魔系统
升星系统
普通洗练
装备分解
强化传承
```

这些系统能明显提升重复刷取价值。

### P2：正式版或后续版本实现

```text
定向洗练
锁词条洗练
重铸
天品 / 仙品装备
套装烙印
附魔封存
装备残魂
```

这些系统适合在核心循环稳定后加入。

## 26. 最终设计结论

当前装备设定不足的核心原因是：

```text
只有基础属性和品质词条，缺少后续养成层次。
装备之间差异主要由数值高低构成，缺少风格差异。
特殊材料、晶球、灵气、BOSS 材料没有完全进入装备循环。
```

补全后的装备系统应遵循：

```text
阶位决定装备上限。
品质决定词条和附魔空间。
装备类型决定战斗风格。
随机词条决定 Build 差异。
强化提供稳定成长。
附魔提供材料消耗和惊喜感。
升星提供长线追求。
洗练提供超品装备优化空间。
仙品装备提供终局目标。
```

这样装备系统不再只是"攻击力更高的工具"，而会成为玩家反复战斗、收集材料、挑战 BOSS 的核心动力。
