# 日志系统需求缺口评估

> 对《战斗日志管理系统需求规格说明书》的对照评审。
> 评估基准：代码库当前 HEAD，对照 `src/infrastructure/adapters/logging/`、`src/domain/battle/logs/`、`src/presentation/views/BattleLog.vue`。
> 评审日期：2026-08-05。

## 结论

原需求规格中的大部分功能已落地，但存在 **一处文档声明与源码不符**，以及 **4 项需求仍未实现**。
已实现部分（颜色标识、事件模板、筛选、主题、性能、导出）不再追踪，从本文档删除。

---

## 0. 文档声明与源码不符（需更正）

原文档"更新说明"声称已采用 **三层架构 `LogCollector` → `LogParser` → `LogRenderer`**，并指向 `src/infrastructure/adapters/logging/`。
**源码中不存在这三个类**（全库检索无结果）。

实际架构：

- `BattleLogManager`（`src/infrastructure/adapters/logging/BattleLogManager.ts`）——统一收集器，维护 battle / system / item / action / debug 五类日志、sub 日志缓冲、过滤、监听器
- `RoundNarrativeRenderer`（`src/domain/battle/logs/renderers/RoundNarrativeRenderer.ts`）——把 `BattleLogEntry[]` 聚合为叙事块（round / action / settlement 等）
- `BattleLogProjector` / `EffectRenderer` / `BattleSummaryGenerator`——战斗文本投影与战报摘要
- `BattleLog.vue`——UI 渲染层

---

## 1. 连续同类事件合并（未实现）★ 价值最高

**需求（原 §3.1 / §3.3 / §4.1）：**

> 对同一来源（如"张三"）对同一目标（如"李四"）连续造成的多次同类型事件（普通攻击、暴击）合并为一条汇总日志，如"张三 对 李四 连续造成 5 次伤害（共 320 点）"，中间无其他类型事件打断。

**现状：**

- `RoundNarrativeRenderer` 仅按 `meta.role` 分组，每次普通攻击都渲染为独立 action 块，**无合并逻辑**
- `LogEntry` / `BattleLogEntry` 无 `mergeKey` 字段
- 合并规则、`rawData.events` 子事件数据结构均未落地

**建议改动：**

- `BattleLogEntry` 增加 `mergeKey`（`source_target_type`）
- `addBattleLog` 时若上一条可合并则更新汇总（次数 + 总值）
- 渲染层支持"汇总行 + 展开详情"（详情可暂不展开，保留 `rawData` 供未来扩展）

---

## 2. 回合数统计（未实现）

**需求（原 §3.1）：**

> 在日志区域顶部显示当前战斗的总回合数（实时更新）。

**现状：**

- `BattleLog.vue` 头部只有标题、状态明细开关、搜索、导出、页签，**无回合数统计**
- 回合信息仅作为日志中的 round 分隔块存在（"第 X 回合"），无顶部汇总

---

## 3. 清空日志入口（未实现）

**需求（原 §3.4）：**

> 提供"清空日志"按钮，点击后清空当前日志列表，并重置回合计数。

**现状：**

- `clearLogs()` 方法存在（`BattleLogManager.ts:392`），但仅在战斗开始/重置时由 `BattleManager` / `BattleDataGenerator` 自动调用
- **UI 无手动清空入口**（`BattleLog.vue` 无对应按钮）

---

## 4. 战利品独立筛选（部分缺失）

**需求（原 §3.3）：**

> "战利品 | 系统 | 战斗"三个互斥筛选按钮，战利品类只显示物品/宝箱/战利品相关事件。

**现状：**

- 已改为页签方案（战斗 / 系统 / 调试）+ 关键字搜索
- 物品日志并入系统页签（`SYSTEM_TYPES` 含 `ITEM`），**无独立"战利品"分类入口**
- 功能上覆盖分类查看，但与需求的"战利品"独立维度不符

---

## 已实现（不再追踪，从文档删除）

- **颜色标识**：`LogSeg.vue` 语义片段——entity 阵营色芯片、damage 红、heal 绿、crit 黄、skill 蓝
- **事件类型模板**：普攻 / 暴击 / 闪避 / 技能 / buff / debuff / 治疗 / 战斗开始结束 / 回合 / 进场倒下，由 `BattleLogProjector` + `EffectRenderer` 实现
- **回合分组**：`RoundNarrativeRenderer` 按 turn 插入 round 块
- **筛选**：页签（战斗 / 系统 / 调试）+ 关键字搜索 + 状态明细开关
- **主题切换**：`tokens.scss` 定义 `:root[data-theme='light']`
- **性能**：`battleMaxLogs=500`、`maxDebugLogs=1000`、keyed 渲染，满足"单场 <1000 条无需虚拟滚动"
- **导出**：TXT / HTML（超出原需求）
