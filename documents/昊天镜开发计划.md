## 1. 参考蓝本提炼（三份文件定位与合成）

三份文件描述同一模块（战斗日志/调试/回放）的三个侧面，**互补不冲突**，合成即昊天镜：

| 文件 | 定位 | 关键布局 / 功能 |
| ---- | ---- | ---------------- |
| `调试日志UI示例.html` | 三栏检视器 v3（调试主界面） | 顶栏（品牌 + 过滤组 + 工具栏）+ 三栏（结构树 / 事件流卡片 / 数据检视）+ 状态栏（Battle_ID/seed/事件数/渲染/标记/步进）+ 战场回放缩略图 + 弹层（分支对比、条件断点、调试会话） |
| `调试日志UI-调试系统示例.html` | 调试系统（Schema 契约层） | 引导幕 + 指令栏（品牌/BATTLE 元信息/搜索/演示/压测/导出）+ 三栏（时间线 Timeline / 事件流 Event Stream / 深度检视 Inspector）+ 状态栏（SCHEMA/事件/判定/解析/SEED）+ Schema 校验报告弹层 + Web Worker 解析管线（parse→migrate→validate→done） |
| `调试日志UI-回放系统.html` | 回放系统（同源双投影） | 引导幕 + 指令栏（TRACE-EVENT[] / 复制深链 / 导出存档）+ 回放舞台 Projection 1（时间读数/回合 chip/阶段 chip/战场 arena/overlay/transport 传输条）+ 三栏（统一事件流 TraceEvent[] / 因果树 correlationId / 共用检视器 PAYLOAD+STEPS）+ 状态栏（STREAM/事件/锚点/SEED）+ 校验报告 |
| **`调试日志UI-V4.html`** | **最终蓝本 · 双工作台**（回放系统 ⇄ 调试系统） | **模式切换（1/2 快捷键）**：① 回放系统 = 回放舞台（arena + transport + seek 刻度 + follow）+ 双栏（事件流·TIMESTAMP 序 / 检视器）；② 调试系统 = 三栏（战斗时间线 Timeline / 事件流·卡片流 PROJECTION 2·CORRELATIONID / 深度检视）；公共：指令栏（品牌 + mode-switch + 元信息 + 复制深链 + 导出存档）、状态栏（STREAM v/事件/锚点/MODE/SEED/时钟）、校验报告弹层、Toast、键盘导航（空格/←→/↑↓/F/Esc）、深链 `#m=&e=`、PHASE_META 唯一分类表、验证器（Worker 注入）、存档 v2.0.0（initialState + events: TraceEvent[]） |

**合成结论**：昊天镜 = **回放系统 ⇄ 调试系统 双工作台 · 同一 TraceEvent[] 两个投影**（V4 口号，为最终蓝本）。
- 主布局取 V4 双工作台：模式切换 + 回放舞台（Projection 1）+ 调试三栏（Projection 2）+ 共用检视器渲染器 + 状态栏 + 校验报告；
- V4 之前的 file1/file2/file3 作为功能细节补充来源（断点/单步/书签/会话/分支对比/RNG 敏感性/Schema 契约/migrate 管线等）逐项并入；
- 数据源统一为 `TraceEvent[]` 存档 v2.0.0（V4 ARCHIVE 与项目现有 `trace-event.ts` 高度吻合，天然可复用），回放与调试消费同一索引。

## 2. 架构与目录

### 2.1 目录结构（新模块，与唤灵台 `views/` 完全分离）

```
src/presentation/modules/haotian/
├── HaotianMirror.vue        # 模块容器页（被 BattleArena 挂载，v-show 保活；含 1/2 模式切换）
├── views/
│   ├── CommandBar.vue       # 指令栏（品牌 + mode-switch + BATTLE/VERSION 元信息 + 复制深链 + 导出存档）
│   ├── ReplayStage.vue      # 回放舞台 Projection 1（stage-hd + arena + transport + seek 刻度 + follow）
│   ├── ReplayStream.vue     # 事件流 · TIMESTAMP 序（回放侧，含调试专属过滤）
│   ├── DebugTimeline.vue    # 战斗时间线 Timeline（回合节点树，dot 标记）
│   ├── DebugCards.vue       # 事件流 · 卡片流（调试侧，PROJECTION 2 · CORRELATIONID）
│   ├── Inspector.vue        # 共用检视器（PAYLOAD + STEPS + 各 section 渲染器，双模式共用）
│   ├── StatusBar.vue        # 状态栏（STREAM v/事件/锚点/MODE/SEED/时钟）
│   └── DiagPanel.vue        # 校验报告弹层
├── components/
│   ├── EventCard.vue        # 事件卡片（tone/徽章/多段 seg/展开）
│   ├── InspectorSection.vue # 结构化 section（formula/RNG/delta/chain/scores/KV/children）
│   └── Toast.vue            # 轻提示
├── composables/
│   └── useHaotianHotkeys.ts # 键盘导航（1/2/空格/←→/↑↓/F/Esc）
├── stores/
│   └── haotianStore.ts      # 模块状态（archive/indices/模式/选中/回放 P/cur sim/校验/Toast）
└── styles/
    └── haotian.scss         # 模块 scoped 样式（复用 tokens，工程化深色主题参考 V4）
```

> 共享组件（Dialog/Tabs/EmptyState/SpeedSelector 等）仍从 `presentation/components/` 复用，不复制。

### 2.3 数据源（同源双投影）

```
实时战斗
  battleStore.participants ──► BattleProjection ──► 快照/属性（检视器/缩略图）
  TraceEventCollector ──► TraceEvent[] ──► EventStream + CausalityTree（实时）

endBattle
```

## 6. 风险与注意事项

| 风险 | 应对 |
| ---- | ---- |
| 弹窗→页面化迁移的状态生命周期（v-show 保活） | 状态收敛进 haotianStore + battleStore，组件不持有战斗状态 |
| 回放与实时共享事件流 | 统一读 TraceEvent[]，回放用 RecordedBattle.traceEvents + initialState，不重放领域实体 |
| TraceEvent 缺 battle_start/battle_end 根事件（《统一战斗事件流方案》§1.3 注记） | P0 补根事件发射，作为时基零点 |
| Worker 注入纯函数与主线程双实现 | migrate/validate 为纯函数（仅字符串拼接），Worker 失败回退主线程 |
| 断点暂停与现有战斗循环冲突 | 先核对 DebugGate 能力，需扩展则收敛改动面 |

## 8. 资深使用者评审改进（2026-08-03 已实施）

按使用评审落地，分四级：

**P0 真实数据展示适配（核心）**
- `fromRecordedBattle` 归一化：`final→result`、`crit{rate,triggered}→rolls`（标记 derived）、`DamageStep→CalcStep`
- HP 快照：按伤害/治疗对 target 累减生成 snapshot（近似，未计护盾/过量，HACK），真实录制回放舞台可动

**P1 闭环效率**
- 战斗结束（唤灵台）自动保存录制 + 通知"可在昊天镜回放"
- 昊天镜「战斗记录」多场列表（名称/时间/事件数）替代"最新一场"
- 分支对比支持「从战斗记录选分支」
- 实时跟随：战斗未开始时选「实时战斗」保持待命，开战后自动接入
