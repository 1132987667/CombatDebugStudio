# 玩家属性创建 · 设计说明

> 背景：修行「角色」面板原先直接使用 `mock.ts` 硬编码的 `player` 数值与演示属性值。为让属性面板展示真实养成属性，建立配置驱动的玩家属性创建与计算链路，替代模拟数据。

## 一、数据链路

```
configs/xiyou/player.json  配置（基础属性 / 等级成长 / 经验表 / 加点转换）
        ↓ import
data/playerProfile.ts      创建与计算（createPlayerProfile / computePlayerBase / computeStatBonuses / expNeedForLevel）
        ↓ import
data/mock.ts               运行时状态（player reactive）+ 展示快照（playerAttributes computed）
        ↓ import
CharacterPanel.vue         属性面板（三层分组展示 + 悬浮说明）
```

## 二、配置：configs/xiyou/player.json

| 字段 | 说明 |
|------|------|
| `name` / `title` | 玩家名与称号 |
| `initialLevel` | 新建玩家初始等级 |
| `base` | 1 级基础属性（maxHealth / attackMin / attackMax / defense / speed / critRate / critDamage / maxEnergy / hit / dodge / hitValue / dodgeValue） |
| `growth` | 每级成长（maxHealth / attack / defense / speed） |
| `expTable` | 升级经验表（`level → expRequired`，缺档视为封顶） |
| `statBonuses` | 加点转换表（strength→attack、vitality→maxHealth、agility→speed、spirit→maxEnergy） |

与其它 `configs/xiyou/*.json` 一致，数值集中便于调优；不进封神榜 IDB（玩家初始配置静态，直接 import，不参与 `loadXiyouData` 覆盖）。

## 三、创建与计算：data/playerProfile.ts

- `createPlayerProfile({ level, exp, stats })`：创建满血满能量玩家快照，属性 = `base + (level-1)×growth` 叠加 `statBonuses` 加点加成
- `computePlayerBase(level)`：仅基础 + 等级成长（不含加点），供创建与重算复用
- `computeStatBonuses(stats)`：按当前加点分配汇总各属性加成（`config.statBonuses`）
- `expNeedForLevel(level)`：经验表查询，无档位返回 `Infinity`（封顶）

当前档位（level 5）计算结果与改造前演示档位一致：攻击 12-20、防御 8、速度 15、气血 420、能量 150、升级需 1500 经验。

## 四、运行时状态与展示快照：data/mock.ts

- `player`：`reactive(createPlayerProfile(...))`，运行时玩家状态（等级/经验/气血/能量/基础字段）
- `playerAttributes`：`computed` 实时快照，键为 `ATTRIBUTE_CODE`，值 = `player` 基础字段（含永久丹药改动）+ `computeStatBonuses(statPoints)` 加点加成；缺省键走领域默认值 `getAttrDv`

属性面板与加点天然联动：`playerAttributes` 依赖 `statPoints`（reactive），分配/重置加点即时反映在面板数值上。

## 五、面板展示分组（CharacterPanel.vue）

对齐唤灵台「角色监控」三层结构，共 26 项：

| 分组 | 项数 | 内容 |
|------|------|------|
| 基础属性 | 10 | 气血、能量 + core 层（攻击 / 防御 / 速度 / 暴击率 / 暴击伤害 / 免伤率 / 命中值 / 闪避值） |
| 属性加成 | 4 | 气血 / 攻击 / 防御 / 速度加成（当前无加成来源，值为 0） |
| 进阶属性（折叠） | 12 | 仅展示 `ATTRIBUTE_DISPLAY_CONFIG` 显式配置的 advanced 项（防御 5 / 攻击 2 / 元素 2 / 控制 2 / 辅助 1），值真实（大多为 0） |

> 过滤说明：未显式配置的属性（默认归 utility 组，多为 0/1 免疫抗性）不进玩家面板，避免调试噪音。

## 六、已知边界

- **永久丹药**（packStore）直接修改 `player` 基础字段，已并入展示（`playerAttributes` 读 `player` 字段）；但等级成长重算不会保留丹药增量（未记录"丹药增量基线"）
- **境界加成 / 装备加成** 尚未结构化并入计算（`realms.bonus`、`gearSlots.effect` 为描述文本，非 `Record<ATTRIBUTE_CODE, number>`）
- **升级入口**（`gainExp`）未接 UI，`expTable` 已备，后续升级时重算 `player` 字段即可
