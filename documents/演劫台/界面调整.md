### 2.3 装备卡片信息展示（Card UI）

每张装备卡片必须展示以下核心信息，严格遵循字号规范：

```text
┌──────────────────────────┐
│ [图标] 流云剑 (+12)  ★★☆ │ <- 名称与强化/星级
│ 轻型武器 · 灵猴道        │ <- 子类型与流派
│ 攻击 +45  攻速 +15%      │ <- 主属性
│ · 连击率 +6%             │ <- 随机词条 (最多展示3条，溢出折叠)

│ [ 强化 ] [ 洗练 ] [ 详情 ]│ <- 操作按钮区
└──────────────────────────┘
```

**UI 强制规范**：
1. **禁止 Emoji**：星级使用 SVG 星星图标（`<svg class="xy-star">`），不可使用 `⭐` 或 `★` 字符。
2. **字号底线**：所有文本（包括词条、属性值）不得小于 `--font-size-md`（14px），避免移动端阅读困难。
3. **颜色语义**：
   - 正面属性/词条：`var(--xy-ink-1)` 或 `var(--green)`
   - 负面属性（如重型武器速度-10%）：`var(--red)`
   - 阶位边框：凡品(灰) / 玄品(绿) / 地品(蓝) / 天品(紫) / 仙品(金)

### 3.2 物品详情与「可装备」判断

在 `PackPanel` 的物品抽屉（Drawer）中，「装备」按钮的启用状态需根据新槽位逻辑判断：

```typescript
// 伪代码：判断物品是否可装备到当前角色
function canEquip(item: Item, character: Character): boolean {
  if (!isEquipment(item)) return false;
  
  // 1. 槽位匹配
  const slot = item.slot; // 'weapon' | 'armor' | 'helmet' | 'boots' | 'charm' | 'ring'
  
  // 2. 流派/阵营限制（若有）
  if (item.factionRestriction && item.factionRestriction !== character.faction) return false;
  
  // 3. 职业/武器类型限制（如：灵猴道角色不能装备重型武器）
  if (item.subType === 'heavy_weapon' && character.school === 'linghou') return false;
  
  return true;
}
```

### 3.3 翻译与展示规则（REFERENCE_RULES）

根据项目全局规范，背包与装备面板的展示必须遵循：
1. **中文优先**：所有引用字段（如 `roleId`, `skillIds`, `affixIds`）在 UI 上一律翻译为中文名称。
2. **ID 保留**：原始英文 ID 保留在 HTML `title` 属性或悬浮 Tooltip 中，供调试使用。
3. **跨表翻译**：注意 `roles[].roleId` 可能跨越 `actors` 和 `enemies` 两张表，翻译函数 `translateId` 必须支持多表回退查找。


### 4.2 旧档迁移函数（migrateEquipmentSlots）

针对 v1.x 版本的旧存档（包含 `necklace`, `belt`, `bracelet`, `crown`），必须在 `IndexedDbStorage` 加载时执行静默迁移。

```typescript
function migrateEquipmentSlots(oldSave: any): SaveData {
  const newSave = { ...oldSave, version: "2.0.0" };
  const oldEquip = oldSave.equipment || {};
  
  newSave.equipment = {
    weapon: oldEquip.weapon || null,
    armor: oldEquip.armor || null,
    // 迁移规则：
    // 项链(necklace) + 冠冕(crown) -> 头盔(helmet)
    helmet: oldEquip.necklace || oldEquip.crown || null, 
    // 腰带(belt) -> 靴子(boots)
    boots: oldEquip.belt || null,
    // 手镯(bracelet) -> 戒指(ring)
    ring: oldEquip.bracelet || null,
    charm: oldEquip.charm || null
  };

  // 将未映射的旧饰品移入背包（inventory.equipments），防止资产丢失
  const migratedIds = [newSave.equipment.helmet, newSave.equipment.boots, newSave.equipment.ring];
  const lostItems = [oldEquip.necklace, oldEquip.crown, oldEquip.belt, oldEquip.bracelet]
    .filter(id => id && !migratedIds.includes(id));
    
  if (lostItems.length > 0) {
    newSave.inventory.equipments.push(...lostItems);
    // 触发 UI 提示：「检测到旧版饰品，已自动转换为新槽位或移入背包」
  }

  return newSave;
}
```

## 6. UI/UX 强制规范（石匠守则）

为避免后续开发中出现视觉与交互退化，所有涉及装备/背包的组件必须遵守以下守则：

1. **绝对禁止 Emoji**：
   - ❌ 错误：`<span>⭐⭐⭐</span>` 或 `<button>🔨 强化</button>`
   - ✅ 正确：使用 `<svg class="icon-star">` 和 `<svg class="icon-hammer">`。
   - 控制类符号（⏮ ⏪ ▶ ⏸ ⚡）同样禁止，必须用 SVG 矢量图标。

2. **字号底线**：
   - 任何文本（包括辅助说明、词条数值）不得小于 `--font-size-md`（14px）。
   - 若空间不足，应优化布局或使用 Tooltip 折叠，而非缩小字号。

3. **色彩语义化**：
   - 必须使用 CSS 变量（如 `var(--xy-ink-1)`, `var(--green)`），禁止硬编码 Hex 颜色。
   - 确保在「水墨/暗色」主题下对比度符合 WCAG AA 标准。

4. **空状态处理**：
   - 当背包或槽位为空时，必须展示统一的 `EmptyState` 组件（含 SVG 插图与引导文案），禁止留白或显示 `undefined`。
