# 现象
### P3-1：守护者被动技能类型分布单一

**现象**：25 个守护者被动中：
- `ON_TURN_START`（回合开始治疗）：10 个
- `ON_DAMAGE_TAKEN`（受击防御/反伤）：9 个
- `ON_BLOCK_SUCCESS`（格挡后防御）：2 个
- `ON_DODGE_SUCCESS`（闪避后加速/治疗）：3 个
- `ON_ATTACK_LANDED`（攻击后加攻）：1 个

**建议**：后续迭代中补充 `ON_KILL`（击杀后回能）、`ON_CRIT_LANDED`（暴击后追加效果）等类型。
