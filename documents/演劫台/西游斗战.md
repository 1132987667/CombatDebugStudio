# 说明

简单小型的回合制战斗游戏游戏，背景: 西游记

# 核心玩法

玩家战胜敌人，收集材料、图纸、丹药，打造强化极品装备，提升角色能力，战胜最终BOSS
其中掉落物环环相扣，各有作用

# 美术风格

不使用任何形式的图片、图标、字体

## 水墨风格设计说明

### UI 设计

- 所有 UI 元素（按钮、文本框、弹窗等）必须符合项目的视觉风格
- 所有 UI 元素的交互行为必须符合用户习惯
- 要紧凑布局，避免元素之间的过大间距

### 艺术哲学

- 「留白」「气韵生动」

### 色彩体系

- 墨色系列: 焦墨(#1a1a1a)、浓墨(#333333)、淡墨(#666666)、清墨(#999999)
- 背景: 宣纸白(#F8F5F0)、米色(#FAF0E6)、象牙白(#FFFFF0)
- 点缀: 朱红印章色(#C41E3A)、青绿山水色(#2E8B57)
- 金色点缀(#D4AF37)用于高端装饰

### 交互反馈

- 悬停时微妙的水墨晕开效果

### 氛围

水墨风格传达宁静、深邃、诗意的东方美学。用户感受到古典与现代的完美融合。

# 游戏目标

战胜各场景boss即游戏胜利
分为10个场景，每个场景分为: 简单、普通、核心困难，对应敌人等级为: 1-5,5-10,11-15

# 人物属性

等级，名称，能量(上限为100，初始值为25)，气血，最小攻击-最大攻击，防御，速度，暴击率(默认为10%)，暴击伤害(默认125)
气血%，攻击%，防御%，速度%，

## 能量机制

每回合自动获得25能量，受到攻击获得15能量
50能量释放小技能，100能量释放大招

## 技能体系优化

玩家可随意重置技能选择
开局可解锁一个小技能，5级可选择被动 + 小技能，10级可解锁大招, 15级可选择被动

卡片分为三种状态: 已选择(金色) 未选择(灰色) 查看(蓝色)，对应颜色边框和淡色背景色

在以上内容下方，为两个按钮，一个为确认选择，一个为重置

### 轻型套装「灵猴三变」:

- 2件:连击率+10%，触发连击时回复5点能量
- 4件:触发连击时，恢复15能量，并使下次攻击伤害+10%（可叠加3层）

### 中型套装「金睛火眼」:

- 2件:暴击率+8%，暴击伤害+10%
- 4件:暴击时，无视30%防御，并恢复8%最大气血

### 重型套装「不动明王」:

- 2件:格挡率+12%，格挡成功时反击40%攻击力伤害
- 4件:成功格挡时，获得一个相当于10%最大气血的护盾（持续2回合）

## 物品分类

材料:木材（桃/松/铁）、矿石（铜/铁/金精）、灵水/灵气、晶球（开启获得异矿/灵水/灵气）。
丹药:治疗、攻/防/速/全属性临时提升。
装备:武器（轻/中/重）、衣服（皮/木/铠）、饰品（护符/戒指/项链/腰带/手镯/冠冕）。
杂物: 用于出售换取金钱

1-10级，每级提升5%装备最大属性，初始0级
即装备属性加成 = 基础属性 × 品质系数 × (1 + 技艺等级 × 5%)
每次制作对应装备，提升对应技艺经验+1，到达升级经验要求，则对应技艺等级+1，经验值重置为0

# 战斗

战斗动画:

- 玩家和敌人轮流进行攻击，每个回合显示攻击结果（伤害值、是否暴击、是否触发BUFF等）。
- 战斗结束后，显示战斗结果（胜利/失败），并奖励经验、金钱和物品。

## 规则

模式:1v1 回合制。
先手机制:基于双方【速度】属性，速度高者先行动。
胜负判定:一方气血归零即战斗结束。
自动战斗:提供“自动战斗”开关，开启后AI自动选择技能（优先使用大招，其次小技能，最后普攻）。

## 伤害公式

基础伤害 = 攻击方攻击力 - 防御方防御力
暴击伤害 = 基础伤害 × 暴击伤害%
最终伤害 = max(1, 基础伤害/暴击伤害) // 保底1点伤害

遵循「留白」与「气韵生动」的水墨美学原则，采用三栏式黄金分割布局，各功能区域边界以淡墨线条勾勒，形成层次分明的视觉层次。界面整体采用宣纸底色(#F8F5F0)，核心元素以浓墨(#333333)呈现，关键交互点以朱红印章色(#C41E3A)点缀，营造出古典雅致的东方韵味。

### 1. 左侧区域（场景画卷 - 场景列表）

- **视觉风格**:卷轴式设计，顶部以书法体题字「降妖路引」
- **内容布局**:
  - 加载 #场景 中的数据，以水墨山水插画+文字描述的卡片形式展示
  - 每个场景卡片包含:场景名称（书法体）、等级区间、简短背景故事
  - 当前已解锁场景以浓墨高亮，未解锁场景以淡墨(#999999)半透明显示
  - 场景卡片悬停时呈现墨晕扩散效果，点击时有印章盖下的视觉反馈
- **交互体验**:支持上下滚动浏览，点击场景卡片后，中间战斗区域平滑过渡到对应场景

### 2. 中间区域（战斗禅台 - 玩家与战斗信息）

作为界面核心区域，采用圆形禅台布局，突出战斗主题

#### 2.1 顶部（场景与敌情）

- 「当前场景名」以大字书法体居中显示，下方用小字标注场景难度
- 下一行以「墨韵气泡」效果显示当前场景可能出现的敌人信息:
  - 例如:「水蛇精[14]」，其中名称为黑色，等级为朱红色
  - 多个敌人时，以横向排列的墨点连接，点击可查看详细属性

#### 2.2 中上部（气血与能量）

- 采用左右对称布局，左侧显示玩家信息，右侧显示敌人信息
- **气血条**:
  - 形状:毛笔笔触状，红色渐变填充（朱红→淡红）
  - 显示:"当前气血/最高气血"（如「350/420」）
  - 特色:受击时气血条有墨水泼洒效果，回气血时有墨色晕染动画
- **能量条**:
  - 形状:祥云环绕状，金色渐变填充（金黄→淡金）
  - 显示:"当前能量/最高能量"（如「120/150」）
  - 特色:能量增长时有祥云飘动效果，满能量时边缘发光

#### 2.3 中部（技能灵台）

- 四个技能按钮呈菱形布局，中心为角色立绘
- 按钮设计:
  - **自动战斗**:圆形开关，开启时呈现金色光晕
  - **小技能**（2个）:方形印章式按钮，淡蓝底色
  - **大技能**:圆形印章式按钮，朱红底色，满能量时边缘闪烁
- 交互:点击技能时有毛笔挥毫动画，技能冷却时呈灰色半透明

#### 2.4 底部（战斗心经 - 战斗日志）

- 设计:卷轴式文本框，顶部有「战斗心经」书法标题
- 功能:实时显示战斗过程信息，如「玩家使用破甲斩，造成120点伤害」
- 特色:新日志以淡墨渐显方式出现，关键信息（如暴击、技能释放）以朱红强调
- 交互:支持上下滚动查看历史记录，点击日志条目可查看详细战斗数据

### 3. 右侧区域（功能宝阁 - 游戏功能模块）

采用「多宝阁」式模块化设计，根据当前选中的功能标签显示对应内容

#### 3.1 背包（乾坤袋）

- 顶部标签栏:「材料」、「装备」、「丹药」三个水墨书签式标签
- 中间区域:
  - 物品以「水墨卡片」形式展示，卡片上有物品简笔画
  - 悬停效果:显示物品名称、属性和使用方法的墨韵气泡
  - 交互:点击物品卡片可使用或查看详情，支持拖拽排序

#### 3.2 技艺（修行录）

- 显示人物所有技艺和等级的卷轴式列表
- 每个技艺包含:技艺名称、等级、当前进度条、下一等级效果
- 特色:等级提升时有墨韵扩散动画，高等级技艺以金色边框突出

#### 3.3 角色（降妖录）

- 左侧:角色立绘，随等级提升解锁不同姿态
- 右侧:
  - 等级信息（书法体大字显示）
  - 人物属性面板，各项属性以图标+文字形式展示
  - 属性值变化时有墨色浮动动画

#### 3.4 洞府（修炼洞）

- 显示当前洞府中可进行的操作的「丹炉」式布局
- 各项操作（如炼丹、炼器）以圆形按钮形式展示，按钮上有对应图标
- 悬停时显示操作详情和所需材料，点击后进入对应功能界面

### 4. 最右侧区域（功能菜单 - 四象栏）

采用「四象」主题的纵向标签页设计，对应四个核心功能

- 功能标签:「背包」、「技艺」、「角色」、流派、「洞府」
- 设计:每个标签为方形印章样式，顶部有对应功能的简笔画图标
- 交互:
  - 当前选中标签以朱红底色突出显示
  - 悬停时标签有墨晕扩散效果
  - 切换标签时有书页翻动动画

### 界面动效与交互细节

1. **墨韵系统**:所有交互元素都有相应的墨色动画效果
2. **过渡动画**:功能模块切换采用卷轴展开/收起动画
3. **反馈机制**:按钮点击有印章盖下的视觉反馈和微妙音效
4. **响应式设计**:适配不同屏幕尺寸，核心功能始终保持在可视区域
5. **辅助功能**:支持文字大小调整、高对比度模式等无障碍设计

### 整体设计原则

- **主题一致性**:所有界面元素都融入水墨西游主题
- **用户友好**:操作流程简洁直观，信息层级清晰
- **视觉美感**:遵循传统东方美学，营造沉浸式游戏体验
- **性能优化**:动画效果流畅不卡顿，保证游戏运行效率

整体布局既符合现代游戏UI的易用性要求，又充分体现了西游记主题的古典美学，为玩家提供一个视觉愉悦、操作流畅的游戏界面。

游戏需支持完整的存档系统，包含自动存档、手动存档、自动加载和存档导出功能。存档数据存储于浏览器localStorage中。、

## 存档内容

存档应包含以下游戏状态数据：

玩家属性
当前选择场景与难度
背包物品（材料、丹药、装备）
已穿戴装备
技能选择与流派
技艺等级与经验
任务进度
在每个场景战斗次数，与每种敌人战斗次数，包括(总次数、胜利次数、失败次数)
