# 说明

简单小型的回合制战斗游戏游戏，背景: 西游记

# 核心玩法

玩家战胜敌人，收集材料、图纸、丹药，打造强化极品装备，提升角色能力，战胜最终BOSS
其中掉落物环环相扣，各有作用

# 美术风格

不使用任何形式的图片、图标、字体

## 水墨风格设计说明

### UI 设计

- 所有 UI 元素（按钮、文本框、弹窗等）必须符合项目的视觉风格
- 所有 UI 元素的交互行为必须符合用户习惯
- 要紧凑布局，避免元素之间的过大间距

### 艺术哲学

- 「留白」「气韵生动」

### 色彩体系

- 墨色系列: 焦墨(#1a1a1a)、浓墨(#333333)、淡墨(#666666)、清墨(#999999)
- 背景: 宣纸白(#F8F5F0)、米色(#FAF0E6)、象牙白(#FFFFF0)
- 点缀: 朱红印章色(#C41E3A)、青绿山水色(#2E8B57)
- 金色点缀(#D4AF37)用于高端装饰

### 交互反馈

- 悬停时微妙的水墨晕开效果

### 氛围

水墨风格传达宁静、深邃、诗意的东方美学。用户感受到古典与现代的完美融合。

# 游戏目标

战胜最终BOSS（六耳猕猴）即游戏胜利
分为10个场景，每个场景分为: 简单、普通、困难 三个难度，敌人等级随关卡递增（1-27级）
每关通关困难难度解锁该关BOSS，通关全部场景后解锁最终BOSS

# 人物属性

等级，名称，能量(上限为150，初始值为25)，气血，最小攻击-最大攻击，防御，速度，暴击率(默认为10%)，暴击伤害(默认125)
气血%，攻击%，防御%，速度%，

## 能量机制

每回合自动获得25能量，受到攻击获得15能量
50能量释放小技能，150能量释放大招

## 技能体系优化

玩家可随意重置技能选择
开局可解锁一个小技能，5级可选择被动 + 小技能，10级可解锁大招, 15级可选择被动

### 轻型套装「灵猴三变」:

- 2件:连击率+10%，触发连击时回复5点能量
- 4件:触发连击时，恢复15能量，并使下次攻击伤害+10%（可叠加3层）

### 中型套装「金睛火眼」:

- 2件:暴击率+8%，暴击伤害+10%
- 4件:暴击时，无视30%防御，并恢复8%最大气血

### 重型套装「不动明王」:

- 2件:格挡率+12%，格挡成功时反击40%攻击力伤害
- 4件:成功格挡时，获得一个相当于10%最大气血的护盾（持续2回合）

## 物品分类

材料:木材（桃/松/铁）、矿石（铜/铁/金精）、灵水/灵气、晶球（开启获得异矿/灵水/灵气）。
丹药:治疗、攻/防/速/全属性临时提升。
装备:武器（轻/中/重）、衣服（皮/木/铠）、饰品（护符/戒指/项链/腰带/手镯/冠冕）。
杂物: 用于出售换取金钱

# 敌人

有小技能和大招

等级1-27，随场景递增（各场景具体分布见 #场景）

## 词缀系统

词缀（Affix）是附加在敌人/角色身上的**常驻属性标签**：战斗开始时按规则将属性修正（比例修正）
直接作用于基础属性，持续整场。词缀**只做属性修正**；能力型效果（吸血/反伤/格挡/中毒/净化等）
交给 Buff 系统实现，两者职责分离，不混淆。
词缀不与装备词条混淆：装备词条是玩家装备的强化，词缀是敌人的难度标签。

参考刷子游戏（暗黑/流放之路/火炬之光）与回合制游戏的词缀设计，词缀覆盖**六大战类**：
攻伐（攻击/暴击/暴伤/伤害提升/真实伤害/连击）、守御（防御/免伤/闪避/反伤）、
五行（金木水火土攻）、生存（气血/回复/治疗加成）、资源（能量）、控制（控制成功率/抗性）。

### 词缀分配规则

- 每个难度的第3个敌人（守护者）固定附加 1 个增益词缀
- BOSS 固定附加 1 个增益词缀 + 1 个减益词缀（减益词缀作用于玩家，见下）
- 增益词缀从对应档位中随机选取
- 同一敌人不重复附加同名词缀

# 战斗

战斗动画:

- 玩家和敌人轮流进行攻击，每个回合显示攻击结果（伤害值、是否暴击、是否触发BUFF等）。
- 战斗结束后，显示战斗结果（胜利/失败），并奖励经验、金钱和物品。

## 规则

模式:支持 1v1 与 多v多（NvN）回合制。
- 常规敌人战斗为 1v1。
- BOSS 战支持召唤单位（如小花妖、小蜘蛛）形成 1vN 或 NvN。
- 多目标技能通过目标选择器决定（single_enemy 单体 / all_enemies 全体 / front_row 前排 / all_allies 全体友方）。
先手机制:基于双方【速度】属性，速度高者先行动；多v多时按速度降序决定行动顺序。
胜负判定:一方（玩家或敌方全体）气血归零即战斗结束。
自动战斗:提供“自动战斗”开关，开启后AI自动选择技能（优先使用大招，其次小技能，最后普攻）。
能量获取:每回合开始自动+25，受到攻击+15。

## 伤害公式

每个技能用公式字符串定义伤害，最终伤害 = max(1, 公式结果)（保底1点）。
- 普攻: a.atk - b.def × 0.5
- 技能倍率型: 攻击力 × 技能系数 - 目标防御 × 系数（各技能独立定义，见技能配置）
- 无视防御型: 攻击力 × 技能系数（目标防御按技能比例扣除）
- 暴击: 命中后判定暴击率，暴击时伤害 × 暴击伤害%(基础125%)
- 闪避: 目标闪避率判定，闪避成功不造成伤害（技能命中前结算）
- 固定伤害: 不经过防御/暴击，直接扣除气血

### 整体布局理念

遵循「留白」与「气韵生动」的水墨美学原则，采用三栏式黄金分割布局，各功能区域边界以淡墨线条勾勒，形成层次分明的视觉层次。界面整体采用宣纸底色(#F8F5F0)，核心元素以浓墨(#333333)呈现，关键交互点以朱红印章色(#C41E3A)点缀，营造出古典雅致的东方韵味。

### 1. 左侧区域（场景画卷 - 场景列表）

- **视觉风格**:卷轴式设计，顶部以书法体题字「降妖路引」
- **内容布局**:
  - 加载 #场景 中的数据，以水墨山水插画+文字描述的卡片形式展示
  - 每个场景卡片包含:场景名称（书法体）、等级区间、简短背景故事
  - 当前已解锁场景以浓墨高亮，未解锁场景以淡墨(#999999)半透明显示
  - 场景卡片悬停时呈现墨晕扩散效果，点击时有印章盖下的视觉反馈
- **交互体验**:支持上下滚动浏览，点击场景卡片后，中间战斗区域平滑过渡到对应场景

### 2. 中间区域（战斗禅台 - 玩家与战斗信息）

作为界面核心区域，采用圆形禅台布局，突出战斗主题

#### 2.1 顶部（场景与敌情）

- 「当前场景名」以大字书法体居中显示，下方用小字标注场景难度
- 下一行以「墨韵气泡」效果显示当前场景可能出现的敌人信息:
  - 例如:「水蛇精[14]」，其中名称为黑色，等级为朱红色
  - 多个敌人时，以横向排列的墨点连接，点击可查看详细属性

#### 2.2 中上部（气血与能量）

- 采用左右对称布局，左侧显示玩家信息，右侧显示敌人信息
- **气血条**:
  - 形状:毛笔笔触状，红色渐变填充（朱红→淡红）
  - 显示:"当前气血/最高气血"（如「350/420」）
  - 特色:受击时气血条有墨水泼洒效果，回气血时有墨色晕染动画
- **能量条**:
  - 形状:祥云环绕状，金色渐变填充（金黄→淡金）
  - 显示:"当前能量/最高能量"（如「120/150」）
  - 特色:能量增长时有祥云飘动效果，满能量时边缘发光

#### 2.3 中部（技能灵台）

- 四个技能按钮呈菱形布局，中心为角色立绘
- 按钮设计:
  - **自动战斗**:圆形开关，开启时呈现金色光晕
  - **小技能**（2个）:方形印章式按钮，淡蓝底色
  - **大技能**:圆形印章式按钮，朱红底色，满能量时边缘闪烁
- 交互:点击技能时有毛笔挥毫动画，技能冷却时呈灰色半透明

#### 2.4 底部（战斗心经 - 战斗日志）

- 设计:卷轴式文本框，顶部有「战斗心经」书法标题
- 功能:实时显示战斗过程信息，如「玩家使用破甲斩，造成120点伤害」
- 特色:新日志以淡墨渐显方式出现，关键信息（如暴击、技能释放）以朱红强调
- 交互:支持上下滚动查看历史记录，点击日志条目可查看详细战斗数据

### 3. 右侧区域（功能宝阁 - 游戏功能模块）

采用「多宝阁」式模块化设计，根据当前选中的功能标签显示对应内容

#### 3.1 背包（乾坤袋）

- 顶部标签栏:「材料」、「装备」、「丹药」三个水墨书签式标签
- 中间区域:
  - 物品以「水墨卡片」形式展示，卡片上有物品简笔画
  - 悬停效果:显示物品名称、属性和使用方法的墨韵气泡
  - 交互:点击物品卡片可使用或查看详情，支持拖拽排序

#### 3.2 技艺（修行录）

- 显示人物所有技艺和等级的卷轴式列表
- 每个技艺包含:技艺名称、等级、当前进度条、下一等级效果
- 特色:等级提升时有墨韵扩散动画，高等级技艺以金色边框突出

#### 3.3 角色（降妖录）

- 左侧:角色立绘，随等级提升解锁不同姿态
- 右侧:
  - 等级信息（书法体大字显示）
  - 人物属性面板，各项属性以图标+文字形式展示
  - 属性值变化时有墨色浮动动画

#### 3.4 洞府（修炼洞）

- 显示当前洞府中可进行的操作的「丹炉」式布局
- 各项操作（如炼丹、炼器）以圆形按钮形式展示，按钮上有对应图标
- 悬停时显示操作详情和所需材料，点击后进入对应功能界面

### 4. 最右侧区域（功能菜单 - 四象栏）

采用「四象」主题的纵向标签页设计，对应四个核心功能

- 功能标签:「背包」、「技艺」、「角色」、流派、「洞府」
- 设计:每个标签为方形印章样式，顶部有对应功能的简笔画图标
- 交互:
  - 当前选中标签以朱红底色突出显示
  - 悬停时标签有墨晕扩散效果
  - 切换标签时有书页翻动动画

### 界面动效与交互细节

1. **墨韵系统**:所有交互元素都有相应的墨色动画效果
2. **过渡动画**:功能模块切换采用卷轴展开/收起动画
3. **反馈机制**:按钮点击有印章盖下的视觉反馈和微妙音效
4. **响应式设计**:适配不同屏幕尺寸，核心功能始终保持在可视区域
5. **辅助功能**:支持文字大小调整、高对比度模式等无障碍设计

### 整体设计原则

- **主题一致性**:所有界面元素都融入水墨西游主题
- **用户友好**:操作流程简洁直观，信息层级清晰
- **视觉美感**:遵循传统东方美学，营造沉浸式游戏体验
- **性能优化**:动画效果流畅不卡顿，保证游戏运行效率

整体布局既符合现代游戏UI的易用性要求，又充分体现了西游记主题的古典美学，为玩家提供一个视觉愉悦、操作流畅的游戏界面。

## BOSS战触发规则

- 每关通关【困难】难度后，解锁该关场景BOSS挑战入口
- 隐藏BOSS：对应关卡通关后，在场景深处刷新隐藏入口
- 三大BOSS：对应关卡通关后解锁独立挑战
- 最终BOSS：通关全部10个场景的困难难度 + 击败全部场景BOSS后解锁

## 关卡/难度解锁规则

- 关卡1默认解锁；关卡N（N≥2）需通关关卡N-1的【简单】难度解锁
- 难度解锁:通关当前难度的所有敌人（各难度首个战斗）后解锁下一难度（简单→普通→困难）
- 通关困难难度解锁该关场景BOSS
- 技能/流派:开局解锁1小技能，5级解锁被动+小技能，10级解锁大招，15级解锁额外被动

## BOSS掉落

- 场景BOSS:对应关卡的三阶材料 + 灵气 + 随机1件稀有物品（如三阶晶球、珍稀丹药）
- 隐藏BOSS:神秘宝箱（必掉，开出灵气碎片/丹药）+ 对应稀有材料
- 三大BOSS:九转金丹 + 专属材料（牛魔角/毒囊/鹏羽，用于制作传说装备）
- 最终BOSS:胜利即通关，奖励混元灵气×1 + 九转金丹×3 + 传说装备

# 任务系统

建立“西行志”任务系统:提供阶段性目标，如“收集10个桃木”、“制作任意一件精良装备”，奖励包含经验、金钱和稀有材料。

# 存档功能概述

游戏需支持完整的存档系统，包含自动存档、手动存档、自动加载和存档导出功能。存档数据存储于浏览器localStorage中。、

## 存档内容

存档应包含以下游戏状态数据：

玩家属性
当前选择场景与难度
背包物品（材料、丹药、装备）
已穿戴装备
技能选择与流派
技艺等级与经验
任务进度
在每个场景战斗次数，与每种敌人战斗次数，包括(总次数、胜利次数、失败次数)
