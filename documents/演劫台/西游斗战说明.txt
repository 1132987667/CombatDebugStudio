# 说明
简单小型的回合制战斗游戏游戏，背景: 西游记

# 核心玩法
玩家收集材料打造装备，提升角色能力，战胜最终BOSS
其中掉落物环环相扣，各有作用

# 平台
PC端

# 实现技术
VUE3 相应动画库 或粒子库


# 美术风格
不使用任何图片、图标
## 水墨风格设计说明
### UI 设计
- 所有 UI 元素（按钮、文本框、弹窗等）必须符合项目的视觉风格
- 所有 UI 元素的交互行为必须符合用户习惯
- 要紧凑布局，避免元素之间的过大间距
### 艺术哲学
- 「留白」：空白不是虚无，而是意境的延伸
- 「墨分五色」：焦、浓、重、淡、清，层次丰富
- 「气韵生动」：追求神韵而非形似
- 「虚实相生」：有无相生，动静结合
### 色彩体系
- 墨色系列：焦墨(#1a1a1a)、浓墨(#333333)、淡墨(#666666)、清墨(#999999)
- 背景：宣纸白(#F8F5F0)、米色(#FAF0E6)、象牙白(#FFFFF0)
- 点缀：朱红印章色(#C41E3A)、青绿山水色(#2E8B57)
- 金色点缀(#D4AF37)用于高端装饰
### 视觉元素
- 水墨山水：使用 CSS 渐变和 filter 模拟远山近水
- 毛笔笔触：不规则边缘的墨迹效果
- 书法文字：传统书法字体或手写体
- 印章：红色方形或圆形印章作为装饰
- 竹、梅、兰、菊等传统纹样
- 宣纸纹理：微妙的纸张肌理
### 布局特点
- 大量留白，呼吸感强
- 不对称构图，追求自然之美
- 垂直阅读方向的文字排列
- 元素之间保持疏朗距离
### 效果技巧
- 墨晕效果：使用 filter: blur()和 opacity 渐变
- 泼墨效果：随机形状的墨迹装饰
- 干笔效果：虚实交替的线条
- 晕染效果：边缘柔化的色块
### 排版
- 草书大标题，笔势飞扬
- 行书副标题，流畅端正
- 楷书正文，工整易读
- 竖排装饰文字，营造古典氛围
- 文字大小对比强烈（text-xl 到 text-8xl）
### 交互反馈
- 墨迹扩散动画
- 元素渐隐渐现如云雾
- 悬停时微妙的水墨晕开效果
### 氛围
水墨风格传达宁静、深邃、诗意的东方美学。用户感受到古典与现代的完美融合。

# 目标
战胜最终boss即游戏胜利
存在5个隐藏BOSS和三个大BOSS

分为10个场景，每个场景分为三个难度，需命名三个难度，对应敌人等级为: 1-3,4-6,7-9，为关卡1-10生成对应的场景名
数据格式为:
关卡X
敌人: 难度1敌人、难度2敌人、难度3敌人
掉落: 难度1敌人掉落、难度2敌人掉落、难度3敌人掉落
如果未直接写明，而是用()代替，如(杂物、宝物用于出售获取金钱)，则需要你进行设计


# 属性

名称，等级，能量，气血，最小攻击-最大攻击，防御，速度，暴击率，暴击伤害(默认125)
气血%，攻击%，防御%，速度%，
能量上限150，50释放小技能，150释放大招

## 能量机制
每回合自动获得20能量
受到攻击获得10能量
小技能消耗50能量
大招消耗150能量

## 玩家技能设计
基础技能（无消耗）：普攻，造成100%攻击力伤害
小技能（50能量）：
破甲斩：造成120%攻击力伤害，无视30%防御
治疗术：恢复(50+等级×5)气血
疾风步：提升30%速度，持续3回合
大招（150能量）：
金刚怒：造成200%攻击力伤害，30%几率眩晕1回合
佛光普照：恢复150+等级×10气血，驱散所有负面状态
齐天战意：提升50%攻击力和30%暴击率，持续5回合

# 物品
移动到物品上，可以看到它的作用，如 制造哪些装备

桃木、松木、铁木
异矿 三种 对应三阶装备 矿晶球开启获得 用来强化武器
灵水 三种 对应三阶装备 矿晶球开启获得 用来强化饰品

# 装备
装备没有等级要求，由场景中敌人掉落材料制作，技艺等级决定制作装备品质，还需消耗金钱
武器、衣服、饰品都分三阶，品质如下
装备品质与词条：
破损（0词条）：基础属性90%
普通（1词条）：基础属性100%，随机1条副属性
精良（2词条）：基础属性110%，随机2条副属性
极品（3词条）：基础属性120%，随机3条副属性

## 强化
消耗对应材料提升装备基础属性
强化上限：一阶+5，二阶+10，三阶+15
强化失败机制：50%几率失败，但不降级，仅消耗材料

## 装备升星
默认0星、最高三星、升星需要相同装备，数量为: 3 6 9
每星提升10%基础属性 // 暂不解锁1条额外词条

# BUFFS

眩晕：跳过下一回合

虚弱：降低30%攻击力
破甲：降低30%防御力
迟缓：降低30%速度
正面状态：
激怒：提升30%攻击力，降低15%防御

灵巧：提升30%速度，降低15%防御
精准：提升30%暴击率
坚韧：提升30%最大气血
狂热：每次攻击额外获得10能量

# 战斗
## 规则
1v1回合制战斗
出手顺序：根据速度属性决定，速度高者先行动
战斗持续到一方气血归零

## 支持手动战斗和自动战斗

## 伤害公式
基础伤害 = 攻击方攻击力 - 防御方防御力
暴击伤害 = 基础伤害 × 暴击伤害%
最终伤害 = max(1, 基础伤害/暴击伤害)  // 保底1点伤害
