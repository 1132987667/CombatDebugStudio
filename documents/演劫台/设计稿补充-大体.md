作为一名专业系统策划，在补全了**装备系统**之后，我们需要对《西游斗战》的其他核心子系统进行深度梳理与规则补完。

当前知识库中虽然列出了大量的 Buff、材料、敌人和任务，但缺乏**底层结算规则、概率公式、AI逻辑以及系统间的联动机制**。以下为您输出《全子系统深度补完设计稿》，确保游戏在开发阶段有严密的逻辑支撑。

# 一、 战斗与状态结算子系统 (Combat & Status)

战斗是游戏的核心，知识库中定义了多达 20 余种 Buff/Debuff，如果不明确**结算轴与优先级**，开发时必然会出现逻辑冲突（例如：先算闪避还是先算护盾？中毒和重伤如何结算？）。

### 1.1 回合行动轴与结算优先级
每个回合必须严格按照以下 **5 个阶段** 进行结算，不可乱序：

| 阶段 | 名称 | 结算内容 | 规则说明 |
|---|---|---|---|
| **Phase 1** | **回合开始** | 能量恢复、Buff 持续时间递减、持续伤害结算 | 玩家/敌人获得 25 能量；中毒/燃烧/流血在此阶段扣血；若因持续伤害死亡，直接判负，不进入行动阶段。 |
| **Phase 2** | **行动判定** | 控制状态判定、速度排序 | 判定是否处于【眩晕/沉睡/束缚/麻痹】，若是则跳过行动；按【速度】决定多方行动顺序。 |
| **Phase 3** | **行动执行** | 技能释放、普攻、闪避/暴击判定 | 攻击方发起动作 $\rightarrow$ 判定目标【闪避】 $\rightarrow$ 判定【命中】 $\rightarrow$ 判定【暴击】 $\rightarrow$ 计算基础伤害。 |
| **Phase 4** | **伤害结算** | 护盾吸收、格挡、反伤、真实伤害 | 伤害先扣【护盾】 $\rightarrow$ 触发【格挡/免伤】 $\rightarrow$ 扣除气血 $\rightarrow$ 触发【反伤/受击回能】。 |
| **Phase 5** | **回合结束** | 死亡判定、状态刷新、清理临时 Buff | 气血 $\le 0$ 则死亡；清除本回合到期的临时 Buff（如丹药的 3 回合增益）。 |

### 1.2 流派能量循环模型
知识库中能量上限为 150，每回合 +25，受击 +15。这会导致不同流派的节奏完全不同，必须在数值上予以明确：

*   **灵猴道（轻型/高频）**：依赖普攻和连击。由于攻击频率高，触发“受击回能”或“攻击回能”词条的概率大，**大招释放频率最快**（约 4-5 回合一次）。
*   **金行道（中型/爆发）**：依赖技能爆发。通常需要“蓄力”或“弱点打击”，能量积累中等，**大招释放频率中等**（约 6-7 回合一次），依赖丹药或元气丹加速。
*   **磐石道（重型/反击）**：攻速慢（-20%），但防御高、受击多。极度依赖“受击能量获取”词条，**前期极慢，后期靠挨打快速充能**。

### 1.3 自动战斗 AI 策略树
为了保证挂机体验，自动战斗不能只是“无脑平A”，需要内置基于流派和状态的策略树：

```text
IF (自身气血 < 30%) AND (有疗伤丹药) -> 使用疗伤丹药
IF (自身有负面状态) AND (有净化技能/丹药) -> 使用净化
IF (能量 >= 150) AND (大招可用) -> 释放大招
IF (能量 >= 50) AND (小技能可用) AND (敌人无护盾/免伤) -> 释放小技能
IF (敌人处于破绽/低血量) -> 优先使用高爆发技能
ELSE -> 普通攻击
```

# 二、 制造与炼丹子系统 (Crafting & Alchemy)

知识库提到了“技艺等级决定品质”，且有大量如 `寒潭水`、`毒液`、`神泉水` 的特殊材料，但缺乏具体的**制造公式**和**炼丹玩法**。

### 2.1 洞府锻造与“技艺”概率公式
制造不是简单的“材料=装备”，而是结合技艺等级的**概率池**。

**品质判定公式：**
```text
基础极品率 = 5%
基础精良率 = 20%
基础普通率 = 60%
基础破损率 = 15%

最终极品率 = 基础极品率 + (技艺等级 × 2%) + (特殊材料加成)
```
*   **玄学惊喜设计**：如果在制造时投入**非必须的特殊材料**（如打造竹剑时额外投入 1 个 `珍珠`），不会改变装备基础，但会**强制将 1 条随机词条替换为“闪避/速度”相关词条**。这赋予了玩家“定向赌词条”的乐趣。

### 2.2 炼丹系统补全（盘活特殊液体）
知识库中丹药只有战斗掉落，这浪费了 `寒潭水`、`毒液`、`神泉水`。必须在洞府增加【炼丹炉】功能：

| 丹方名称 | 必需材料 | 辅助材料 | 产出结果 | 战略价值 |
|---|---|---|---|---|
| **避毒丹** | 毒液 ×2 | 疗伤丹药 ×1 | 战斗前服用，免疫中毒 3 回合 | 克制蛛丝谷、蝎子精 |
| **寒息散** | 寒潭水 ×2 | 元气丹 ×1 | 战斗中服用，清除自身【燃烧/灼烧】 | 克制熔岩洞、牛魔王 |
| **神行水** | 神泉水 ×1 | 速度丹药 ×1 | 战斗中服用，速度 +40% 且必定先手 | 抢夺 BOSS 战先手权 |
| **洗髓液** | 寒潭水 ×3 | 地脉灵气 ×1 | 用于装备【定向洗练】或【重置词条】 | 终局 Build 核心消耗 |

### 2.3 图纸与配方解锁机制
*   **一阶配方**：默认解锁，或在新手任务中直接发放。
*   **二阶/三阶配方**：不直接掉落成品，而是掉落【残页】。收集 3 张残页在洞府【合成】为完整图纸，解锁制造权限。
*   **传说配方**：击败三大 BOSS 后，直接解锁对应传说装备的制造权限（如击败牛魔王解锁【牛魔撼天锤】图纸）。

# 三、 关卡与词缀生成子系统 (Level & Affix)

知识库中定义了极其丰富的词缀（一至四档），但如果没有**生成权重控制**，玩家可能会在 1 级遇到四档词缀怪导致秒杀，或者在 30 级遇到一档词缀怪觉得无聊。

### 3.1 词缀动态生成权重表
词缀的生成必须与**关卡深度**和**难度**严格挂钩：

| 关卡进度 | 简单难度词缀池 | 普通难度词缀池 | 困难难度词缀池 | 守护者/BOSS 词缀池 |
|---|---|---|---|---|
| **1-3关** | 无 | 一档 (10%) | 一档 (30%) | 一档 + 减益一档 |
| **4-6关** | 一档 (5%) | 一档 (30%) | 二档 (20%) | 二档 + 减益一档 |
| **7-9关** | 一档 (10%) | 二档 (20%) | 三档 (30%) | 三档 + 减益二档 |
| **10关** | 二档 (10%) | 三档 (30%) | 四档 (20%) | 四档 + 减益二档 |

*   **词缀怪的“狩猎”体验**：在场景中，带有**三档/四档词缀**的敌人，其名字在 UI 上会带有**朱红印章标记**。击败它们除了常规掉落，**必定额外掉落【降妖令】或【灵气碎片】**。这会促使玩家主动去寻找并挑战高难度词缀怪，而不是避战。

### 3.2 场景隐藏要素与“机缘”触发
为了增加探索感，每个场景设置一个隐藏条件，满足后触发【机缘事件】（纯文本弹窗，符合水墨无图风格）：
*   **小花山**：连续 3 场战斗不使用技能（纯普攻） $\rightarrow$ 触发【老猴传功】，获得大量武器制作经验。
*   **浅水涧**：背包中携带【珍珠】进入战斗 $\rightarrow$ 触发【河伯馈赠】，本场战斗掉落率翻倍。
*   **熔岩洞**：穿戴【火属性附魔】武器击败守护者 $\rightarrow$ 触发【地火淬体】，永久提升 5 点基础防御。

# 四、 任务与经济宏观调控 (Quest & Economy)

### 4.1 “西行志”动态悬赏契约
静态任务（如“收集10个桃木”）完成后就失去了意义。需要将任务系统改造为**每日/每周刷新的动态契约**，引导玩家去刷特定关卡：

*   **流派限制契约**：*“【金行道】以锐破坚：使用【破甲斩】累计造成 5000 点伤害。奖励：二阶灿金晶球 ×3”*
*   **环境限制契约**：*“【无伤】降妖：在【碎石坡】困难难度下，不损失气血击败 3 只敌人。奖励：洗髓液 ×1”*
*   **收集限制契约**：*“【奇珍】寻药：收集 5 瓶【寒潭水】。奖励：神秘宝箱钥匙”*

### 4.2 经济水池与防通胀机制
随着玩家刷怪，金钱和基础材料会大量溢出。必须建立**经济回收黑洞**：
1.  **强化黑洞**：三阶装备 +10 之后的强化，不仅需要晶球，还需要消耗**大量金钱**（呈指数级增长）。
2.  **洗练黑洞**：使用【洗髓液】洗练词条时，每次消耗 5000 金钱。
3.  **杂物回收**：客栈/黑市 NPC 提供【批量出售】功能，将无用的【碎银】、【青花瓷碎片】等杂物一键转化为金钱。
4.  **丹药上限**：九转金丹（永久加属性）设定**背包堆叠上限为 5**，且**全服/全存档最多只能服用 10 颗**，防止玩家通过无限刷碎片导致数值崩坏。

# 五、 存档与底层数据结构 (Save & Data)

由于游戏是“简单小型”且基于浏览器（localStorage），存档结构必须**紧凑、防丢、支持版本迁移**。

### 5.1 核心存档 JSON Schema 设计
```json
{
  "meta": {
    "version": "1.2.0",       // 用于后续版本迁移
    "save_time": 1690000000,
    "play_time": 3600         // 总游玩秒数
  },
  "player": {
    "level": 15,
    "exp": 4500,
    "hp_max": 250,
    "energy_max": 150,
    "base_atk": [20, 30],
    "gold": 12500,
    "pills_eaten": {"elix_007": 3} // 记录九转金丹服用次数，防作弊
  },
  "progress": {
    "max_scene": 5,           // 最高解锁关卡
    "boss_killed": ["boss_001", "boss_002"],
    "hidden_boss_killed": ["hboss_001"]
  },
  "inventory": {
    "materials": {"mat_001": 45, "mat_014": 2}, // 材料ID: 数量
    "equip_ids": ["eq_10293", "eq_10294"]       // 装备实例ID列表
  },
  "equip_instances": {
    "eq_10293": {
      "base_id": "wp_003",    // 流云剑
      "quality": "rare",      // 精良
      "star": 1,
      "enhance": 5,
      "affixes": ["crit_rate_5", "atk_pct_4"], // 随机词条ID
      "enchant": "fire_01"    // 附魔ID
    }
  },
  "crafting": {
    "wp_level": 4, "wp_exp": 2,
    "ar_level": 2, "ar_exp": 0
  }
}
```

### 5.2 防作弊与版本迁移
*   **防内存修改**：由于是单机网页游戏，无法完全杜绝内存修改。但可以在存档中加入 `checksum`（校验和），例如 `checksum = hash(player.gold + inventory.length + meta.version)`，读取时校验，防止玩家直接用 CE 修改金钱导致存档损坏。
*   **版本迁移**：当游戏更新（例如增加了“炼丹系统”），读取旧存档时，通过 `meta.version` 判断，自动执行 `migrate_v1_to_v2()` 函数，为玩家补偿新系统的引导材料，避免坏档。

### 总结：子系统联动全景图

经过以上补完，《西游斗战》的底层逻辑已形成完美闭环：

1. 玩家在 **【关卡系统】** 中遭遇**词缀怪**，通过 **【战斗系统】** 的结算轴击败它们。
2. 获得**特殊材料**（如毒液、寒潭水）和**图纸残页**。
3. 回到洞府，通过 **【制造/炼丹系统】** 将材料转化为**定向丹药**或**极品装备**。
4. 装备在 **【装备系统】** 中进行强化、附魔、洗练，消耗大量 **【经济系统】** 产出的金钱。
5. 实力提升后，去完成 **【西行志动态契约】**，挑战更高难度的**场景 BOSS**。
6. 最终击败六耳猕猴，达成通关。

这套设计既保证了**水墨文字游戏的轻量感**，又具备了**刷子游戏（Looter）的深度与成瘾性**，可直接作为程序开发的逻辑说明书。
