## 0. 设计前提

```text
回合制战斗，每回合只能行动一次。
玩家操作选项：普攻 / 小技能A / 小技能B / 大招 / 丹药 / 自动战斗。
战斗目标时长：6-12 回合。
能量上限 150，初始 25，每回合 +25，受击 +15。
小技能消耗 50 能量，冷却 2-3 回合。
大招消耗 150 能量，冷却 5 回合。
技能通过技能树加点解锁（详见 §1-§6）。
```

**核心约束**：每回合只能做一个操作。4 个技能 + 普攻 = 5 个选项，是回合制的合理上限。不需要更多。

## 2. 技能树结构总览

每流派一棵技能树，分 **3 个分支**，每分支 **4 层**，共 **12 个节点/流派**。

```text
3 流派 × 12 节点 = 36 个节点
60 点技能点（等级 50 + 悟道丹 10），节点消耗 1-5 点
玩家大约可以点亮 20-28 个节点（约 55%-78%）
不可能点满，必须取舍
```

### 节点类型与分布

| 节点类型 | 消耗 | 灵猴道 | 金行道 | 磐石道 | 说明 |
|---|---:|---:|---:|---:|---|
| 属性节点 | 1-2 点 | 6 | 6 | 6 | 直接加属性（攻击%/防御%/暴击率等） |
| 强化节点 | 2 点 | 1 | 0 | 0 | 强化已有技能效果 |
| 被动节点 | 2 点 | 1 | 2 | 2 | 解锁被动技能（自动触发） |
| 小技能节点 | 3 点 | 3 | 3 | 2 | 解锁小技能（消耗 50 能量） |
| 大招节点 | 5 点 | 1 | 1 | 2 | 解锁大招（消耗 150 能量） |
| **合计节点** | | **12** | **12** | **12** | |
| **点满消耗** | | **26** | **27** | **28** | |

## 6. 加点规则

### 6.1 前置关系

```text
每个分支内，必须从第 1 层开始逐层点亮。
不能跳过第 1 层直接点第 3 层。
同一分支内，上一层未点亮则下一层不可点。
```

### 6.2 跨流派

```text
允许跨流派加点。
每个流派的第 1 层节点无前置，可直接点亮。
例：灵猴道第 1 层（攻击+5%）+ 金行道第 1 层（暴击率+3%）+ 磐石道第 1 层（防御+5%）
```

### 6.3 大招解锁

```text
大招节点消耗 5 点，且必须点亮同分支前 3 层。
每流派有 1-2 个大招节点（磐石道有 2 个：泰山压顶 / 金刚不坏）。
玩家最多解锁 2 个大招（跨流派各 1 个，或同流派 2 个）。
```

### 6.4 小技能装备上限

```text
技能树解锁的小技能可以超过 2 个，但战斗中最多装备 2 个。
在「流派修行」界面选择当前出战的 2 个小技能。
可随时切换（战斗外），不消耗技能点。
```

### 6.5 被动装备上限

```text
技能树解锁的被动可以超过 1 个，但战斗中最多装备 2 个。
在「流派修行」界面选择当前出战的 2 个被动。
```

### 6.6 重置

```text
技能点重置消耗：金钱 500 × 当前已分配点数。
重置后所有技能点返还，可重新分配。
悟道丹获得的技能点重置后不返还（已消耗）。
```

## 8. 能量节奏与技能释放频率

### 8.1 标准能量曲线（不普攻攒能量）

| 回合 | 能量 | 可释放 | 说明 |
|---:|---:|---|---|
| 1 | 50 | 小技能 | 开局即可放小技能 |
| 2 | 25 | 普攻 | 能量不足 |
| 3 | 50 | 小技能 | 第二个小技能 |
| 4 | 25 | 普攻 | |
| 5 | 50 | 小技能 | 第一个小技能冷却结束 |
| 6 | 75 | 普攻 | 攒能量 |
| 7 | 100 | 小技能 | |
| 8 | 125 | 普攻 | |
| 9 | 150 | **大招** | 大招就绪 |

### 8.2 受击加速

若玩家每回合受到攻击（+15 能量）：

| 回合 | 能量（含受击） | 可释放 |
|---:|---:|---|
| 1 | 50 | 小技能 |
| 2 | 40 | 普攻 |
| 3 | 65 | 小技能 |
| 4 | 55 | 小技能 |
| 5 | 80 | 普攻 |
| 6 | 105 | 小技能 |
| 7 | 130 | 普攻 |
| 8 | **155→150** | **大招** |

**结论**：大招最快第 6 回合（受击加速）或第 9 回合（纯攒）释放。在 6-12 回合的战斗中，大招释放 **1-2 次**。

### 8.3 技能释放频率总结

| 技能类型 | 释放频率 | 一场战斗（8 回合）中约释放 |
|---|---|---|
| 普攻 | 每回合可用 | 4-5 次 |
| 小技能 | 每 2-3 回合 | 2-3 次 |
| 大招 | 每 6-9 回合 | 1 次 |
| 被动 | 自动触发 | 持续 |

## 9. 数值平衡验证

### 9.1 单回合等效伤害

| 操作 | 伤害 | 等效 DPS（÷等待回合） |
|---|---|---|
| 普攻 | 100% | 100%/回合 |
| 小技能（平均） | 130%-180% | 65%-90%/回合（÷2-3 回合冷却） |
| 大招（平均） | 250%-350% | 42%-58%/回合（÷6 回合积累） |

**结论**：大招的"每回合等效伤害"低于普攻。大招的价值不在于 DPS，而在于**单次爆发**和**不可替代的机制**（控制/护盾/必暴/破防）。

### 9.2 大招的不可替代性

| 大招 | 不可替代的机制 | 普攻/小技能能否替代 |
|---|---|---|
| 千影绝杀 | 末击必暴 + 击杀返还 50 能量 | 不能（暴击率无法保证 100%） |
| 天罡斩 | 暴击追加 100%（250%+100%）+ 无视 30% 防御 + 残血增伤 | 不能（小技能最高 130%） |
| 泰山压顶 | 100% 眩晕 | 不能（撼地击只有 30%） |
| 金刚不坏 | 30% 最大气血护盾 + 30% 反伤 | 不能（无其他护盾来源） |

**每个大招都有普攻和小技能无法替代的机制。** 这是大招存在的理由。

### 9.3 终局数值校验

```text
终局玩家预期：攻击 400-1200，暴击伤害 150%-260%
千影绝杀：5×70%×1200 = 4200 伤害（末击暴击 ×1.5 = 额外 630）
天罡斩暴击：350%×1200 = 4200 伤害
泰山压顶：220%×1200 = 2640 伤害 + 眩晕

最终 BOSS 气血 2600 → 一个大招即可击杀。
普通 BOSS 气血 5000-8000 → 需要大招 + 小技能 + 普攻组合。
```

数值在 10000 以内，合理。

## 10. 与装备词条的联动

技能树中的属性节点与装备词条**叠加**，但受词条总和上限约束：

| 属性 | 技能树可提供 | 装备词条上限 | 总上限 |
|---|---|---|---|
| 攻击% | +5%（1 节点） | +80% | 80% |
| 暴击率 | +3%（1 节点） | 55% | 55% |
| 暴击伤害 | +10%（1 节点）+ 被动 150% | 300% | 300% |
| 连击率 | +5% + 3%（2 节点） | 60% | 60% |
| 闪避率 | +3%（1 节点） | 40% | 40% |
| 格挡率 | +3%（1 节点） | 60% | 60% |
| 能量获取 | +5% + 10%（2 节点） | 50% | 50% |

技能树提供的属性加成计入词条总和上限，不会导致溢出。

## 11. 与 engines 的接入方式

### 11.1 技能配置结构

```json
{
  "id": "lh_skill_3",
  "name": "乱舞",
  "school": "linghou",
  "type": "skill",
  "energyCost": 50,
  "cooldown": 2,
  "steps": [
    { "type": "deal_damage", "attackType": "normal", "calculation": { "baseValue": 0, "extraValues": [{ "ratio": 0.6, "attribute": "attack" }] } },
    { "type": "deal_damage", "attackType": "normal", "calculation": { "baseValue": 0, "extraValues": [{ "ratio": 0.6, "attribute": "attack" }] } },
    { "type": "deal_damage", "attackType": "normal", "calculation": { "baseValue": 0, "extraValues": [{ "ratio": 0.6, "attribute": "attack" }] } }
  ],
  "passiveTrigger": "lh_passive_1",
  "description": "3 次快速攻击，每次 60% 伤害，每段触发连击被动判定"
}
```

### 11.2 被动接入

被动通过 `PassiveSkillManager` 注册，监听战斗事件：

| 被动 | 监听事件 | 触发条件 | 效果 |
|---|---|---|---|
| 迅捷连击 | `on_attack_landed` | 30% 概率 | 追加一次 50% 伤害 |
| 致命精准 | 属性修正 | 始终生效 | critDamage = 150% |
| 破军之势 | 伤害管线第 8 步 | 始终生效 | defense × 0.9 |
| 磐石格挡 | `on_hit_received` | 20% 概率 | 伤害 ×0.5 |
| 以守为攻 | `on_hit_received` / `on_block` | 受击/格挡 | 能量 +20% / 反弹 10% |

### 11.3 大招接入

大招通过 `SkillExecutor` 执行，步骤编排：

```text
泰山压顶：
  Step 1: deal_damage（220% 攻击）
  Step 2: apply_buff（眩晕，duration=1，successRate=100%）

金刚不坏：
  Step 1: apply_buff（护盾，value=maxHealth×30%，duration=3）
  Step 2: apply_buff（反伤，reflectPercent=30%，duration=3）

千影绝杀：
  Step 1-4: deal_damage（70% 攻击，每段触发连击判定）
  Step 5: deal_damage（70% 攻击，crit=true）
  Step 6: on_kill → 返还 50 能量

天罡斩：
  Step 1: deal_damage（250% 攻击，ignoreDefense=30%，targetHp<30% 时 +50%）
  Step 2: crit 时追加 +100% 伤害
```

## 13. 验收标准

```text
1. 技能点获取正确：等级 30 + 悟道丹 10 = 40。
2. 技能树前置关系正确：未点亮前置节点时，后续节点不可点。
3. 跨流派加点正常：每个流派第 1 层无前置，可直接点亮。
4. 属性节点生效：点亮后属性实时反映到 ParticipantStats。
5. 被动节点生效：装备后战斗中自动触发。
6. 小技能/大招节点生效：装备后可在战斗中使用，能量消耗正确。
7. 出战槽位限制：被动最多 2、小技能最多 2、大招最多 1。
8. 重置功能正常：消耗金钱，技能点返还，悟道丹不返还。
9. 技能树 UI 为全屏覆盖模式（A 方案）。
10. 能量节奏达标：小技能每 2-3 回合可释放一次，大招每 6-9 回合可释放一次。
11. 每个大招有不可替代的机制（控制/护盾/必暴/破防）。
12. 蓄势一击的蓄力状态在 UI 中可见（防御姿态标记）。
13. 所有技能数值不超过 10000。
14. balance-check.cjs 在技能注入后 TTK 断言通过。
15. 所有节点效果有 Vitest 测试覆盖。
```
