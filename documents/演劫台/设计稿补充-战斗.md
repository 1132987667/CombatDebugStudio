# 流派技能系统 v2.0（重新设计）

---

## 0. 设计前提

```text
回合制战斗，每回合只能行动一次。
玩家操作选项：普攻 / 小技能A / 小技能B / 大招 / 丹药 / 自动战斗。
战斗目标时长：6-12 回合。
能量上限 150，初始 25，每回合 +25，受击 +15。
小技能消耗 50 能量，冷却 2 回合。
大招消耗 150 能量，冷却 5 回合。
技能点分配：被动 1 + 小技能 2 + 大招 1 = 4 个技能。
可跨流派混搭。
```

**核心约束**：每回合只能做一个操作。4 个技能 + 普攻 = 5 个选项，是回合制的合理上限。不需要更多。

---

## 1. 技能点与选择空间

| 槽位 | 点数 | 每流派可选 | 总池 | 选择方式 |
|---|---:|---:|---:|---|
| 被动 | 1 | 2 | 6 选 1 | 定义战斗风格底色 |
| 小技能 | 2 | 3 | 9 选 2 | 定义回合内操作 |
| 大招 | 1 | 2 | 6 选 1 | 定义关键时刻 |
| **合计** | **4** | **7/流派** | **21 选 4** | |

每流派 **7 个技能**（2 被动 + 3 小技能 + 2 大招），3 流派共 **21 个技能**。

## 5. 跨流派混搭规则

### 5.1 允许混搭

```text
玩家可从不同流派选择技能：
  灵猴道被动 + 金行道小技能 + 磐石道大招
```

### 5.2 纯流派加成

为激励纯流派加点，增加以下规则：

| 条件 | 额外加成 |
|---|---|
| 被动 + 2 小技能 + 大招全部来自灵猴道 | 连击率 +10% |
| 被动 + 2 小技能 + 大招全部来自金行道 | 暴击率 +10% |
| 被动 + 2 小技能 + 大招全部来自磐石道 | 格挡率 +10% |

混搭无额外加成，但灵活性更高。

### 5.3 混搭示例

| Build | 被动 | 小技能 | 大招 | 思路 |
|---|---|---|---|---|
| 闪避爆发 | 灵猴轻身 | 弱点打击 + 蓄势一击 | 天罡斩 | 闪避换能量 → 蓄力 → 暴击大招 |
| 控制输出 | 迅捷连击 | 撼地击 + 乱舞 | 泰山压顶 | 连击 + 眩晕 + 多段 |
| 铁壁反伤 | 以守为攻 | 铜墙铁壁 + 疾风步 | 金刚不坏 | 受击换能量 + 速度先手 + 护盾反伤 |

## 6. 能量节奏与技能释放频率

### 6.1 标准能量曲线（不普攻攒能量）

| 回合 | 能量 | 可释放 | 说明 |
|---:|---:|---|---|
| 1 | 50 | 小技能 | 开局即可放小技能 |
| 2 | 25 | 普攻 | 能量不足 |
| 3 | 50 | 小技能 | 第二个小技能 |
| 4 | 25 | 普攻 | |
| 5 | 50 | 小技能 | 第一个小技能冷却结束 |
| 6 | 75 | 普攻 | 攒能量 |
| 7 | 100 | 小技能 | |
| 8 | 125 | 普攻 | |
| 9 | 150 | **大招** | 大招就绪 |

### 6.2 受击加速

若玩家每回合受到攻击（+15 能量）：

| 回合 | 能量（含受击） | 可释放 |
|---:|---:|---|
| 1 | 50 | 小技能 |
| 2 | 40 | 普攻 |
| 3 | 65 | 小技能 |
| 4 | 55 | 小技能 |
| 5 | 80 | 普攻 |
| 6 | 105 | 小技能 |
| 7 | 130 | 普攻 |
| 8 | **155→150** | **大招** |

**结论**：大招最快第 6 回合（受击加速）或第 9 回合（纯攒）释放。在 6-12 回合的战斗中，大招释放 **1-2 次**。

### 6.3 技能释放频率总结

| 技能类型 | 释放频率 | 一场战斗（8 回合）中约释放 |
|---|---|---|
| 普攻 | 每回合可用 | 4-5 次 |
| 小技能 | 每 2-3 回合 | 2-3 次 |
| 大招 | 每 6-9 回合 | 1 次 |
| 被动 | 自动触发 | 持续 |

## 7. 数值平衡验证

### 7.1 单回合等效伤害

| 操作 | 伤害 | 等效 DPS（÷等待回合） |
|---|---|---|
| 普攻 | 100% | 100%/回合 |
| 小技能（平均） | 130%-180% | 65%-90%/回合（÷2 回合冷却） |
| 大招（平均） | 250%-350% | 42%-58%/回合（÷6 回合积累） |

**结论**：大招的"每回合等效伤害"低于普攻。大招的价值不在于 DPS，而在于**单次爆发**和**不可替代的机制**（控制/护盾/必暴/破防）。

### 7.2 大招的不可替代性

| 大招 | 不可替代的机制 | 普攻/小技能能否替代 |
|---|---|---|
| 千影绝杀 | 最后一击必暴 | 不能（暴击率无法保证 100%） |
| 神行百变 | 3 回合闪避+50% + 必连击 | 不能（无其他技能提供闪避） |
| 天罡斩 | 暴击时 300% 总伤害 | 不能（小技能最高 130%） |
| 金锋贯穿 | 无视 60% 防御 + 团队破甲 | 不能（破甲斩只无视 40%） |
| 泰山压顶 | 100% 眩晕 | 不能（撼地击只有 30%） |
| 金刚不坏 | 30% 最大气血护盾 + 30% 反伤 | 不能（无其他护盾来源） |

**每个大招都有普攻和小技能无法替代的机制。** 这是大招存在的理由。

### 7.3 终局数值校验

```text
终局玩家预期：攻击 400-1200，暴击伤害 150%-260%
千影绝杀：5×70%×1200 = 4200 伤害（最后一击暴击 ×1.5 = 额外 630）
天罡斩暴击：300%×1200 = 3600 伤害
泰山压顶：220%×1200 = 2640 伤害 + 眩晕

最终 BOSS 气血 2600 → 一个大招即可击杀。
普通 BOSS 气血 5000-8000 → 需要大招 + 小技能 + 普攻组合。
```

数值在 10000 以内，合理。

## 8. 与 engines 的接入方式

### 8.1 技能配置结构

```json
{
  "id": "lh_skill_3",
  "name": "乱舞",
  "school": "linghou",
  "type": "skill",
  "energyCost": 50,
  "cooldown": 2,
  "steps": [
    { "type": "deal_damage", "attackType": "normal", "calculation": { "baseValue": 0, "extraValues": [{ "ratio": 0.6, "attribute": "attack" }] } },
    { "type": "deal_damage", "attackType": "normal", "calculation": { "baseValue": 0, "extraValues": [{ "ratio": 0.6, "attribute": "attack" }] } },
    { "type": "deal_damage", "attackType": "normal", "calculation": { "baseValue": 0, "extraValues": [{ "ratio": 0.6, "attribute": "attack" }] } }
  ],
  "passiveTrigger": "lh_passive_1",
  "description": "3 次快速攻击，每次 60% 伤害，每段触发连击被动判定"
}
```

### 8.2 被动接入

被动通过 `PassiveSkillManager` 注册，监听战斗事件：

| 被动 | 监听事件 | 触发条件 | 效果 |
|---|---|---|---|
| 迅捷连击 | `on_attack_landed` | 30% 概率 | 追加一次 50% 伤害 |
| 灵猴轻身 | `on_dodge_success` | 闪避成功 | 能量 +10 |
| 致命精准 | 属性修正 | 始终生效 | critDamage = 150% |
| 破军之势 | 伤害管线第 8 步 | 始终生效 | defense × 0.9 |
| 磐石格挡 | `on_hit_received` | 20% 概率 | 伤害 ×0.5 |
| 以守为攻 | `on_hit_received` / `on_block` | 受击/格挡 | 能量 +20% / 反弹 10% |

### 8.3 大招接入

大招通过 `SkillExecutor` 执行，步骤编排：

```text
泰山压顶：
  Step 1: deal_damage（220% 攻击）
  Step 2: apply_buff（眩晕，duration=1，successRate=100%）

金刚不坏：
  Step 1: apply_buff（护盾，value=maxHealth×30%，duration=3）
  Step 2: apply_buff（反伤，reflectPercent=30%，duration=3）
```

## 11. 验收标准

```text
1. 玩家装备 4 个技能 + 普攻，每回合有 5 个操作选项。
2. 小技能每 2-3 回合可释放一次，大招每 6-9 回合可释放一次。
3. 每个大招有不可替代的机制（控制/护盾/必暴/破防）。
4. 被动自动触发，不消耗能量，不占行动。
5. 分身斩的分身在昊天镜中可见（作为独立实体或 Buff）。
6. 蓄势一击的蓄力状态在 UI 中可见（防御姿态标记）。
7. 跨流派混搭正常工作，纯流派加成正确计算。
8. 所有技能数值不超过 10000。
9. balance-check.cjs 在技能注入后 TTK 断言通过。
10. 每个技能的效果有 Vitest 测试覆盖。
```
