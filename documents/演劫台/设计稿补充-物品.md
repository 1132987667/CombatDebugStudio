# 《西游斗战》掉落系统专项设计稿  
## 关卡 / 小怪 / BOSS 物品掉落、管理与关联设计

本文档暂不涉及 UI 表现，仅从系统策划角度梳理：

1. 各关卡小怪、守护者、BOSS 的掉落定位。
2. 掉落物与装备、强化、丹药、任务、经济之间的关联。
3. 掉落管理规则：权重、保底、首杀、重复刷取、回收。
4. 当前知识库掉落表中存在的问题与修正建议。

核心目标：

```text
每个关卡都有明确的刷取价值。
每个敌人都至少绑定一类资源用途。
每个物品都有明确去向。
每次战斗掉落都能推动玩家成长。
BOSS 掉落必须形成阶段性目标。
普通小怪不能只是过渡，而要在中后期仍具备定向刷取价值。
```

---

# 1. 当前掉落系统的主要问题

知识库已有较完整的物品表与敌人掉落，但从“刷子循环”和“资源管理”角度看，仍存在以下问题。

---

## 1.1 掉落过于线性，缺少长期刷取价值

当前多数小怪掉落结构为：

```text
基础材料 + 少量丹药 + 极低概率晶球
```

例如：

```text
花妖：桃木
草精：桃木 / 粗石
小虾兵：贝壳 / 淡水玉
```

这类掉落只服务于一阶装备制造。  
一旦玩家完成一阶装备制作，这些敌人就会失去刷取价值。

问题：

```text
玩家做出竹剑后，不会再想刷花妖。
玩家做出二阶装备后，不会再想刷碎石坡。
通关后旧关卡缺乏回访理由。
```

---

## 1.2 特殊材料用途不足

知识库中有大量特殊材料，但用途关联不够明确：

| 材料 | 当前状态 | 问题 |
|---|---|---|
| 铁焰矿 | 制作特殊装备的材料 | 缺少对应特殊装备 |
| 金阳矿 | 制作特殊装备的材料 | 缺少对应特殊装备 |
| 寒潭水 | 炼制特殊丹药 | 缺少炼丹规则 |
| 毒液 | 毒丹药 / 毒武器 | 缺少毒武器 / 毒丹药具体产出 |
| 神泉水 | 高级丹药材料 | 缺少高级丹药产出 |
| 珍珠 | 特殊饰品 | 缺少珍珠饰品 |
| 古铜镜 | 三阶腰带材料 | 用途单一，缺少稀有感 |
| 玉佛像 | 顶级饰品 / 特殊装备 | 缺少对应装备 |
| 碎银 | 出售价值 100 | 只是换钱，缺少独立用途 |
| 神秘宝箱 | 隐藏 BOSS 掉落 | 宝箱内容未定义 |
| 新手礼包 | 灵霄台守护者掉落 | 内容未定义 |
| 牛魔角 / 毒囊 / 鹏羽 | 制作传说装备 | 传说装备未定义 |

如果这些材料只是“写着有用”，但没有明确产出，玩家不会形成刷取欲望。

---

## 1.3 晶球掉落阶级存在错位

现有掉落中部分后期敌人仍掉落一阶晶球：

```text
关卡 10 普通：佛门叛徒精英掉落一阶灿金晶球
关卡 10 普通：金刚护法将领掉落一阶清辉晶球
关卡 10 普通：罗汉使者长老掉落一阶玲珑晶球
关卡 10 困难：佛门叛徒首领掉落一阶灿金晶球 ×2
关卡 10 困难：金刚护法统帅掉落一阶清辉晶球 ×2
```

这与关卡 10 的终局定位不匹配。

建议：

```text
关卡 10 应掉落三阶晶球、天罡灵气、混元灵气、九转金丹碎片、传说装备残页等终局资源。
```

---

## 1.4 守护者掉落吸引力不足

当前守护者是每个难度的第 3 个敌人，规则上会附加 1 个增益词缀，但掉落多为：

```text
主题材料 + 低概率晶球
```

例如：

```text
小花山守护者：淡水玉 ×3，一阶玲珑晶球 5%
浅水涧守护者：珍珠，一阶玲珑晶球 5%
碎石坡守护者：铁精，一阶清辉晶球 5%
```

守护者的定位应该是：

```text
该关卡中最值得重复挑战的精英敌人。
```

因此守护者掉落必须比普通小怪更稳定、更稀有、更有目标感。

---

## 1.5 BOSS 掉落缺少“专属追求”

当前场景 BOSS 的掉落规则为：

```text
对应关卡的三阶材料 + 灵气 + 随机一件稀有物品
```

这个规则过于笼统。  
BOSS 应该有明确的专属产出，例如：

```text
专属图纸
专属器灵
专属饰品
专属强化石
专属词缀材料
专属任务道具
```

否则 BOSS 只是“材料更多的小怪”，缺少反复挑战的动力。

---

# 2. 掉落系统总体设计原则

---

## 2.1 掉落必须分层

不同敌人承担不同掉落职责：

| 敌人类型 | 掉落职责 |
|---|---|
| 普通小怪 | 提供基础材料、金钱、低概率稀有材料 |
| 困难小怪 | 提供更高数量材料、低概率晶球、任务物品 |
| 守护者 | 提供本关关键稀有材料、晶球、图纸残页 |
| 场景 BOSS | 提供高阶材料、灵气、专属图纸、稀有装备 |
| 隐藏 BOSS | 提供神秘宝箱、稀有丹药、碎片 |
| 三大 BOSS | 提供九转金丹、专属传说材料 |
| 最终 BOSS | 提供通关奖励、传说资源、终极装备 |

---

## 2.2 每个关卡必须有“资源主题”

每个关卡不应随机掉落所有材料，而应有明确主题：

```text
关卡 1：木材与基础玉石
关卡 2：水产与珍珠
关卡 3：粗石与铜矿
关卡 4：皮革、织物、陶瓷
关卡 5：深水玉石与铁精
关卡 6：铁木、火矿、古铜镜
关卡 7：毒液、寒潭水、翡翠
关卡 8：虎皮、金阳矿、神泉水
关卡 9：佛门玉石、玉佛、灵气
关卡 10：终局灵气、金丹碎片、传说材料
```

玩家想刷某类资源时，应能立刻想到对应关卡。

---

## 2.3 每个物品必须有用途闭环

所有物品必须至少进入以下一种循环：

```text
制造循环：材料 → 装备制作
强化循环：晶球 / 异矿 / 灵水 / 灵气 → 装备强化
炼丹循环：液体 / 毒物 / 灵水 → 丹药
合成循环：碎片 → 稀有物品
任务循环：任务物品 → 奖励
经济循环：杂物 / 碎银 → 金钱 / 商店
升星循环：重复装备 → 升星
传说循环：BOSS 专属材料 → 传说装备
```

不允许出现大量“只能卖钱”的材料。

---

## 2.4 掉落要服务玩家当前目标

不同阶段玩家目标不同：

| 阶段 | 玩家目标 | 掉落重点 |
|---|---|---|
| 前期 1-10 级 | 做出一阶装备 | 桃木、粗石、铜精、淡水玉、贝壳、鹿皮 |
| 中期 10-20 级 | 做出二阶装备并强化 | 松木、铁精、深水玉、熊皮、青花瓷 |
| 后期 20-30 级 | 做出三阶装备并挑战 BOSS | 铁木、金精、圣水玉、仙云皮、虎皮、灵气 |
| 终局 | 传说装备、九转金丹、最终 BOSS | 天罡灵气、混元灵气、牛魔角、毒囊、鹏羽 |

---

# 3. 掉落层级结构设计

建议将掉落分为五层：

```text
第一层：基础材料层
第二层：强化资源层
第三层：图纸配方层
第四层：稀有消耗层
第五层：终局传说层
```

---

## 3.1 第一层：基础材料层

来源：

```text
普通小怪
简单 / 普通难度敌人
```

用途：

```text
制造装备
出售换钱
任务收集
技艺经验
```

包含：

```text
桃木、粗石、铜精、淡水玉、贝壳
松木、铁精、深水玉、鹿皮、宣纸
青花瓷、熊皮、铁木、虎皮、仙云皮
圣水玉、翡翠玉镯、古铜镜、金精
```

设计原则：

```text
基础材料必须充足，但不能过量稀有。
每种基础材料必须绑定至少一件装备。
```

---

## 3.2 第二层：强化资源层

来源：

```text
守护者
困难难度敌人
场景 BOSS
隐藏 BOSS
```

用途：

```text
装备强化
装备升星辅助
高级制造
```

包含：

```text
一阶 / 二阶 / 三阶灿金晶球
一阶 / 二阶 / 三阶清辉晶球
一阶 / 二阶 / 三阶玲珑晶球
地脉灵气
天罡灵气
混元灵气
```

设计原则：

```text
晶球必须随关卡阶段提升阶级。
灵气应主要来源于 BOSS、隐藏 BOSS 和高难敌人。
```

---

## 3.3 第三层：图纸配方层

知识库核心玩法提到“图纸”，但当前物品表中没有完整图纸系统。  
建议补全图纸系统，作为掉落的重要组成部分。

图纸分类：

```text
一阶装备图纸
二阶装备图纸
三阶装备图纸
饰品图纸
特殊装备图纸
传说装备图纸
```

获取来源：

```text
普通小怪低概率掉落图纸残页
守护者中概率掉落完整图纸
场景 BOSS 首杀必掉关键图纸
隐藏 BOSS 掉落特殊图纸
三大 BOSS 掉落传说图纸
```

用途：

```text
解锁洞府制造配方
```

设计原则：

```text
一阶图纸可默认开放，或早期必得。
二阶图纸由关卡 3-5 守护者 / BOSS 提供。
三阶图纸由关卡 6-9 守护者 / BOSS 提供。
传说图纸由三大 BOSS 提供。
```

这样玩家重复挑战守护者和 BOSS 就有了明确目标。

---

## 3.4 第四层：稀有消耗层

来源：

```text
精英敌人
守护者
隐藏 BOSS
特定场景小怪
```

用途：

```text
战斗增益
炼丹
临时强化
特殊制造
```

包含：

```text
疗伤丹药
元气丹
攻击丹药
防御丹药
速度丹药
全属性丹药
寒潭水
神泉水
毒液
珍珠
```

设计原则：

```text
普通丹药前期有用，后期应转化为炼丹材料或出售。
稀有液体 / 毒物应进入炼丹或特殊装备制造。
```

---

## 3.5 第五层：终局传说层

来源：

```text
场景 BOSS
隐藏 BOSS
三大 BOSS
最终 BOSS
关卡 10 高难敌人
```

用途：

```text
传说装备
永久成长
终极强化
最终 Build 成型
```

包含：

```text
九转金丹
九转金丹碎片
天罡灵气
混元灵气
牛魔角
毒囊
鹏羽
玉佛像
玉佛像碎片
传说装备
传说装备材料
```

设计原则：

```text
终局资源必须稀缺。
但必须给玩家稳定进度，例如碎片、代币、保底掉落。
```

# 4. 各关卡掉落定位设计

以下为 10 个关卡的掉落定位建议。  
每关都应有明确的“刷什么、为什么刷、刷给谁用”。

---

## 4.1 关卡 1：小花山

### 资源主题

```text
一阶入门材料
木材、粗石、基础玉石
```

### 主要产出

| 物品 | 用途 |
|---|---|
| 桃木 | 一阶轻型 / 中型武器、木甲 |
| 粗石 | 一阶重型武器、铠甲、项链 |
| 铜精 | 一阶武器、饰品、铠甲 |
| 淡水玉 | 一阶护符、手镯、冠冕 |
| 贝壳 | 一阶戒指、手镯 |
| 疗伤丹药 | 前期恢复 |

### 守护者建议掉落

```text
必掉：淡水玉 ×3
概率：一阶玲珑晶球
概率：一阶饰品图纸残页
首杀：一阶护符图纸 或 一阶手镯图纸
```

### 场景 BOSS：花妖王·灵根

建议掉落：

```text
首杀必掉：
一阶武器图纸包
一阶衣服图纸包
地脉灵气碎片 ×1-2

重复挑战：
桃木 ×5-8
粗石 ×3-5
铜精 ×2-4
疗伤丹药 / 元气丹
低概率一阶晶球
```

### 刷取价值

```text
前期制作一阶装备。
中后期可回来刷桃木完成悬赏任务。
花妖王可作为一阶图纸稳定来源。
```

---

## 4.2 关卡 2：浅水涧

### 资源主题

```text
水产、贝壳、珍珠、基础饰品材料
```

### 主要产出

| 物品 | 用途 |
|---|---|
| 贝壳 | 一阶戒指、手镯 |
| 淡水玉 | 一阶护符、手镯 |
| 珍珠 | 特殊饰品、出售、炼丹辅助 |
| 速度丹药 | 速度流 Build |

### 守护者建议掉落

```text
必掉：珍珠 ×1
概率：一阶玲珑晶球
概率：一阶戒指图纸残页
首杀：珍珠项链图纸 或 珍珠手镯图纸
```

### 场景 BOSS：河伯·沧浪

建议掉落：

```text
首杀必掉：
一阶饰品图纸包
地脉灵气碎片 ×1-2

重复挑战：
贝壳 ×5-8
淡水玉 ×3-5
珍珠 ×1 概率
速度丹药
低概率一阶玲珑晶球
```

### 刷取价值

```text
珍珠应作为特殊饰品材料，而不是单纯出售。
浅水涧是饰品 Build 的起点。
```

建议新增：

```text
珍珠项链：速度 +6%
珍珠手镯：闪避率 +3%
珍珠护符：受到治疗效果 +5%
```

这样珍珠就有明确刷取目标。

---

## 4.3 关卡 3：碎石坡

### 资源主题

```text
矿石、木材、二阶过渡材料
```

### 主要产出

| 物品 | 用途 |
|---|---|
| 粗石 | 一阶重甲、项链 |
| 松木 | 二阶武器、木甲 |
| 铜精 | 一阶金属装备 |
| 铁精 | 二阶装备核心金属 |

### 守护者建议掉落

```text
必掉：铁精 ×1-2
概率：一阶灿金晶球
概率：二阶武器图纸残页
首杀：二阶中型武器图纸
```

### 场景 BOSS：山神·岩坚

建议掉落：

```text
首杀必掉：
二阶武器图纸包
地脉灵气 ×1

重复挑战：
粗石 ×6-8
松木 ×4-6
铜精 ×3-5
铁精 ×1-2
防御丹药
低概率一阶 / 二阶晶球
```

### 刷取价值

```text
碎石坡是从一阶到二阶的关键桥梁。
铁精是二阶装备核心，应让碎石坡成为铁精稳定来源。
```

### 资源主题

```text
皮革、织物、陶瓷、二阶饰品材料
```

### 主要产出

| 物品 | 用途 |
|---|---|

| 鹿皮 | 一阶皮甲 |
| 宣纸 | 一阶腰带 |
| 青花瓷 | 二阶戒指、腰带 |
| 熊皮 | 二阶皮甲 |
| 深水玉 | 二阶护符、手镯 |

### 守护者建议掉落

```text
必掉：熊皮 ×1-2
概率：二阶清辉晶球
概率：二阶皮甲图纸残页
首杀：二阶皮甲图纸
```

### 场景 BOSS：迷雾妖主·幻影

建议掉落：

```text

二阶衣服图纸包
二阶饰品图纸包

重复挑战：
松木 ×5-8
鹿皮 / 熊皮
宣纸 / 青花瓷
深水玉
攻击丹药
低概率二阶晶球
```

## 4.5 关卡 5：浊浪滩

### 资源主题

```text
二阶强化、水属性饰品、铁精过渡
```

### 主要产出

| 物品 | 用途 |
|---|---|
| 粗石 | 基础材料补充 |
| 贝壳 | 饰品 |
| 深水玉 | 二阶护符、手镯 |
| 铁精 | 二阶装备 |
| 全属性丹药 | 稀有战斗增益 |

### 守护者建议掉落

```text
必掉：圣水玉 ×1
概率：二阶灿金晶球
概率：二阶饰品图纸残页
```

# 5. 小怪、守护者、BOSS 的掉落规则设计

---

## 5.1 普通小怪掉落规则

普通小怪应提供稳定基础资源。

建议结构：

```text
金钱：100%
主题基础材料：60%-80%
次级材料：20%-40%
丹药：15%-30%
杂物 / 特殊材料：5%-15%
稀有晶球：0%-2%
```

不同难度修正：

| 难度 | 掉落数量 | 稀有概率 |
|---|---:|---:|
| 简单 | 1.0 | 1.0 |
| 普通 | 1.2 | 1.2 |
| 困难 | 1.5 | 1.5 |

示例：

```text
花妖 简单：
金钱 100%
桃木 ×2 80%
疗伤丹药 20%

花妖 困难：
金钱 100%
桃木 ×3-4 85%
疗伤丹药 25%
桃木精华 / 图纸残页 5%
```

设计目的：

```text
普通小怪负责基础资源供给。
困难小怪增加少量稀有产出，提高重复刷价值。
```

---

## 5.2 守护者掉落规则

守护者应是该关卡最值得反复挑战的精英敌人。

建议结构：

```text
固定关键材料：100%
晶球：30%-50%
图纸残页：20%-30%
稀有丹药：20%
首杀奖励：100%
```

守护者首杀建议：

```text
首次击败守护者，必掉一件该关卡关键图纸或稀有材料。
```

例如：

```text
小花山守护者首杀：一阶护符图纸
浅水涧守护者首杀：珍珠饰品图纸
碎石坡守护者首杀：二阶武器图纸
熔岩洞守护者首杀：三阶武器图纸
禅音崖守护者首杀：玉佛饰品图纸
灵霄台守护者首杀：灵霄宝匣
```

设计目的：

```text
守护者承担“定向稀有资源”职责。
玩家卡关时，可通过刷守护者获得突破资源。
```

---

## 5.3 场景 BOSS 掉落规则

场景 BOSS 应该有首杀奖励和重复挑战奖励。

### 首杀奖励

```text
必掉关键图纸
必掉灵气或晶球
必掉稀有丹药
可能解锁隐藏 BOSS 或三大 BOSS 条件
```

### 重复挑战奖励

```text
高阶材料包
灵气碎片
晶球
BOSS 代币 / 妖魂
低概率专属装备
```

建议引入轻量代币：

```text
降妖令
```

来源：

```text
击败场景 BOSS
击败隐藏 BOSS
完成西行志悬赏
```

用途：

```text
兑换图纸
兑换晶球
兑换稀有材料
兑换灵气碎片
```

这样即使 BOSS 随机掉落不理想，玩家也有稳定进度。

---

## 5.4 隐藏 BOSS 掉落规则

隐藏 BOSS 是一次性挑战，但奖励必须有独特性。

建议掉落：

```text
神秘宝箱：100%
稀有丹药：100%
专属碎片或专属材料：100%
```

神秘宝箱内容建议：

```text
随机灵气碎片 ×3-5
随机丹药 ×2-4
金钱 ×1000-3000
低概率天罡灵气
低概率九转金丹碎片
低概率特殊装备图纸
```

隐藏 BOSS 专属奖励建议：

| 隐藏 BOSS | 建议专属掉落 |
|---|---|
| 混世魔王·黑风 | 黑风残页，可兑换轻型速度装备 |
| 土行孙·遁地 | 遁地符，可兑换闪避饰品 |
| 九齿钉耙·朱刚鬣 | 钉耙残片，可兑换重型破甲装备 |
| 百眼魔君·多目 | 毒眼珠，可兑换毒系饰品 |
| 金蝉长老·净坛 | 禅杖舍利，可兑换佛门传说饰品材料 |

这样隐藏 BOSS 不只是给宝箱，而是有独特 Build 价值。

---

## 5.5 三大 BOSS 掉落规则

三大 BOSS 应为终局前的重要挑战。

建议掉落：

```text
九转金丹：100%
专属材料：100%
传说图纸：首杀 100%
```

| BOSS | 专属材料 | 建议传说装备 |
|---|---|---|
| 牛魔王 | 牛魔角 | 牛魔撼天锤 |
| 蝎子精 | 毒囊 | 万毒蚀心镯 |
| 金翅大鹏 | 鹏羽 | 大鹏逐日冠 |

建议传说装备效果：

```text
牛魔撼天锤：
攻击力高，攻击时概率造成眩晕，但速度降低。

万毒蚀心镯：
攻击命中时概率叠毒，毒层可被技能引爆。

大鹏逐日冠：
速度提升，闪避成功后下次攻击必暴击。
```

这样三大 BOSS 的重复挑战目标非常明确。

# 7. 重复刷取价值设计

为了让每个关卡的小怪和 BOSS 长期有价值，建议加入以下机制。

---

## 7.1 定向刷：每个敌人绑定一种关键资源

原则：

```text
玩家缺某种材料时，必须知道去哪里刷。
```

例如：

```text
缺桃木：小花山
缺贝壳：浅水涧
缺铁精：碎石坡
缺熊皮：迷雾林
缺深水玉：浊浪滩
缺铁木：熔岩洞
缺毒液：蛛丝谷
缺虎皮：狂风岭
缺圣水玉：禅音崖
缺天罡灵气：禅音崖 / 灵霄台
```

这样旧关卡会因“特定资源”保留价值。

---

## 7.2 困难专属掉落

每个困难难度敌人应有少量简单 / 普通无法获得的资源。

例如：

```text
困难花妖王：低概率掉落桃木精华
困难浅水涧守护者：低概率掉落珍珠项链图纸
困难碎石坡守护者：低概率掉落二阶武器图纸
困难熔岩洞守护者：低概率掉落铁焰强化石
困难禅音崖守护者：低概率掉落玉佛像碎片
```

这样玩家为了图纸、碎片和稀有材料会主动挑战困难。

---

## 7.3 守护者首杀与重复挑战分离

首杀给高价值奖励：

```text
图纸
稀有材料
晶球
碎片
```

重复挑战给稳定资源：

```text
主题材料
少量金钱
低概率晶球
降妖令
```

这样既保证首次惊喜，也保证长期可刷。

---

## 7.4 西行志悬赏任务

任务系统应驱动玩家回到旧关卡。

示例：

```text
收集 20 个桃木。
使用磐石道技能击败 10 只碎石坡敌人。
在困难迷雾林击败守护者 3 次。
收集 5 瓶毒液。
不使用丹药通关浅水涧普通。
击败花妖王 5 次。
```

奖励：

```text
金钱
经验
晶球
灵气碎片
图纸残页
降妖令
```

这样旧关卡会被任务系统重新激活。

---

## 7.5 幸运值 / 保底机制

对于低概率掉落，建议加入隐藏幸运值。

例如：

```text
玩家每次击败守护者未获得晶球，幸运值 +1。
幸运值达到 5 后，下次守护者必掉晶球。
获得晶球后幸运值清零。
```

BOSS 专属材料同理：

```text
每次未获得专属图纸，怨念值 / 降妖值增加。
累计 3 次未获得，下次必掉。
```

目的：

```text
避免玩家因长期不出货而流失。
让重复刷有稳定预期。
```

---

## 7.6 降妖令 / 妖魂代币

建议新增一种轻量管理资源：

```text
降妖令
```

获取：

```text
击败场景 BOSS
击败隐藏 BOSS
完成悬赏任务
困难守护者低概率掉落
```

用途：

```text
兑换指定图纸
兑换晶球
兑换灵气碎片
兑换稀有材料
```

这样玩家即使随机掉落不佳，也有稳定兑换路径。

注意：

```text
降妖令不应过多产出。
它只是保底和定向手段，不是主掉落。
```

# 9. 概率与数量管理建议

---

## 9.1 材料数量控制

装备制造消耗应与掉落数量匹配。

以竹剑为例：

```text
竹剑需要：
桃木 ×4
铜精 ×2
金钱 50
```

如果小花山简单花妖掉落：

```text
桃木 ×2，80%
```

那么玩家大约需要：

```text
2-3 场战斗即可制作竹剑
```

这是合理的新手节奏。

二阶装备建议：

```text
5-8 场普通战斗可制作一件
```

三阶装备建议：

```text
10-15 场战斗可制作一件
```

BOSS 装备 / 传说装备建议：

```text
需要多次 BOSS 挑战或代币兑换
```

---

## 9.2 稀有掉落概率建议

| 类型 | 建议概率 |
|---|---:|
| 基础材料 | 60%-85% |
| 次级材料 | 20%-40% |
| 普通丹药 | 15%-35% |
| 稀有丹药 | 5%-15% |
| 晶球 | 5%-15% 守护者，0%-3% 普通敌人 |
| 图纸残页 | 10%-20% 守护者 |
| 完整图纸 | 首杀 100%，重复 5%-10% |
| 灵气 | 10%-25% BOSS |
| 碎片 | 15%-35% 高难敌人 |
| 传说材料 | 首杀 100%，重复 10%-20% |

---

## 9.3 首杀与重复挑战奖励分离

建议：

```text
首杀奖励 > 重复挑战奖励
```

首杀负责惊喜和解锁。  
重复挑战负责稳定积累。

例如：

```text
花妖王首杀：
一阶武器图纸包
地脉灵气碎片 ×2
金钱 ×300

花妖王重复挑战：
桃木 ×5-8
粗石 ×3-5
金钱 ×100
低概率一阶晶球
低概率一阶图纸残页
```

# 12. 最终设计结论

掉落系统的核心不是“掉更多东西”，而是：

```text
每个掉落都能推动玩家下一个目标。
```

建议重点落实以下五点：

1. **每关有资源主题**  
   让玩家知道缺什么就去哪里刷。

2. **守护者承担定向稀有掉落**  
   守护者必须是该关卡最值得重复挑战的敌人。

3. **BOSS 掉落图纸与专属资源**  
   BOSS 不能只掉材料，必须掉 Build 目标。

4. **补全特殊材料用途**  
   铁焰矿、毒液、寒潭水、珍珠、玉佛像等必须进入装备或丹药循环。

5. **加入保底与代币**  
   用碎片、幸运值、降妖令降低随机掉落的挫败感。

这样处理后，《西游斗战》的掉落系统会从“线性过关材料”变成“可长期刷取的资源网络”，每个关卡、每个小怪、每个 BOSS 都会有明确的存在价值。
