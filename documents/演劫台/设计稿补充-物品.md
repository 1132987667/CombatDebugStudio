## 1. 当前掉落系统诊断与重构目标

### 1.1 现有系统问题

| 编号 | 问题 | 影响 |
|------|------|------|
| P1 | 掉落过于线性，缺少长期刷取价值 | 旧关卡完成制造后失去回访理由 |
| P2 | 特殊材料用途不足（铁焰矿/金阳矿/寒潭水/毒液/珍珠） | 无法形成刷取欲望，占背包 |
| P3 | 晶球掉落阶级错位（关卡 10 终局仍掉一阶晶球） | 终局体验割裂 |
| P4 | 守护者吸引力不足 | 沦为"材料稍多的小怪" |
| P5 | BOSS 缺少专属追求 | 无阶段性目标感 |
| P6 | 术语残留：配置中仍用「饰品」「项链」「腰带」「手镯」 | 与 6 槽体系冲突 |

### 1.2 重构核心目标

```text
1. 每个关卡都有明确的资源主题与刷取价值。
2. 每个敌人至少绑定一类资源用途（基础/稀有/图纸/代币）。
3. 每个物品都有明确去向（制造/强化/炼丹/兑换/洗练）。
4. BOSS 掉落形成阶段性目标（首杀惊喜 + 重复保底）。
5. 全面适配 6 槽装备体系，杜绝「饰品」等模糊术语。
6. 法宝/神器为独立类型，不占装备槽位。
```

## 4. 掉落系统总体原则与五层结构

### 4.1 设计原则

```text
1. 掉落分层：基础材料 → 强化资源 → 图纸配方 → 稀有消耗 → 终局传说。
2. 服务玩家当前目标：缺什么就去哪里刷。
3. 首杀与重复分离：首杀给惊喜，重复给积累。
4. 保底兜底：降妖令代币消除纯 RNG 挫败。
5. 零断裂引用：所有掉落 itemId 必须在 items.json 注册。
```

### 4.2 五层掉落结构

| 层级 | 来源 | 用途 | 包含内容 |
|------|------|------|----------|
| **第一层：基础材料** | 普通小怪 | 制造装备、出售、技艺经验 | 桃木、粗石、铜精、淡水玉、贝壳、鹿皮等 |
| **第二层：强化资源** | 守护者、困难敌人、BOSS | 装备强化、升星辅助 | 一~三阶灿金/清辉/玲珑晶球、地脉灵气 |
| **第三层：图纸配方** | 守护者、BOSS 首杀、小怪 | 解锁洞府制造配方 | 一~三阶武器/衣服/配件图纸、残页 |
| **第四层：稀有消耗** | 精英、守护者、隐藏 BOSS | 洗练、保底、特殊增益 | 寒潭水、天罡灵气、强化保护符、降妖令 |
| **第五层：终局传说** | 三大 BOSS、最终 BOSS | 天品/仙品合成、终局毕业 | 牛魔角、毒囊、鹏羽、混元灵气、九转金丹 |

## 6. 各类型敌人掉落规则

### 6.1 普通小怪（基础供给）

```text
金钱：100%（随关卡递增）
主题基础材料：60%-80%
次级材料：20%-40%
丹药/杂物：15%-30%
图纸残页：1%-5%（3 张合成 1 张完整图纸）
```

设计目的：保证基础制造节奏，如「2-3 场战斗可制作一阶竹剑」。

### 6.2 守护者（定向稀有，每关第 3 个敌人）

```text
固定关键材料：100%
对应槽位晶球：30%-50%
完整图纸/残页：20%-30%
首杀必掉：该关卡关键图纸或稀有配件材料
降妖令：首杀 +1，重复 +0（仅首杀给）
```

### 6.3 场景 BOSS（阶段门槛）

**首杀奖励**（一次性）：

```text
必掉关键图纸 ×1
灵气 ×1（地脉/天罡/混元，按关卡阶级）
降妖令 ×3-5
低概率解锁隐藏 BOSS 入口
```

**重复挑战奖励**：

```text
高阶材料包 ×1-2
灵气碎片 ×1-3
低概率专属配件
降妖令 ×1
```

### 6.4 隐藏 BOSS

```text
必掉：神秘宝箱 ×1
专属异化材料 ×1（如黑风残页→轻型速度靴子）
天罡灵气 ×1
降妖令 ×5
低概率特殊装备图纸
```

### 6.5 三大 BOSS（牛魔王/蝎子精/金翅大鹏）

```text
必掉：专属 BOSS 材料 ×1（牛魔角/毒囊/鹏羽）
天品图纸 ×1（首杀）
天罡灵气 ×2
混元灵气碎片 ×1
降妖令 ×10
```

### 6.6 最终 BOSS（六耳猕猴）

```text
必掉：混元灵气 ×1
仙品图纸 ×1（首杀）
混元灵气碎片 ×3
九转金丹碎片 ×2
降妖令 ×20
```

## 7. 概率、数量与保底机制

### 7.1 制造节奏控制

| 装备阶位 | 预期刷取场次（普通难度） | 说明 |
|----------|--------------------------|------|
| 一阶 | 2-4 场 | 新手快速成型 |
| 二阶 | 5-8 场 | 中期过渡 |
| 三阶 | 10-15 场 | 后期主力 |
| 天品/仙品 | 多次 BOSS 挑战 + 代币兑换 | 终局追求 |

### 7.2 概率区间建议

| 掉落类型 | 概率区间 | 说明 |
|----------|----------|------|
| 主题基础材料（普通敌人） | 60%-80% | 高频，保证节奏 |
| 次级材料（普通敌人） | 20%-40% | 中频 |
| 图纸残页（普通敌人） | 1%-5% | 低频，3 张合成 |
| 完整图纸（守护者） | 20%-30% | 中频 |
| 晶球（守护者） | 30%-50% | 中高频 |
| 灵气（BOSS） | 40%-60% | 中频 |
| BOSS 专属材料 | 100%（首杀）/ 30%-50%（重复） | 首杀必掉 |
| 天品/仙品图纸 | 100%（首杀） | 一次性 |

### 7.3 保底与幸运值

```text
每次未获得关键图纸/晶球，幸运值 +1。
幸运值满 5 时，下次必掉对应物品。
幸运值按关卡/敌人类型独立计算。
```

### 7.4 降妖令（代币系统）

**来源**：

```text
场景 BOSS 首杀：+3-5
隐藏 BOSS：+5
三大 BOSS：+10
最终 BOSS：+20
西行志悬赏：+1-3
困难守护者：+1
```

**用途**（坊市/洞府兑换）：

```text
指定图纸 ×1：10 降妖令
三阶晶球 ×1：5 降妖令
天罡灵气 ×1：8 降妖令
混元灵气碎片 ×1：15 降妖令
特殊配件材料 ×1：6 降妖令
强化保护符 ×1：3 降妖令
```

**目的**：消除纯 RNG 带来的挫败感，保证核心玩家有稳定毕业进度。

### 7.5 首杀与重复挑战分离

```text
首杀奖励 > 重复挑战奖励
首杀负责惊喜和解锁（如必掉灵霄宝匣、关键图纸）。
重复负责稳定积累（如掉基础材料、低概率残页）。
```

## 19. 最终掉落闭环

```text
玩家选择关卡（如：迷雾谷 困难）
  ↓
击败普通小怪 → 获得虎皮、仙云皮（三阶衣服材料）
  ↓
击败守护者 → 获得寒潭水（洗练材料）、三阶玲珑晶球、配件图纸残页
  ↓
击败场景 BOSS → 获得降妖令、天罡灵气、完整戒指图纸
  ↓
洞府制造 → 打造三阶衣服/戒指，使用寒潭水定向洗练出【毒伤/连击】词条
  ↓
挑战三大 BOSS → 获得毒囊，合成天品【万毒蚀心镯】（戒指）
  ↓
挑战最终 BOSS → 获得混元灵气，合成仙品装备
  ↓
降妖令兑换 → 补齐缺失图纸/材料，确保毕业预期
```
