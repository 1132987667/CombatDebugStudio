# 《西游斗战》装备系统补完设计稿

本章针对当前装备设定的不足，补全以下内容：

1. **装备品级差异**：凡品、玄品、地品、天品、仙品装备之间的区别。
2. **装备品质差异**：凡、精、超、绝、神之间的区别。
3. **不同装备类型的属性定位**：武器、衣服、各饰件的属性设计。
4. **随机词条设计**：词条池、词条权重、词条数值、生成规则。
5. **强化、附魔、升星、洗练、传承、分解等装备操作**。
6. **与材料、掉落、BOSS、制造系统的关联**。

设计原则：

```text
装备不引入等级需求。
装备成长主要通过阶位、品质、强化、附魔、升星、词条实现。
所有操作必须与现有材料、晶球、灵气、特殊掉落形成关联。
数值控制在 10000 以内，避免后期膨胀。
制造仍然是核心获取方式，BOSS 掉落作为补充和追求。
```

---

# 1. 装备品级体系总览

当前文档中的“装备品级”容易混淆，建议拆分为四个维度：

```text
阶位：凡品 / 玄品 / 地品 / 天品 / 仙品
品质：凡 / 精 / 超 / 绝 / 神
星级：0 星 / 1 星 / 2 星 / 3 星
锻造状态：强化等级 / 附魔槽 / 洗练状态
```

四个维度分别承担不同作用：

| 维度 | 作用 | 主要来源 |
|---|---|---|
| 阶位 | 决定装备基础属性区间和成长上限 | 场景材料、关卡进度 |
| 品质 | 决定基础属性系数和词条数量 | 制造、技艺、特殊材料 |
| 星级 | 提升基础属性，增强长期价值 | 同名装备消耗 |
| 锻造状态 | 玩家后续养成操作 | 强化、附魔、洗练、传承 |

# 2. 阶位差异设计

装备分为凡品、玄品、地品、天品四阶，另加仙品装备作为终局追求。

## 2.1 凡品装备

定位：

```text
新手期装备。
服务关卡 1-3。
帮助玩家完成第一次制造、强化、词条认知。
```

特点：

```text
基础属性低。
强化上限低。
词条数值低。
制造成本低。
主要用于过渡。
```

建议属性范围：

| 部位 | 主属性范围 |
|---|---:|
| 轻型武器 | 攻击 8-12 |
| 中型武器 | 攻击 10-15 |
| 重型武器 | 攻击 12-18 |
| 皮甲 | 防御 6 |
| 木甲 | 防御 8 |
| 铠甲 | 防御 10 |
| 护符 | 气血 +5% |
| 戒指 | 攻击 +5% |
| 项链 | 防御 +5% |
| 腰带 | 速度 +5% |
| 手镯 | 暴击率 +3% |
| 冠冕 | 全属性 +2% |

成长限制：

```text
强化上限：+5

词条数值：低档
洗练：仅普通洗练
```

## 2.4 天品装备

定位：

```text
高阶追求装备。
不通过普通材料制造，而是由三大 BOSS、特殊材料合成获得。
```

来源：

```text
牛魔角 → 牛魔系天品武器或饰品
毒囊 → 毒系天品饰品或武器
鹏羽 → 速度系天品饰品或轻型装备
玉佛像 → 佛门天品饰品
```

天品装备特点：

```text
默认品质为绝，基础系数 131%-140%，可消耗资源补全至 140%。
拥有固定天品特效。
可携带 4 条随机词条。
可强化至 +15。
可附魔 3 个槽位。
可随意重铸。
不可升星。
不可传承。
不可分解。
```

天品装备示例：

| 天品装备 | 材料来源 | 定位 | 固定特效建议 |
|---|---|---|---|
| 牛魔撼天锤 | 牛魔角 | 重型爆发 | 攻击时概率降低目标防御 |
| 万毒蚀心镯 | 毒囊 | 毒系持续伤害 | 攻击命中概率附加中毒 |
| 大鹏逐日冠 | 鹏羽 | 速度闪避 | 闪避后提升下次攻击暴击率 |
| 玉佛净心冕 | 玉佛像 | 生存净化 | 每回合概率清除一个负面状态 |

# 3. 品质差异设计

品质共五档：凡 / 精 / 超 / 绝 / 神。

```text
凡：基础属性 101%-110%，1 词条
精：基础属性 111%-120%，2 词条
超：基础属性 121%-130%，3 词条
绝：基础属性 131%-140%，4 词条
神：基础属性 141%-150%，5 词条
```

品质与阶位正交：凡品 / 玄品 / 地品装备通过制造获得凡 / 精 / 超品质；天品装备固定绝品质，仙品装备固定神品质。

---

## 3.1 品质总表

| 品质 | 基础系数 | 词条数 | 附魔槽 | 洗练权限 | 分解价值 | 定位 |
|---|---|---:|---:|---:|---|---:|---|
| 凡 | 101%-110% | 1 | 0 | 普通洗练 | 低 | 基础可用装备 |
| 精 | 111%-120% | 2 | 1 | 普通 / 定向洗练 | 中 | 中期主力 |
| 超 | 121%-130% | 3 | 2 | 普通 / 定向 / 锁词条洗练 | 高 | 后期主力 |
| 绝 | 131%-140% | 4 | 3 | 有限洗练 | 不可分解 | 天品装备专属品质 |
| 神 | 141%-150% | 5 | 3 | 有限洗练 | 不可分解 | 仙品装备专属品质 |

绝 / 神品质说明：

```text
天品：默认品质为绝，基础系数 131%-140%，可消耗资源补全至 140%。
仙品：默认品质为神，基础系数 141%-150%，可消耗资源补全至 150%。
```

---

# 5. 随机词条系统设计

随机词条是装备长期追求的核心。  
但词条数量不能过多，数值不能失控。

---

## 5.1 词条分类

词条分为五类：

```text
通用词条
部位词条
流派专属词条
元素词条
天品词条
```

---

## 5.2 通用词条池

通用词条可以出现在大多数装备上。

| 词条 | 适用部位 | 说明 |
|---|---|---|
| 攻击 +X | 武器、戒指、冠冕 | 固定攻击提升 |
| 攻击 +X% | 武器、戒指、冠冕 | 百分比攻击提升 |
| 防御 +X | 衣服、项链、冠冕 | 固定防御提升 |
| 防御 +X% | 衣服、项链、冠冕 | 百分比防御提升 |
| 气血 +X | 衣服、护符、冠冕 | 固定气血提升 |
| 气血 +X% | 衣服、护符、冠冕 | 百分比气血提升 |
| 速度 +X | 腰带、轻型武器 | 固定速度提升 |
| 速度 +X% | 腰带、冠冕 | 百分比速度提升 |
| 暴击率 +X% | 手镯、武器 | 暴击提升 |
| 暴击伤害 +X% | 手镯、中型武器 | 爆发提升 |
| 命中 +X% | 手镯、戒指 | 对抗闪避敌人 |
| 闪避 +X% | 皮甲、腰带 | 生存提升 |
| 格挡 +X% | 铠甲、重型武器 | 磐石道核心 |

## 5.7 词条生成规则

制造装备时按以下流程生成词条：

```text
第一步：根据装备阶位确定词条数值区间。
第二步：根据品质确定词条数量。
第三步：根据装备部位选择对应词条池。
第四步：按权重随机抽取词条。
第五步：检查是否与装备类型冲突。
第六步：生成数值。
```

品质决定词条数：

```text
凡：1 条
精：2 条
超：3 条
绝：4 条
神：5 条
```

词条不可重复：

```text
同一件装备不允许出现两条同名词条。
例如不能同时出现两个“暴击率 +3%”。
```

### 通用权重

| 词条类型 | 权重 |
|---|---:|
| 主属性相关 | 100 |
| 攻防血速基础词条 | 80 |
| 暴击、命中、闪避 | 50 |
| 流派专属词条 | 30 |
| 元素词条 | 10，通常由附魔获得 |
| 特殊机制词条 | 5-10 |

---

## 5.9 流派倾向设计

为了让装备更贴近 Build，建议制造材料影响词条倾向。

示例：

```text
使用桃木、松木、铁木制造轻型武器时，灵猴道词条权重提升。
使用铜精、铁精、金精制造中型武器时，金行道词条权重提升。
使用粗石、铁焰矿、金阳矿制造重型武器时，磐石道词条权重提升。
使用鹿皮、虎皮、仙云皮制造皮甲时，灵猴道词条权重提升。
使用圣水玉、玉佛像制造饰品时，佛门 / 生存词条权重提升。
使用毒液、寒潭水制造饰品时，元素 / 异常词条权重提升。
```

这样材料不仅决定能做什么装备，也决定装备可能出现的词条方向。

# 6. 强化系统设计

强化是最基础的装备养成操作。  
现有规则已有框架，这里补全细节。

---

## 6.1 强化定位

```text
强化提升装备基础属性。
强化不影响随机词条。
强化不改变装备品质。
强化是稳定消耗晶球、异矿、灵水、灵气的核心出口。
```

---

## 6.2 强化部位规则

| 装备类型 | 强化提升内容 |
|---|---|
| 武器 | 攻击力提升 |
| 衣服 | 防御力提升 |
| 护符 | 气血加成提升 |
| 戒指 | 攻击加成提升 |
| 项链 | 防御加成提升 |
| 腰带 | 速度加成提升 |
| 手镯 | 暴击率加成提升 |
| 冠冕 | 全属性加成提升 |

---

## 6.3 强化上限

| 阶位 | 强化上限 |
|---|---:|
| 凡品 | +5 |
| 玄品 | +10 |
| 地品 | +15 |
| 天品 | +15 |
| 仙品 | +20 |

---

## 6.4 强化消耗

### 武器强化

```text
消耗灿金晶球或异矿。
```

### 衣服强化

```text
消耗清辉晶球或灵气。
```

### 饰品强化

```text
消耗玲珑晶球或灵水。
```

### 金钱消耗建议

| 阶位 | 金钱消耗公式 |
|---|---:|
| 凡品 | 20 × 目标强化等级 |
| 玄品 | 50 × 目标强化等级 |
| 地品 | 100 × 目标强化等级 |
| 天品 | 150 × 目标强化等级 |
| 仙品 | 200 × 目标强化等级 |

示例：

```text
地品武器从 +7 强化到 +8：
消耗：地品灿金晶球 ×1
金钱：100 × 8 = 800
成功率：50%
```

---

## 6.5 强化成功率与失败机制

保留知识库设定：

```text
成功率：50%
失败：不降级
失败：仅消耗材料与金钱
```

建议增加隐藏保底机制：

```text
每次强化失败，积累 1 点匠心。
1 点匠心提升 5% 下次强化成功率。
匠心最多提升 25%。
强化成功后匠心清零。
```

这样实际成功率区间为：

```text
首次：50%
连续失败 1 次后：55%
连续失败 2 次后：60%
连续失败 3 次后：65%
连续失败 4 次后：70%
连续失败 5 次后：75%
```

避免玩家因连续失败产生过强挫败感。

---

## 6.6 强化数值效果

### 武器 / 衣服

```text
每级提升 5% 基础属性
```

### 饰品

```text
每级提升 3% 主属性加成
```

示例：

```text
地品流云剑基础攻击：25-35
强化 +15：
25-35 × (1 + 15 × 5%)
= 25-35 × 1.75
= 43.75 - 61.25
```

再叠加品质、技艺、星级后仍可控制在合理范围内。

---

## 6.7 强化传承

强化传承仅适用于凡品、玄品、地品装备。

```text
天品装备不可传承。
仙品装备不可传承。
```

传承条件：

```text
1. 同部位。
2. 同阶位。
3. 目标装备未强化，或强化等级低于来源装备。
```

传承内容：

```text
仅转移强化等级。
```

不转移内容：

```text
品质、星级、随机词条、固定特效、附魔。
```

传承结果：

```text
目标装备获得来源装备的强化等级。
来源装备强化等级清零。
```

传承成本建议：

```text
金钱：目标强化等级 × 阶位基础强化金钱
材料：地脉灵气 ×1
```

例如：

```text
将 +10 玄品迅风剑传承到另一把玄品迅风剑：
消耗金钱：50 × 10 = 500
消耗地脉灵气 ×1
```

跨阶传承不建议开放，避免地品强化被低成本转移到更高阶装备，破坏成长曲线。

# 7. 附魔系统设计

附魔是装备差异化追求的重要来源。  
它与随机词条的区别在于：

```text
词条：制造时随机生成。
附魔：玩家后期主动附加，偏可控。
```

---

## 7.1 附魔定位

```text
附魔不改变装备基础属性。
附魔提供额外属性或元素效果。
附魔消耗特殊材料。
附魔是毒液、寒潭水、铁焰矿、金阳矿、神泉水、珍珠、圣水玉、玉佛像的重要用途。
```

---

## 7.2 附魔槽解锁规则

| 品质 | 附魔槽数量 |
|---|---:|
| 凡 | 0 |
| 精 | 1 |
| 超 | 2 |
| 绝 | 3 |
| 神 | 3 |

星级可轻微增强附魔效果，但不增加附魔槽：

```text
每 1 星，附魔效果 +5%
```

这样符合现有“升星暂不解锁额外词条”的设定。

---

## 7.3 附魔类型

附魔分为四类：

```text
属性附魔
元素附魔
流派附魔
特殊附魔
```

---

## 7.4 属性附魔

属性附魔提供稳定数值。

| 附魔 | 效果 | 建议材料 |
|---|---|---|
| 锐利 | 攻击 +X | 铜精、铁精、金精 |
| 坚固 | 防御 +X | 粗石、铁精、金精 |
| 滋养 | 气血 +X | 淡水玉、深水玉、圣水玉 |
| 轻身 | 速度 +X | 宣纸、虎皮、仙云皮 |
| 精准 | 命中 +X% | 贝壳、珍珠 |
| 稳固 | 韧性 +X% | 古铜镜、圣水玉 |

属性附魔数值应低于随机词条，避免数值膨胀。

---

## 7.5 元素附魔

元素附魔主要来自特殊材料，是附魔系统的核心惊喜点。

### 火附：铁焰矿


适合：

```text
武器
```

### 冰附：寒潭水

```text

```

适合：

```text
武器、手镯
```

---

### 毒附：毒液

```text
攻击时 8% 概率施加中毒 1 层。
中毒每回合损失 3% 最大气血。
最多 3 层，持续 3 回合。
```

适合：

```text
武器、戒指
```

---

### 风附：金阳矿

```text
速度 +X。
攻击时 5% 概率获得 10 点能量。
```

适合：

```text
腰带、轻型武器
```

---

### 泉附：神泉水

```text
每回合恢复 1% 最大气血。
受到治疗效果 +5%。
```

适合：

```text
护符、木甲
```

---

### 珠附：珍珠

```text
护盾效果 +5%。
受到治疗效果 +5%。
```

适合：

```text
护符、项链
```

---

### 圣附：圣水玉

```text
异常状态抗性 +5%。
受击时 5% 概率恢复 2% 最大气血。
```

适合：

```text
护符、冠冕、衣服
```

---

### 佛附：玉佛像

```text
控制抗性 +5%。

```

适合：

```text
冠冕、项链、护符
```

---

## 7.6 流派附魔

流派附魔用于强化特定 Build。

| 流派附魔 | 效果 | 建议材料 |
|---|---|---|
| 灵猴之影 | 连击率 +3% | 仙云皮、神泉水 |
| 金行之锋 | 暴击伤害 +8% | 金精、金阳矿 |
| 磐石之固 | 格挡率 +5% | 粗石、古铜镜、圣水玉 |
| 疾风之息 | 能量获取 +8% | 虎皮、仙云皮 |
| 破军之锐 | 无视防御 +5% | 铁精、铁焰矿 |
| 不动之守 | 受击能量获取 +10% | 金精、圣水玉 |

流派附魔只能出现在对应类型装备上：

```text
灵猴附魔：轻型武器、皮甲、腰带、手镯
金行附魔：中型武器、戒指、手镯、冠冕
磐石附魔：重型武器、铠甲、项链、护符
```

## 7.7 附魔操作规则

### 附魔

```text
玩家选择装备和附魔材料。
若装备有空槽，则直接附加。
若无空槽，则选择覆盖旧附魔。
```

### 附魔成功率

建议：

```text
属性附魔：100%
元素附魔：80%
流派附魔：80%
特殊附魔：70%
```

失败结果：

```text
不破坏装备。
不降低品质。
仅消耗材料。
```

### 附魔注灵

玩家可以使用灵气提升附魔数值。

```text
每次注灵消耗地脉灵气 ×1。
附魔数值提升 5%。
最多注灵 3 次。
```

高阶附魔可使用天罡灵气：

```text
天罡灵气可提升 10%。
```

混元灵气可用于锁定附魔：

```text
覆盖附魔时保留原附魔数值。
```

# 8. 升星系统设计

升星仅适用于凡品、玄品、地品装备。

```text
天品装备不可升星。
仙品装备不可升星。
```

升星规则：

```text
默认 0 星
最高 3 星
升星需要相同装备
数量：1 星 3 / 2 星 6 / 3 星 9
每星提升 10% 基础属性
每星提升 5% 附魔效果
暂不解锁额外词条
```

升星不改变：

```text
装备品质。
装备阶位。
随机词条数量。
随机词条内容。
固定特效。
```

---

## 8.1 升星效果

| 星级 | 基础属性加成 | 附魔效果加成 |
|---|---:|---:|
| 0 星 | 0% | 0% |
| 1 星 | +10% | +5% |
| 2 星 | +20% | +10% |
| 3 星 | +30% | +15% |

说明：

```text
升星不增加词条数量。
升星不改变词条内容。
升星增强基础属性和附魔效果。
```

---

## 8.2 升星材料替代方案

同名装备消耗 3 / 6 / 9 可能导致玩家重复制造旧装备。  
建议加入替代材料：

```text
装备残魂
```

获取：

```text
分解同名装备
击败对应关卡守护者
完成西行志悬赏
```

规则：

```text
1 件同名装备 = 1 点装备残魂
升星可用同名装备或装备残魂混合消耗。
```

例如：

```text
流云剑升 1 星：
需要 3 点残魂
可以是 3 件流云剑
也可以是 2 件流云剑 + 1 点残魂
```

这样减少仓库压力，并让分解系统有价值。

# 9. 洗练与重铸设计

洗练用于调整随机词条。  
为了避免系统过重，洗练应保持克制。

---

## 9.1 洗练权限

| 品质 | 可执行操作 |
|---|---|
| 凡 | 普通洗练 |
| 精 | 普通洗练、定向洗练 |
| 超 | 普通洗练、定向洗练、锁词条洗练 |
| 绝 | 仅限绝品洗练，不可改变固定特效 |
| 神 | 仅限神品洗练，不可改变固定特效 |

---

## 9.2 普通洗练

效果：

```text
随机重置装备上的 1 条词条。
```

消耗：

```text
寒潭水 ×1
金钱 ×当前阶位基础费用
```

结果：

```text
玩家可选择保留旧词条，或替换为新词条。
```

这个设计非常重要，可以避免洗练变成纯负反馈。

---

## 9.3 定向洗练

效果：

```text
将 1 条词条替换为指定类型词条。
```

消耗：

```text
寒潭水 ×2
对应特殊材料 ×1
金钱 ×较高费用
```

示例：

```text
定向洗练连击率：
消耗寒潭水 ×2 + 仙云皮 ×1

定向洗练暴击伤害：
消耗寒潭水 ×2 + 金精 ×1

定向洗练格挡率：
消耗寒潭水 ×2 + 古铜镜 ×1
```

定向洗练不保证数值满值，只保证词条类型。

---

## 9.4 锁词条洗练

效果：

```text
洗练时锁定 1 条词条，不被重置。
```

消耗：

```text
天罡灵气碎片 ×3 或 天罡灵气 ×1
寒潭水 ×3
金钱 ×高费用
```

限制：

```text
最多锁定 1 条词条。
天品、仙品装备不可锁定固定特效。
```

---

## 9.5 重铸

重铸与洗练不同：

```text
洗练：改变词条。
重铸：重新生成整件装备的词条。
```

建议仅超品及以上品质装备开放重铸；天品、仙品装备可随意重铸。

消耗：

```text
混元灵气碎片 ×5 或 混元灵气 ×1
对应阶位晶球 ×1
大量金钱
```

结果：

```text
装备品质不变。
强化等级保留。
附魔保留。
星级保留。
所有随机词条重新生成。
```

重铸是终局装备追求完美词条的手段，不应频繁使用。

# 10. 传承、分解与回收设计

---

## 10.1 强化传承

强化传承仅适用于凡品、玄品、地品装备。

```text
天品装备不可传承。
仙品装备不可传承。
```

传承条件：

```text
1. 同部位。
2. 同阶位。
3. 目标装备未强化，或强化等级低于来源装备。
```

传承内容：

```text
仅转移强化等级。
```

不转移内容：

```text
品质、星级、随机词条、固定特效、附魔。
```

传承结果：

```text
目标装备获得来源装备的强化等级。
来源装备强化等级清零。
```

成本：金钱 + 地脉灵气（详见 §6.7）。

---

## 10.2 附魔剥离

建议附魔不可剥离，避免系统过重。

但可以允许：

```text
使用混元灵气将附魔封存到另一件同阶装备。
```

消耗：

```text
混元灵气碎片 ×3
```

结果：

```text
附魔转移到新装备。
原装备附魔槽清空。
```

---

## 10.3 装备分解

分解用于处理多余装备。

### 分解产出建议

| 装备品质 | 分解产出 |
|---|---|
| 凡 | 金钱 + 基础材料 ×1 |
| 精 | 金钱 + 基础材料 ×2 + 低概率晶球碎片 |
| 超 | 金钱 + 高级材料 ×1 + 装备残魂 ×1 |
| 绝 | 不可分解 |
| 神 | 不可分解 |

分解同名装备额外产出：

```text
该装备残魂 ×1
```

这样分解不仅清理库存，还服务升星。

# 11. 装备最终属性公式

建议采用分层公式，便于控制数值。

---

## 11.1 基础属性公式

```text
装备基础属性
= 原始基础属性
× 品质系数
× (1 + 技艺等级 × 5%)
× (1 + 强化等级 × 强化系数)
× (1 + 星级 × 10%)
```

品质系数：

```text
凡：1.01 - 1.10
精：1.11 - 1.20
超：1.21 - 1.30
绝：1.31 - 1.40
神：1.41 - 1.50
```

强化系数：

```text
武器 / 衣服：5%
饰品：3%
```

---

## 11.2 词条属性公式

词条属性独立计算：

```text
最终角色属性
= 角色基础属性
+ 装备基础属性总和
+ 装备词条固定值总和

然后：
最终角色属性
× (1 + 装备百分比词条总和)
× (1 + 附魔百分比效果总和)
× (1 + 套装效果总和)
```

百分比词条建议加算，避免乘算导致失控。

---

## 11.3 附魔效果公式

```text
附魔最终效果
= 附魔基础效果
× (1 + 星级 × 5%)
× (1 + 注灵次数 × 5%)
```

---

## 11.4 数值上限控制

为避免超过 10000，建议：

```text
固定攻击词条总和不超过 200
百分比攻击词条总和不超过 80%
暴击伤害总和不超过 300%
连击率总和不超过 60%
闪避率总和不超过 40%
格挡率总和不超过 60%
控制概率总和不超过 35%
```

终局玩家预期：

```text
气血：2000 - 4500
攻击：400 - 1200
防御：200 - 700
速度：60 - 140
暴击率：25% - 55%
暴击伤害：150% - 260%
```

最终 BOSS 气血 2600，仍可形成合理战斗长度。

# 13. 装备养成闭环总览

完整装备循环如下：

```text
战斗获得材料
      ↓
洞府制造装备
      ↓
获得品质与随机词条
      ↓
穿戴装备
      ↓
消耗晶球 / 异矿 / 灵水 / 灵气强化装备
      ↓
消耗特殊材料附魔装备
      ↓
消耗同名装备或装备残魂升星
      ↓
使用寒潭水 / 特殊材料洗练词条
      ↓
挑战更高难度敌人
      ↓
获得更高阶材料与稀有附魔材料
      ↓
制造地品超品装备
      ↓
挑战场景 BOSS、隐藏 BOSS、三大 BOSS
      ↓
获得天品材料
      ↓
制作天品装备
      ↓
挑战最终 BOSS
```

# 15. 最终设计结论

当前装备设定不足的核心原因是：

```text
只有基础属性和品质词条，缺少后续养成层次。
装备之间差异主要由数值高低构成，缺少风格差异。
特殊材料、晶球、灵气、BOSS 材料没有完全进入装备循环。
```

补全后的装备系统应遵循：

```text
阶位决定装备上限。
品质决定词条和附魔空间。
装备类型决定战斗风格。
随机词条决定 Build 差异。
强化提供稳定成长。
附魔提供材料消耗和惊喜感。
升星提供长线追求。
洗练提供超品装备优化空间。
仙品装备提供终局目标。
```

这样装备系统不再只是“攻击力更高的工具”，而会成为玩家反复战斗、收集材料、挑战 BOSS 的核心动力。
