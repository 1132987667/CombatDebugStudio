# 《西游斗战》装备系统补完设计稿（v2.0）
> **版本**：v2.0  
> **更新日期**：2026-08-11  
> **变更说明**：装备类型体系重构——原「武器 / 衣服 / 饰品」三槽改为六槽（武器 / 衣服 / 头盔 / 靴子 / 护符 / 戒指），新增法宝与神器为独立类型。原「饰品」子类并入新槽位：项链→头盔、腰带→靴子、手镯→戒指、冠冕→头盔。

---

本章针对当前装备设定的不足，补全以下内容：

1. **装备品级差异**：凡品、玄品、地品、天品、仙品装备之间的区别。
2. **装备品质差异**：凡、精、超、绝、神之间的区别。
3. **不同装备类型的属性定位**：武器、衣服、头盔、靴子、护符、戒指，以及法宝、神器的属性设计。
4. **随机词条设计**：词条池、词条权重、词条数值、生成规则。
5. **强化、附魔、升星、洗练、传承、分解等装备操作**。
6. **与材料、掉落、BOSS、制造系统的关联**。

设计原则：

```text
装备不引入等级需求。
装备成长主要通过阶位、品质、强化、附魔、升星、词条实现。
所有操作必须与现有材料、晶球、灵气、特殊掉落形成关联。
数值控制在 10000 以内，避免后期膨胀。
制造仍然是核心获取方式，BOSS 掉落作为补充和追求。
```

# 1. 装备品级体系总览

当前文档中的"装备品级"容易混淆，建议拆分为四个维度：

```text
阶位：凡品 / 玄品 / 地品 / 天品 / 仙品
品质：凡 / 精 / 超 / 绝 / 神
星级：0 星 / 1 星 / 2 星 / 3 星
锻造状态：强化等级 / 附魔槽 / 洗练状态
```

四个维度分别承担不同作用：

| 维度 | 作用 | 主要来源 |
|------|------|----------|
| 阶位 | 决定装备基础属性区间和成长上限 | 场景材料、关卡进度 |
| 品质 | 决定基础属性系数和词条数量 | 制造、技艺、特殊材料 |
| 星级 | 提升基础属性，增强长期价值 | 同名装备消耗 |
| 锻造状态 | 玩家后续养成操作 | 强化、附魔、洗练、传承 |

# 2. 阶位差异设计

装备分为凡品、玄品、地品、天品四阶，另加仙品装备作为终局追求。

## 2.1 凡品装备

定位：

```text
新手期装备。
服务关卡 1-3。
帮助玩家完成第一次制造、强化、词条认知。
```

特点：

```text
基础属性低。
强化上限低。
词条数值低。
制造成本低。
主要用于过渡。
```

建议属性范围：

| 部位 | 主属性范围 |
|------|-----------|
| 轻型武器 | 攻击 8-12 |
| 中型武器 | 攻击 10-15 |
| 重型武器 | 攻击 12-18 |
| 皮甲 | 防御 6 |
| 木甲 | 防御 8 |
| 铠甲 | 防御 10 |
| 头盔 | 防御 +5% |
| 靴子 | 速度 +5% |
| 护符 | 气血 +5% |
| 戒指 | 攻击 +5% / 暴击率 +3% |

成长限制：

```text
强化上限：+5
附魔槽：最多 1 个
词条数值：低档
洗练：仅普通洗练
```

## 2.2 玄品装备

```text
中期主力装备。
服务关卡 4-6。
开始承担流派 Build 作用。
```

特点：

```text
基础属性明显提升。
强化上限提升。
可出现更完整的流派词条。
附魔槽增加。
```

建议属性范围：

| 部位 | 主属性范围 |
|------|-----------|
| 轻型武器 | 攻击 15-22 |
| 中型武器 | 攻击 18-27 |
| 重型武器 | 攻击 22-32 |
| 皮甲 | 防御 12 |
| 木甲 | 防御 16 |
| 铠甲 | 防御 20 |
| 头盔 | 防御 +8% |
| 靴子 | 速度 +8% |
| 护符 | 气血 +8% |
| 戒指 | 攻击 +8% / 暴击率 +5% |

成长限制：

```text
强化上限：+10
附魔槽：最多 2 个
词条数值：中档
洗练：开放普通洗练与定向洗练
```

|------|-----------|
| 轻型武器 | 攻击 30-42 |
| 中型武器 | 攻击 36-50 |
| 重型武器 | 攻击 42-60 |
| 皮甲 | 防御 20 |

成长限制：

```text

词条数值：高档
洗练：开放普通洗练、定向洗练与锁词条洗练
```

## 2.4 天品装备

定位：

```text
终局追求装备。
由三大 BOSS 材料定向合成。
拥有固定天品特效。
```

特点：

```text
基础系数 121%-140%。
4 条随机词条。
3 个附魔槽。
拥有固定天品特效。
不可升星。
不可传承。
不可分解。
可随意重铸。
```

成长限制：

```text
强化上限：+15
附魔槽：最多 3 个
词条数值：高档
洗练：仅限绝品洗练（天命洗炼符），不可改变固定特效
```

## 2.5 仙品装备

定位：

```text
终局最强装备。
由最终 BOSS 材料定向合成。
默认品质为神。
```

特点：

```text
基础系数 141%-150%，可消耗资源补全至 150%。
5 条随机词条。
3 个附魔槽。
拥有固定仙品特效。
不可升星。
不可传承。
不可分解。
可随意重铸。
```

成长限制：

```text
强化上限：+20
附魔槽：最多 3 个
词条数值：最高档
洗练：仅限神品洗练（天命洗炼符），不可改变固定特效
```

## 2.6 绝 / 神品与凡 / 精 / 超品的区别

```text
凡 / 精 / 超品：制造体系内可重复获得，可升星、可传承、可分解。
绝 / 神品：由 BOSS 材料定向合成，拥有固定特效，不可升星、不可传承、不可分解，可随意重铸。
```

# 3. 品质差异设计

品质决定装备的基础属性系数与随机词条数量。

| 品质 | 基础属性系数 | 随机词条数量 | 获取方式 |
|------|-------------|-------------|----------|
| 凡 | 80%-90% | 1 条 | 制造（低技艺） |
| 精 | 91%-105% | 2 条 | 制造（中技艺） |
| 超 | 106%-120% | 3 条 | 制造（高技艺）/ 特殊材料 |
| 绝 | 121%-140% | 4 条 | BOSS 材料定向合成（天品） |
| 神 | 141%-150% | 5 条 | 最终 BOSS 材料定向合成（仙品） |

品质生成规则：

```text
制造时根据技艺等级、材料品质、运气因素综合判定。
技艺等级越高，高品质概率越大。
使用特殊材料可提升品质下限。
```

# 4. 不同装备类型的属性设定

装备分为六类槽位与两大独立类型：

```text
六类槽位：武器 / 衣服 / 头盔 / 靴子 / 护符 / 戒指
两大独立类型：法宝 / 神器
```

其中武器影响输出节奏，衣服影响生存方式，头盔与靴子补齐头部与腿部防御，护符与戒指塑造 Build 细节；法宝提供成长型战力，神器提供稀有特效。

> **槽位迁移说明**：原「饰品」子类并入新槽位——项链→头盔、腰带→靴子、手镯→戒指、冠冕→头盔。

## 4.1 武器属性设计

武器主属性为攻击力。不同类型的武器决定战斗风格。

### 4.1.1 轻型武器

定位：

```text
高攻速
连击
能量循环
灵猴道适配
```

基础属性：

```text
主属性：攻击力
副属性倾向：攻速、连击率、能量获取
```

### 4.1.2 中型武器

定位：

```text
爆发输出
暴击
金行道适配
```

基础属性：

```text
主属性：攻击力
副属性倾向：暴击率、暴击伤害、命中
```

### 4.1.3 重型武器

定位：

```text
重击控制
生存优先
磐石道适配
```

基础属性：

```text
主属性：攻击力
副属性倾向：格挡率、受击能量获取、伤害减免
```

## 4.2 衣服属性设计

衣服主属性为防御力，决定生存方式。

### 4.2.1 皮甲（轻型）

定位：

```text
轻装闪避
灵猴道适配
```

基础属性：

```text
主属性：防御力
副属性倾向：闪避率、速度
```

### 4.2.2 木甲（中型）

定位：

```text
均衡防御
通用
```

基础属性：

```text
主属性：防御力
副属性倾向：气血百分比、治疗效果
```

### 4.2.3 铠甲（重型）

定位：

```text
重装格挡
磐石道适配
```

基础属性：

```text
主属性：防御力
副属性倾向：格挡率、伤害减免、韧性
```

## 4.3 头盔属性设计

头盔主属性为防御百分比或全属性百分比，是防御向与综合向的核心部位。

（原「项链」的防御定位与「冠冕」的综合定位并入头盔。）

主属性：

```text
防御百分比 / 全属性百分比
```

适合副词条：

```text
伤害减免
韧性
控制抗性
反弹伤害
格挡率
能量获取
技能伤害
护盾效果
全属性加成
```

定位：

```text
防御向 / 综合向核心部位
```

## 4.4 靴子属性设计

靴子主属性为速度，决定先手与行动节奏。

（原「腰带」的速度定位并入靴子。）

主属性：

```text
速度百分比
```

适合副词条：

```text
闪避率
能量获取
先手概率
速度
受击能量获取
```

定位：

```text
节奏向部位
```

## 4.5 护符属性设计

护符不直接提供大量攻防，而是塑造生存 Build。

主属性：

```text
气血百分比
```

适合副词条：

```text
气血恢复
护盾效果
治疗效果
异常状态抗性
韧性
```

定位：

```text
生存向部位
```

## 4.6 戒指属性设计

戒指主属性为攻击与暴击，是输出 Build 的核心。

（原「手镯」的暴击定位并入戒指。）

主属性：

```text
攻击百分比 / 暴击率
```

适合副词条：

```text
暴击率
暴击伤害
命中
技能伤害
对异常目标伤害
精准
连击率
大招伤害
```

定位：

```text
输出向 / 爆发向核心部位
```

## 4.7 法宝属性设计

法宝是独立于六槽之外的成长型装备（如意金箍棒、九齿钉耙、降妖宝杖、芭蕉扇、紫金红葫芦等），不占槽位，与角色绑定出战。

定位：

```text
成长型战力
喂养升级
觉醒解锁本源神通
```

主属性：

```text
随等级成长的基础属性（攻击/防御/气血）
专属技能（随觉醒解锁）
```

成长规则：

```text
法宝通过喂养材料升级。
每次升级提升基础属性。
达到特定等级解锁专属技能。
法宝不可交易、不可分解。
```

## 4.8 神器属性设计

神器是终局追求的稀有装备，拥有独特特效。

定位：

```text
稀有特效
终局追求
不可成长
```

特点：

```text
固定特效，不可洗练。
不可强化、不可升星。
仅通过终极内容获取。
```

## 5.4 词条数值分档

| 阶位 | 词条数值区间 |
|------|-------------|
| 凡品 | 低档（区间下限 60%-80%） |
| 玄品 | 中档（区间 70%-90%） |
| 地品 | 高档（区间 80%-100%） |
| 天品 | 最高档（区间 90%-100%） |
| 仙品 | 满值（100%） |

## 5.5 词条生成规则

```text
第一步：确定装备阶位。
第二步：根据品质确定词条数量。
第三步：根据装备部位选择对应词条池。
第四步：按权重随机抽取词条。
第五步：检查是否与装备类型冲突。
第六步：生成数值。
```

品质决定词条数：

```text
凡：1 条
精：2 条
超：3 条
绝：4 条
神：5 条
```

词条不可重复：

```text
同一件装备不允许出现两条同名词条。
例如不能同时出现两个"暴击率 +3%"。
```

## 5.6 词条权重设计

### 通用权重

| 词条类型 | 权重 |
|----------|------|
| 主属性相关 | 100 |
| 攻防血速基础词条 | 80 |
| 暴击、命中、闪避 | 50 |
| 流派专属词条 | 30 |
| 元素词条 | 10，通常由附魔获得 |
| 特殊机制词条 | 5-10 |

## 5.7 流派倾向设计

为了让装备更贴近 Build，建议制造材料影响词条倾向。

示例：

```text
使用桃木、松木、铁木制造轻型武器时，灵猴道词条权重提升。
使用铜精、铁精、金精制造中型武器时，金行道词条权重提升。
使用粗石、铁焰矿、金阳矿制造重型武器时，磐石道词条权重提升。
使用鹿皮、虎皮、仙云皮制造皮甲时，灵猴道词条权重提升。
使用圣水玉、玉佛像制造护符、戒指时，佛门 / 生存词条权重提升。
使用毒液、寒潭水制造戒指时，元素 / 异常词条权重提升。
```

这样材料不仅决定能做什么装备，也决定装备可能出现的词条方向。

## 5.8 装备最终属性公式

```text
装备基础属性 = 原始基础属性 × 品质系数 × (1 + 技艺等级 × 5%) × (1 + 强化等级 × 强化系数) × (1 + 星级 × 10%)

最终角色属性 = 角色基础属性 + 装备基础属性总和 + 装备词条固定值总和

然后：
最终角色属性 × (1 + 装备百分比词条总和) × (1 + 附魔百分比效果总和) × (1 + 套装效果总和)
```


## 8.2 升星材料替代方案

同名装备消耗 3 / 6 / 9 可能导致玩家重复制造旧装备。建议加入替代材料：

```text
装备残魂
```

获取：

```text
分解同名装备
击败对应关卡守护者
完成西行志悬赏
```

规则：

```text
1 件同名装备 = 1 点装备残魂
升星可用同名装备或装备残魂混合消耗。
```

例如：

```text
流云剑升 1 星：需要 3 点残魂
可以是 3 件流云剑
也可以是 2 件流云剑 + 1 点残魂
```

这样减少仓库压力，并让分解系统有价值。

# 9. 洗练与重铸设计

洗练用于调整随机词条。为了避免系统过重，洗练应保持克制。

## 9.1 洗练权限

| 品质 | 可执行操作 |
|------|-----------|
| 凡 | 普通洗练 |
| 精 | 普通洗练、定向洗练 |
| 超 | 普通洗练、定向洗练、锁词条洗练 |
| 绝 | 仅限绝品洗练，不可改变固定特效 |
| 神 | 仅限神品洗练，不可改变固定特效 |

## 9.2 普通洗练

效果：

```text
随机重置装备上的 1 条词条。
```

消耗：

```text
寒潭水 ×1
金钱 ×当前阶位基础费用
```

结果：

```text
玩家可选择保留旧词条，或替换为新词条。
```

这个设计非常重要，可以避免洗练变成纯负反馈。

## 9.3 定向洗练

效果：

```text
将 1 条词条替换为指定类型词条。
```

消耗：

```text
寒潭水 ×2
对应特殊材料 ×1
金钱 ×较高费用
```

示例：

```text
定向洗练连击率：消耗寒潭水 ×2 + 仙云皮 ×1
定向洗练暴击伤害：消耗寒潭水 ×2 + 金精 ×1
定向洗练格挡率：消耗寒潭水 ×2 + 古铜镜 ×1
```

定向洗练不保证数值满值，只保证词条类型。

## 9.4 锁词条洗练

效果：

```text
洗练时锁定 1 条词条，不被重置。
```

消耗：

```text
天罡灵气碎片 ×3 或 天罡灵气 ×1
寒潭水 ×3
金钱 ×高费用
```

限制：

```text
最多锁定 1 条词条。
天品、仙品装备不可锁定固定特效。
```

## 9.5 重铸

重铸与洗练不同：

```text
洗练：改变词条。
重铸：重新生成整件装备的词条。
```

建议仅超品及以上品质装备开放重铸；天品、仙品装备可随意重铸。

消耗：

```text
混元灵气碎片 ×5 或 混元灵气 ×1
对应阶位晶球 ×1
大量金钱
```

结果：

```text
装备品质不变。
强化等级保留。
附魔保留。
星级保留。
所有随机词条重新生成。
```

重铸是终局装备追求完美词条的手段，不应频繁使用。

| stats | object[] | 属性加成：`{ attribute, modifierType, value }[]` |
| affixes | object[] | 随机词条列表 |
| enhance | number | 当前强化等级 |
| maxEnhance | number | 强化上限 |
| star | number | 当前星级（0-3） |
| enchantSlots | object[] | 附魔槽 |
| requiredLevel | number | 穿戴等级门槛（可选） |
| factionRestriction | string | 阵营限制（可选） |
| description | string | 描述 |
