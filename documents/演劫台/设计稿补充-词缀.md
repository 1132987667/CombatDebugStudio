## 0. 设计原则

```text
1. 词缀只作为敌人难度标签。
2. 词缀只做属性修正，不承载具体能力机制。
3. 概率/百分比属性（吸血率、反伤率、格挡率、连击率、反击率等）可作为词缀属性修正——引擎每次结算时读取判定。
4. 有独立生命周期的持续效果（中毒 DOT、护盾、控制状态、净化）交给 Buff 系统——有施加/持续/移除事件。
5. 词缀不与玩家装备词条混用。
6. 增益词缀作用于敌人，只做正面修正（增强敌人）。
7. 减益词缀作用于玩家（唯一的"负面"方向）。
8. 词缀的"性格"通过「选择增强哪些属性」体现，不通过「增强A削弱B」体现。不增强某属性本身就是该敌人的相对弱点，无需显式削弱。
9. 五行攻击属性已从引擎删除（设计决策 D1b），词缀中不出现五行攻击修正。五行相关词缀统一为「五行抗性」（对应 fireRes/waterRes/metalRes/woodRes/earthRes）。
10. 同一敌人不附加同名词缀。
11. 同一 conflict_group 的词缀不共存。
12. 天命词缀为 BOSS 专属，不参与随机。
13. 词缀数量随场景/爬塔层数递增，不锁死为固定 1 个。
```

## 1. 词缀体系总览

本项目中「词缀」涵盖两个独立系统：

| 系统 | 作用对象 | 来源 | 配置文件 | 生命周期 |
|------|----------|------|----------|----------|
| **装备词条**（Equipment Affix） | 玩家装备 | 制造/洗练/重铸时随机生成 | `configs/equipment/equipment-affixes.json` | 永久 |
| **战斗词缀**（Battle Affix） | 敌人/玩家（战斗中临时） | 敌人 affixPool 配置、守护者/BOSS 被动 | `configs/xiyou/affixes.json` | 仅本场战斗 |

两者独立运作，互不覆盖：

```text
装备词条：永久附加在装备上，影响角色面板属性。
战斗词缀：战斗开始时由 affixPool 随机抽取，仅本场战斗生效。
```

## 3. 词缀字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一 ID，前缀 `affix_yao_{tier}_{seq}` / `affix_mandate_{seq}` / `affix_jie_{seq}` |
| name | string | 中文名称（修仙风格） |
| tier | string | 档位：`yao_1` / `yao_2` / `yao_3` / `yao_4` / `mandate` / `jie` |
| target | string | 作用目标：`enemy`（增益）/ `player`（劫数） |
| statModifiers | array | 属性修正列表 `[{ attribute, percent, type }]` |
| conflict_group | string? | 冲突组（同组词缀不共存） |
| rarity | number | 稀有度（1-5，用于 UI 高亮） |
| description | string | 描述文本 |
| drop_hint | string? | 掉落倾向提示（用于 UI 展示） |

## 6. 五行抗性规则

### 6.1 五行抗性上限

```text
五行抗性上限：80%（保留 20% 克制穿透空间）。
词缀修正后若超过 80%，钳制为 80%。
```

### 6.2 五行克制与抗性的关系

```text
五行克制矩阵是「天赋」——阵营克制系数。
五行抗性是「修行」——词缀修正的抗性层。
两者并存的策略意义：火克木是天理（克制矩阵），但木阵营敌人可以堆 fireRes 反制（五行抗性词缀）。
「克制是天赋，抗性是修行。」
```

### 6.3 五行冲突规则

```text
五行单体抗性（火灵/水灵/金灵/木灵/土灵）之间不互斥。
五行单体抗性与五行全抗（五行轮转/混元归一）互斥。
同一敌人最多拥有 2 条五行单体抗性，或 1 条五行全抗。
```

### 6.4 conflict_group 归属表（v2.0 词缀库）

新版词缀库的 conflict_group 仅用于五行族群互斥，非五行词缀一律为空（可自由组合，由词缀数量上限约束）：

| conflict_group | 包含词缀 | 共存规则 |
|----------------|----------|----------|
| `wuxing_single` | affix_yao_3_011 火灵护体、affix_yao_3_012 水灵护体、affix_yao_3_013 金灵护体、affix_yao_3_014 木灵护体、affix_yao_3_015 土灵护体 | 同组内可共存，上限 2 条 |
| `wuxing_all` | affix_yao_3_016 五行轮转、affix_yao_3_017 混元归一 | 同组内可共存，上限 1 条 |
| （空） | 其余全部词缀（一/二/四档、天命、劫数） | 自由组合，无冲突限制 |

> **说明**：旧版词缀库曾按属性分组（enemy_atk/enemy_def 等 19 组）互斥，v2.0 重新设计后改为按档位与词缀数量控制强度，不再按属性分组互斥。

## 7. 词缀生成逻辑

```javascript
function generateAffixes(enemyType, sceneIndex, difficulty, towerFloor) {
  const affixes = [];
  const usedGroups = new Set();
  const plan = resolveAffixPlan(enemyType, sceneIndex, difficulty, towerFloor);

  // 天命独占
  if (plan.hasMandate) {
    affixes.push(getMandateByBoss(enemyType));
    return affixes;
  }

  // 增益词缀
  for (let i = 0; i < plan.buffCount; i++) {
    const pool = getAffixPool(plan.buffTier);
    const candidates = pool.filter(a =>
      !affixes.some(x => x.id === a.id) &&
      (!a.conflict_group || !usedGroups.has(a.conflict_group))
    );
    if (candidates.length === 0) break;
    const picked = candidates[Math.floor(Math.random() * candidates.length)];
    affixes.push(picked);
    if (picked.conflict_group) usedGroups.add(picked.conflict_group);
  }

  // 劫数词缀（仅 BOSS）
  if (plan.jieCount > 0) {
    const jiePool = getJiePool();
    for (let i = 0; i < plan.jieCount; i++) {
      const candidates = jiePool.filter(a => !affixes.some(x => x.id === a.id));
      if (candidates.length === 0) break;
      affixes.push(candidates[Math.floor(Math.random() * candidates.length)]);
    }
  }

  return affixes;
}
```

## 8. 掉落联动

### 8.1 词缀与掉落倾向

| 词缀分类 | 掉落倾向 |
|----------|----------|
| 攻伐类（蛮力/天罚/太虚等） | 攻击材料、武器强化石（灿金晶球） |

| 生存类（玄龟/星辰/回春等） | 气血材料、丹药材料 |
| 五行类（火灵/水灵等单体） | 对应五行材料 |
| 五行类（五行轮转/混元归一） | 随机五行材料 + 灵气 |
| 控制类（困仙/缚神） | 配件材料（头盔/靴子/护符/戒指） |
| 概率类（连山/背水/万劫等） | 戒指材料、武器材料 |

### 8.2 词缀怪特殊掉落

```text
三档/四档词缀怪（朱红印章标记）：
  · 必掉【降妖令】或【灵气碎片】

  · 必掉稀有异化材料
```

### 8.3 异化材料用途

异化材料用于制造带有特殊词条的装备，形成「盯猎物」式刷取体验：

```text
玩家进入战斗前能看到敌人词缀，并主动选择刷某种词缀敌人。

```


### 11.5 概率属性消费（触发器路径）

吸血/反伤/格挡/连击/反击为概率属性，词缀只做百分比修正，引擎每次结算时按以下触发器路径判定：

```text
吸血率（lifestealRate）：伤害结算后，攻击者恢复 = 实际伤害 × lifestealRate%。走触发器 on_damage_dealt。
反伤率（reflectDamagePercent）：受击时，攻击者受到 = 原始伤害 × reflectDamagePercent%。走触发器 reflect_damage（已有实现）。
格挡率（blockRate）：伤害管线命中判定后，额外判定格挡。格挡成功：本次伤害 ×0.5。走触发器 on_hit_received。
连击率（comboRate）：攻击结算后，判定是否追加一次攻击。走触发器 on_attack_landed。
反击率（counterRate）：受击后，判定是否立即反击。走触发器 on_hit_received。
```

## 15. 不做的（明确推迟）

| 事项 | 原因 |
|------|------|
| 元素词条进入随机池 | 元素词条仅通过附魔获得，保持系统简洁 |
| 套装词条 | 套装系统未实现（R15 工单，P1） |
| 法宝词条 | 法宝属性由等级成长决定，不引入随机词条 |
| 神器词条洗练 | 神器为固定特效，不可变更 |
| 词条继承 | 传承系统仅转移强化等级，不转移词条 |
| 五行攻击词缀 | 设计决策 D1b 已删除五行攻击属性 |

## 16. 一句话总结

> 词缀是「妖谱」——每条词缀定义一种妖怪的战斗性格。全部正面修正，不削弱敌人。五行攻击已删，五行词缀统一为抗性（让敌人更难被克制）。吸血率、反伤率、格挡率、连击率、反击率是概率属性，归词缀管；中毒、护盾、控制是生命周期效果，归 Buff 管。天命是 BOSS 的身份证，不可随机。装备词条是「器魂」——永久附加在装备上，按 6 槽分配词条池，与战斗词缀完全独立。
