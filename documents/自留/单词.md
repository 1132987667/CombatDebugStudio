# 系统不常用词汇表

> 收录系统中实际使用、但对中文开发者不常见的英文单词（领域术语、控制状态、架构命名、配置 id 词根）。
> 来源：src/ 全部五层 + configs/（buffs.json、skills/）；2026-08 整理，词条均已确认在代码/配置中存在。

## Buff / 战斗机制

- facet: 特征维度（Buff 运行时能力的分类面，如 modifier/trigger/aura）
- polarity: 极性（positive/negative/neutral/mixed，决定 UI 颜色）
- dispellable: 可驱散的
- cascadeRemove: 级联移除（父 Buff 移除时连带移除子 Buff）
- perStack: 每层叠加（修饰符值随层数缩放）
- aura: 光环（影响范围内队友/敌人）
- dot: 持续伤害（damage over time）
- hot: 持续治疗（heal over time）
- modifier: 属性修饰符（ModifierStack 上的修正项）
- passive: 被动技能
- summon: 召唤
- yaotu: 守护者（守护系列 buff/技能前缀）
- formation: 阵型
- tick: 每回合结算（周期性驱动，onTick）
- threat: 威胁值（AI 仇恨）

## 控制 / 状态效果

- taunt: 嘲讽
- petrify: 石化
- polymorph: 变形
- imprison: 禁锢
- immobilize: 定身
- disarm: 缴械
- drain: 吸取
- frostbite: 冻伤/冰息
- knockback: 击退
- cleanse: 净化
- dispel: 驱散
- unyielding: 不屈（效果标签）
- lethal: 致命一击标记
- guixu: 归墟（拼音状态码）

## 架构 / 工程命名

- facade: 门面（应用层统一入口，BattleFacade）
- projection: 投影层（领域 → UI 快照桥接，BattleProjection）
- aggregate: 聚合根（BattleState）
- snapshot: 状态快照
- replay: 回放（战斗回放）
- trace: 追踪（trace-event 日志管线）
- checksum: 校验和
- seed: 随机种子（确定性随机）
- narrative: 叙事（回合叙述渲染）
- borrow: 对象池借用
- prewarm: 对象池预热
