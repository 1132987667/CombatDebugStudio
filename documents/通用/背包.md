
# 背包
**核心职责**：
1. **展示**：让玩家知道「我有什么、有多少、从哪来、能干嘛」
2. **操作**：支持使用、穿戴、出售、存入/取出、购买
3. **持久化**：所有物品变更即时落盘，绝不丢失
4. **引导**：空状态、限购、刷新提示帮助玩家形成目标感
