## 1. 功能作用

昊天镜是**战斗分析中心**，定位为「回放系统 ⇄ 调试系统 双工作台」。消费唤灵台/演劫台产出的战斗记录（以及演示/压测/实时/导入存档），对**同一份统一事件流（`TraceEvent[]`）**做两个投影：

- **回放系统（Projection 1 · TIMESTAMP 序）**：按时间戳顺序播放战斗，舞台随事件推进 HP/EN/Buff，事件流按时间序滚动检视；
- **调试系统（Projection 2 · CORRELATIONID 序）**：按因果链组织的时间线树 + 行动卡片流，深入检视每次行动的伤害计算步骤、RNG 凭证、状态增量。

**核心信条**（`unified-archive.ts:8`）：`events: TraceEvent[]` 是唯一事实来源，回放与调试消费同一份存档 + 同一索引，**无第二份事件序列**。让开发者回到战局中任何一刻，逐帧查看伤害链路、Buff 流转、状态变化——「验证规则正确性」与「定位战斗问题」的核心工具。

模块挂载：`BattleArena.vue:26-28`（`v-show` 保活）；`ModuleHeader.vue:39` tab2。

## 2. 现状实现

### 2.1 双工作台视图结构

容器页 `HaotianMirror.vue`（194 行）：顶部 `CommandBar` → 双工作台 `v-show` 切换 → `StatusBar` + `DiagPanel` + `BookmarkPanel`（右抽屉）。三档可拖拽列宽（`replayA/debugA/debugB`，`localStorage` 持久化）。

|------|------|

**调试工作台**（`store.mode === 'debug'`）：

| 视图 | 职责 |
|------|------|

## 3. 设计细节

### 3.1 领域层（`src/domain/battle/replay/unified/`）

| 文件 | 职责 |
|------|------|
| `unified-archive.ts` | 契约层：`UnifiedArchive`/`UnifiedEvent` 类型 + `PHASE_META` 唯一分类表（12 phase）+ `DEBUG_PHASES` |

| `demo-archive.ts` / `stress-archive.ts` | 演示/压测存档合成 |

### 3.2 关键机制

- **快照跳转**：`rebuildState` 从最近检查点续推——每 200 事件一份 sim 快照（`unified-sim.ts`），避免 seek 全量重跑。
- **实时战斗流**：`LiveBattleStream` 订阅 `TRACE_EVENT_ADDED` 补捞历史 + 观察者快照富化（`LiveBattleStream.ts`，观测快照为近似值 HACK）。
- **校验管线**：Worker 内跑 `validate` 纯函数，2s 超时回退主线程，DiagPanel 展示错误/警告/信息三档。
- **单一统计源**：实时战报（唤灵台 BattleSummaryDialog）与昊天镜摘要共用 `summarizeBattle`，不维护第二套口径。

## 5. 开发方向

1. **调试闭环补全**：断点检测提为公共函数（单步/seek 生效）+ watch 模式 + 命中计数，这是调试工作台最大痛点。
2. **检索升级**：phase 胶囊 + 参与者/数值区间过滤（数据已结构化，缺 UI 暴露）。
4. **种子重演（照妖镜）**：① 引擎随机源收敛注入（已就绪）→ ② 唤灵台/演劫台固定种子开关 → ③ 昊天镜回归台批量重演 + diff + 断言报告。
5. **消解近似 HACK**：buff 正负标记、HP 快照、实时流观察者快照——随统一事件流契约演进逐步精确化。
