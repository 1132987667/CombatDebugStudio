tab1 唤灵台（阵容战斗）
10 条意见
暂停按钮是摆设。 ControlBar.vue:15 发射 toggle-pause，但 Huanling.vue:51-54 根本没监听——点了完全没反应，而底层 battleStore.togglePause 和 BattleLifecycleManager.togglePause 都是完好的，就差一根线。
调试面板大半是假按钮。 Huanling.vue:109-284 的 win_battle/lose_battle/force_crit/force_dodge/export_state/import_state 等 15+ 项只往日志写一行字，不执行任何逻辑。按钮文案写得像真功能（"直接判定我方胜利"），点完啥也不发生。
角色编辑器和场景管理两个对话框永远打不开。 CharacterEditor、SceneManagementDialog 都挂载了、逻辑也完整，但 showStatusDialog/showSceneDialog 全项目从没被置为 true——功能躺在代码里，UI 无入口。
"手动单回合"无处可达。 store 的 processSingleTurn 实现完好，但没有任何 UI 按钮触发它。断点单步（DebugGate）和手动单回合是两回事，后者被遗忘了。
规则对话框部分开关改了不生效。 speedFirst/fixedTurns 只存 Pinia，不同步 BattleRuleManager；而领域层真实的 minDamage/maxDamage/energyGainPerTurn 等参数 UI 又暴露不了。你调的不一定是战斗用的那份。
默认阵容硬编码。 已修复：Huanling.vue initBattle 从封神榜预设阵容（lineups 表）读取默认阵容，roles 中 roleId 匹配 actors 的归我方、匹配 enemies 的归敌方，无可用阵容时回退取前两个敌人。封神榜编辑阵容后默认阵容自动跟随。
作为"调试沙盒"却完全不能手动干预战斗。 技能、目标全部由 AI 自动决策，用户唯一能做的就是点选角色看属性。验证一个技能连招效果只能反复跑随机。
场景管理不落地。 保存/加载"场景"只是内存数组，刷新即失（Huanling.vue:404-425）。
18 个调试预设写死在代码里。 ParticipantPanel.vue:259-388 的预设没法在 UI 增删改，想加个组合只能改代码。
速度档位与配置脱节。 领域层 availableSpeeds 含 0.5×，UI 只有 1/2/3/5，两头对不上。
10 条需求
手动操控模式：选中角色 → 手动选技能 → 手动选目标 → 点释放，走一遍真实结算而不是 AI 代劳。
固定种子复现：每场战斗可设置/随机生成种子，配合已有 SeededRandom 基础设施做"确定性战斗"开关。
战斗规则全项可调：把 BattleRuleManager 的 min/max 伤害、能量获取、防御减伤系数等全部暴露，且每项都真实同步到领域层。
自定义阵容持久化：把搭好的阵容存成带名字的 lineup 回到封神榜，下次直接下拉选用。
伤害公式可视化：点任意伤害数字，弹出该次命中的完整计算分步（攻击→暴击→防御→减伤→浮动）。
战斗中途跳转昊天镜：任何时刻"从当前进度进入昊天镜回放"，无缝衔接分析。
战报 ↔ 摘要打通：战斗结束战报里"查看完整分析"一键跳到昊天镜对应场次。
预设编辑器：在 UI 里创建/修改调试阵容预设，存 IDB 而非硬编码。
单步回退：手动单回合之外支持"撤销上一行动"，调试分支对比用。
Buff/属性注入可视化：把假调试按钮换成真的——直接给指定角色注入指定 Buff、改指定属性，并标注入来源。
tab2 昊天镜（战斗分析）
10 条意见
摘要只展示了七层模型的一半。 L4 判定健康度、L5 技能使用、L6 被动触发、L7 关键事件只存在于模型和 Markdown 导出里，SummaryDialog 的 UI 表格根本没画。想看完整结论得导出文件。
事件流过滤维度太单一。 只有关键词 + "调试专属"开关（haotianStore.ts:228-236），没有按 phase / level / 单位 / 结果类型的组合过滤。断点、回放、查错都得在一整条流里人肉翻。
回放中 Buff 只有名字没有内容。 ReplayStage.vue:129,289 两处 HACK 承认：存档契约缺 buff 正负与属性明细，施加动画统一按正向播，减益也闪"增益光"。
HP 数值是近似值。 录制路径用伤害/治疗累减估算 HP（UnifiedArchiveService.ts:97、LiveBattleStream.ts:63），护盾、过量治疗、多层减伤都没算进去——回放看到的气血可能和实况不一致。
"重掷该判定"是假的。 Inspector.vue:406-428 用 Math.random() 本地模拟，明写"仅模拟，不写入存档"，对验证分支无实际帮助。
角色属性面板只看初始快照。 RoleAttrsPanel.vue:41-43 读的是 initialState.participants.attributes，回放到第 50 回合时面板属性还是开战那一刻的，和当前状态脱节。
断点类型 none（手动暂停）UI 配不出来。 模型支持，BreakpointDialog 下拉却只有 4 项。
战斗记录列表没有搜索/筛选/排序。 词牌名+序号上百条后只能翻，RecordManagerDialog 只有刷新/导出/删除。
会话导入强绑 battleId。 换一场战斗，书签/断点/会话就全拒绝（haotianStore.ts:989-992），分析连续性被打断。
config_validation 归类自相矛盾。 PHASE_META 标它 debugOnly，DEBUG_PHASES 却不含它——校验统计与 UI 隐藏口径不一致，偶发"看不到但也统计不上"。
10 条需求
回放属性实时同步：推进到任一事件时，角色面板属性按 sim 状态刷新，而非初始快照。
多维事件过滤器：phase × 单位 × level × 结果类型组合过滤，过滤结果驱动时间线/流/卡片联动。
摘要 UI 完整化：七层全部上屏，L4-L7 至少用折叠区块呈现，表格化而非仅导出。
Buff 明细契约补齐：存档加 buff 正负/属性明细，回放准确区分增益/减益/层数，动画、卡片、tooltip 同步。
跨场次对比：一次加载多场战斗，按事件时间对齐做 diff——回归时"同一配置跑两场"直接可比。
高级断点：支持组合条件（"某个单位的暴击且伤害 > 500"）、因果链触发、断点命中时自动导出现场。
工作区持久化增强：书签+断点+过滤条件存成命名会话，跨战斗可迁移（弱化 battleId 强绑）。
分支回归：从演示存档自动生成 N 个随机分支批量跑，输出通过/差异报告，而不是靠人一次次点。
录制列表管理增强：搜索、按时间/事件数排序、批量删除、展示 battleId 与来源标记。
RNG 反推真实化：重掷复用存档种子 + 既定 roll 序列做"如果当时阈值不同"假设分析，写入分支而非本地瞎猜。
tab3 封神榜（数据编定）
10 条意见
params（战斗规则参数）编辑了不生效。 FormulasView.vue:5 白纸黑字"当前公式在代码中，此页为只读参考"——页面上却能编辑这 5 条战斗参数，引擎根本不读。能改的东西改了没用，比不能改更误导。
buffs 双轨，改了不回灌战斗。 BuffScriptRegistry.ts:88-89 从静态 configs/buffs/buffs.json 注册，封神榜 IDB 里的 buffs 编辑后列表变了、战斗里的 Buff 定义完全不变。
图鉴与封神榜数据源脱节。 图鉴读 configs/enemies|buffs|materials.json 静态文件，封神榜改完数据图鉴纹丝不动，两套数据互相打架。
enemies 表没有侧栏入口。 角色和敌人明明是一体，UI 却只让走 actors 入口；真正的敌人只能靠数据包导入或健康检查跳转，管理路径绕。
复杂字段全是 JSON 文本编辑。 技能步骤、Buff 效果、掉落条目都是手敲 JSON（FieldEditor.vue:59-69），有语法校验但没有任何结构引导，非技术用户直接劝退。
搜索维度单薄。 只匹配 name/id，想按属性值、技能类型、数值区间找一条记录做不到。
操作日志没有"那一次改了什么"。 只有增/删/改/导入的时间线，点开看不到字段级 diff，出问题没法追溯。
列表数据是"能看不能用的快照"。 全量拉取客户端过滤（fengshenStore.ts:92 自注），数据量上来后分页、搜索、性能都会是隐患，且 API 层的分页参数是死的。
没有批量能力。 批量删倒是有，但批量改属性（比如统一调低某档角色等级）没有。
编辑与校验的"失败感"重。 引用校验、唯一性校验都在保存时才炸，编辑过程中没有实时提示，填错一整个数组才报错。
10 条需求
结构化子编辑器：技能步骤/Buff 效果/掉落条目用可视化行编辑器（字段表单逐行），JSON 仅作高级模式兜底。
数据包导入前差异预览：导入前展示"将新增 N / 覆盖 M / 跳过 K"，逐条可勾选，而不是一把梭三选一。
字段级操作历史：操作日志点开看那次改动的字段级 diff（旧值 → 新值），支持一键回滚到该版本。
图鉴接入 IDB + 补 tab：图鉴直接读封神榜数据源，并补角色、技能、装备 tab，让"查"和"改"看同一份数。
buff/params 真正生效：把 IDB 的 buffs、params 接进引擎数据源（BuffScriptRegistry 改读 IDB、BattleRuleManager 读 params），消灭"能编辑不生效"。
战斗沙盘预览：编辑技能/Buff 后内嵌一个最小模拟器，即时跑一次伤害/治疗看数值，边改边验。
批量字段编辑：多选记录统一改某字段（带覆盖确认），支持范围/批量赋值的常见编定场景。
引用关系可视化：数据域依赖图（谁引用了谁），断裂引用一眼可见，而非只有健康检查表格。
搜索升级：按任意字段值、数值区间、引用目标过滤，支持多条件组合。
阵容/数据包的"在唤灵台打开"：封神榜编辑的 lineup 一键在唤灵台加载开战，数据闭环从"编"直接到"验"。
