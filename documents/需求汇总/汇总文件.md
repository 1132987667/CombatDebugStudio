# 需求汇总（2026-09-09 复核后留存）

> 已逐条核对当前代码：原 30 条意见中 23 条已修复、多数需求已实现，均删除不再记录。
> 本文只保留两类内容：**部分修复项的残留点**、**尚未实现的需求**。

## tab1 唤灵台（阵容战斗）

### 残留问题

1. 战斗规则参数暴露不全。speedFirst/fixedTurns/critEnabled/dodgeEnabled/energyGainPerTurn 已真实同步 BattleRuleManager（battleStore.updateRules），但 minDamage/maxDamage 领域层有配置（BattleRuleManager.ts:161-163）而 BattleRules 接口不含、updateRules 不同步、BattleRulesDialog 无输入项。
2. 手动操控模式缺 UI。executeManualAction 全链路已通（BattleSystem → BattleFacade → battleStore.executeManualAction，battleStore.ts:776-794），但全仓无任何 .vue 调用它——「选中角色 → 选技能 → 选目标 → 释放」的交互界面不存在，手动模式下技能/目标仍由 AI 决策。
3. 内置调试预设只读。预设已外置为 configs/presets/battle_presets.json 但不可编辑；自定义预设可增删，持久化用 localStorage（huanling.presets.custom.v1）而非 IDB。

### 未实现需求

- 单步回退：撤销上一行动，调试分支对比用。全仓无任何 undo/状态回滚逻辑。
- 种子设置入口：锁定种子目前只在演劫台调试台（yanjie/xiyou/debugActions.ts），唤灵台本模块无种子设置 UI。

## tab2 昊天镜（战斗分析）

### 残留问题

1. Buff 存档契约缺正负/明细。ArchiveBuff 仍只有 {name, stacks, turns}（unified-archive.ts:31-36），发射端 BuffTraceLogger payload 也无 polarity；UI 靠 resolveBuffMeta 反查 buffs.json 兜底，脚本自定义 buff 反查不命中时仍默认按正向播。
2. HP 回放仍是累减模拟。录制路径已改用 payload.actual（护盾吸收后真实扣血，TraceDamageLogger）消除护盾/多层减伤偏差，过量治疗靠 clamp 兜底；但 LiveBattleStream.ts:63 历史回填的「近似快照」HACK 仍在。

### 未实现需求

- 跨场次对比：一次加载多场战斗，按事件时间对齐做 diff。现有 DiffDialog 仅支持同场次分支对比，跨场次 correlationId 不对齐。
- 录制列表批量删除：搜索/排序已有（RecordManagerDialog），仍只能逐条删除。

## tab3 封神榜（数据编定）

### 残留问题

1. 复杂字段仍是 JSON textarea。技能步骤/Buff 效果/掉落条目无逐行可视化编辑器；已有改善：实时语法状态条、schema 示例一键填入（fillTemplate）、格式化（FieldEditor.vue）。
2. 列表仍全量拉取 + 客户端分页。API 层已支持 search/offset/limit，但列表实际只传 search、全量读表后客户端分页（fengshenStore.ts:104-106 注释已明示取舍）。本地 IDB 几十~几百条量级下属有意设计，低优先级。

### 未实现需求

- 数据包导入前差异预览：展示「将新增 N / 覆盖 M / 跳过 K」并逐条可勾选。现仅导入前预览包信息（版本/各表条数），导入完成后才给结果统计。
- 操作日志一键回滚：字段级 diff（原值/新值表格）已可查看（LogsView + entity-diff），但无「还原到旧值」。
- 引用关系可视化：现为文本列表式反向引用（EntityDetailPanel「被引用 N 处」），无图形化依赖图。低优先级。
