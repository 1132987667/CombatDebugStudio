## 1. 项目概述

### 1.1 项目背景

战斗调试工作室是一个基于Web的回合制战斗系统调试工具，旨在为游戏开发者提供一个可视化、可调试的战斗系统测试环境。该系统支持多种战斗场景配置、智能敌人AI、完整的Buff/减益效果系统，以及战斗回放和调试功能。

### 1.2 项目目标

1. 提供完整的回合制战斗系统核心实现
2. 支持多种战斗场景和敌人配置
3. 实现智能战斗AI决策系统
4. 提供可视化调试和监控界面
5. 支持战斗过程回放和分析

### 1.3 目标用户

- 游戏开发人员
- 战斗系统测试工程师
- 游戏设计师
- 独立游戏开发者

## 3. 功能需求

### 3.1 战斗系统功能

#### 3.1.1 战斗生命周期管理

| 需求ID | 功能描述 | 优先级 |
|--------|---------|--------|
| F-BATTLE-001 | 创建新的战斗实例 | 高 |
| F-BATTLE-002 | 初始化战斗参与者 | 高 |
| F-BATTLE-003 | 执行回合制战斗流程 | 高 |
| F-BATTLE-004 | 暂停和恢复战斗 | 中 |
| F-BATTLE-005 | 战斗结算和结果判定 | 高 |
| F-BATTLE-006 | 战斗状态查询 | 中 |

**战斗状态定义：**

- `CREATED`：已创建，等待参与者加入
- `PREPARING`：战前准备，初始化技能和Buff
- `ACTIVE`：战斗进行中
- `PAUSED`：战斗暂停
- `SETTLEMENT`：战斗结算
- `ENDED`：战斗结束

#### 3.1.2 回合管理

| 需求ID | 功能描述 | 优先级 |
|--------|---------|--------|
| F-TURN-001 | 按速度属性计算回合顺序 | 高 |
| F-TURN-002 | 检测速度变化并重新排序 | 高 |
| F-TURN-003 | 管理回合内行动顺序 | 高 |
| F-TURN-004 | 回合开始/结束事件触发 | 中 |

#### 3.1.3 动作执行

| 需求ID | 功能描述 | 优先级 |
|--------|---------|--------|
| F-ACTION-001 | 普通攻击执行 | 高 |
| F-ACTION-002 | 技能释放执行 | 高 |
| F-ACTION-003 | 伤害计算和应用 | 高 |
| F-ACTION-004 | 治疗效果计算和应用 | 高 |
| F-ACTION-005 | 闪避判定 | 高 |
| F-ACTION-006 | 暴击判定和伤害倍率 | 高 |

### 3.2 角色战斗属性系统

#### 3.2.1 基础属性（16项）

| 属性 | 说明 | 范围 |
|------|------|------|
| level | 角色等级 | 1-99 |
| name | 角色名称 | 字符串 |
| currentEnergy / maxEnergy | 当前/最大能量 | 0-200 |
| currentHealth / maxHealth | 当前/最大气血 | 0-9999 |
| minAttack / maxAttack | 最小/最大攻击力 | 1-9999 |
| defense | 防御力 | 0-9999 |
| speed | 速度 | 1-9999 |
| critRate | 暴击率 | 0-100% |
| critDamage | 暴击伤害 | 100-500% |
| healthBonus / attackBonus / defenseBonus / speedBonus | 百分比加成 | 0-500% |
| damageReduction | 免伤率 | 0-100% |

#### 3.2.2 能量系统规则

- 初始能量：30点
- 回合开始恢复：15点
- 小技能消耗：50能量（冷却2回合）
- 大技能/终极技消耗：150能量（冷却5回合）
- 受击回复：12点（每回合最多3次）
- 被动技能：无消耗

### 3.3 战斗计算公式

- **基础伤害**：`random(minAttack, maxAttack)`
- **防御减免**：`DEFENSE_EFFECTIVENESS = 0.5`，`DEFENSE_DENOMINATOR = 500`
- **最终伤害**：`基础伤害 × (1 - 防御减免)`，向下取整
- **暴击伤害**：`最终伤害 × critDamage / 100`
- **命中判定**：`random(0, 100) < (命中率 - 目标闪避率)`
- **暴击判定**：`random(0, 1) < critRate`

### 3.4 Buff系统

#### 3.4.1 Buff脚本架构

所有Buff采用**自包含脚本模式**，每个脚本类通过静态 `CONFIG` 字段提供元数据，框架自动读取并注册。脚本位于 `domain/buff/scripts/` 下，按用途分目录组织：

- `combat/` — 战斗Buff（AttackUp、DefenseUp、Poison、Stun等）
- `support/` — 辅助Buff（Shield、HealOverTime等）
- `base/` — 模板基类（BaseBuffScript、AttributeBuffTemplate、BuffTemplate）

#### 3.4.2 增益效果（Buff）

| 效果名称 | 效果 | 持续时间 |
|---------|------|---------|
| 攻击力提升 | 攻击+20% | 3回合 |
| 防御力提升 | 防御+30% | 4回合 |
| 速度提升 | 速度+25% | 3回合 |
| 护盾 | 吸收伤害 | 2回合 |
| 生命回复 | 每回合恢复 | 3回合 |
| 狂暴 | 攻+50% 防-20% | 2回合 |
| 山神祝福 | 受伤-50% + 免疫控制 | 3回合 |
| 闪避提升 | 闪避率+20% | 3回合 |

#### 3.4.3 减益效果（Debuff）

| 效果名称 | 效果 | 持续时间 |
|---------|------|---------|
| 中毒 | 每回合伤害 | 4回合 |
| 眩晕 | 无法行动 | 1回合 |
| 速度降低 | 速度-30% | 2回合 |
| 命中率降低 | 命中-25% | 2回合 |
| 暴击伤害降低 | 暴击伤害-30% | 2回合 |
| 重伤 | 受伤+20% | 3回合 |

#### 3.4.4 叠加规则

- **刷新叠加**：新效果覆盖旧效果，重置持续时间
- **限制层数**：达到上限后不可叠加
- **独立叠加**：每层独立计算

### 3.5 技能系统

#### 3.5.1 技能属性

- ID、名称、描述、能量消耗、冷却时间
- 目标选择策略（self/ally/enemy/all/lowestHP/front/back/random/adjacent）
- 技能步骤数组（damage/heal/buff/debuff/conditional 等类型）

#### 3.5.2 技能类型

| 类型 | 说明 |
|------|------|
| ACTIVE | 主动技能，需要能量消耗和冷却 |
| ULTIMATE | 终极技能，高消耗高冷却 |
| PASSIVE | 被动技能，无消耗 |

#### 3.5.3 效果类型

- `damage` — 伤害
- `heal` — 治疗
- `buff` — 增益
- `debuff` — 减益

### 3.6 AI系统

#### 3.6.1 决策流程

评估战场态势 → 选择最优技能 → 选择攻击目标 → 能量管理 → 威胁计算

#### 3.6.2 优先级策略

1. 治疗技能（血量低于阈值时）
2. 攻击技能/终极技
3. Buff技能
4. Debuff技能

#### 3.6.3 能量阈值

- 高能量（≥70%）：使用大技能
- 中能量（50%-70%）：均衡使用
- 低能量（<50%）：普通攻击

### 3.7 战斗控制

#### 3.7.1 自动战斗
- 开启/关闭自动战斗
- 速度调节（0.5x / 1x / 2x / 5x）
- 战斗暂停/继续

#### 3.7.2 手动干预
- 暂停战斗
- 中断AI行动
- 手动选择技能和目标

#### 3.7.3 战斗重置与回放
- 重置战斗
- 录制战斗过程
- 回放战斗（含状态快照跳转）

### 3.8 调试功能

- 实时显示角色属性
- 属性变化追踪
- Buff状态显示（图标 + 悬停详情）
- 战斗日志记录（分级、过滤、搜索）
- 伤害数值浮动显示
- 场景切换与敌人配置加载
- 战斗规则自定义（先手判定、暴击开关、闪避开关等）
